# 右键菜单：各处现状与调整建议

这份说明按实际界面位置来讲：在哪里右击、现在会发生什么、哪里不顺手，以及建议改成什么。技术依据另见[源码盘点](CONTEXT_MENU_AUDIT.md)。这里的调整均是建议，尚未修改界面。

## 已确认保留的交互

参数面板与关键点编辑控件分别沿用 Cubism 和 Photoshop 的交互习惯。控件和任务不同，右键执行不同操作合理，保留吸附与直接删除，不把它们列为冲突。

停靠标签之间的空白提供“关闭全部”合理，保留这个入口。纹理图集通常不超过六页，目标页继续平铺；菜单超出可用高度时提供滚动条，不强制增加二级菜单。

普通网格右击作用于当前选择合理，保留现有行为，不改成按鼠标位置重新选取对象。顶部菜单的信息组织和操作排列可以继续优化，作为独立优化项梳理。

## 最需要先处理的地方

**层级树里的菜单没有清楚说明改谁。** 多选时，右击其中一行，画面可能仍显示多选，但菜单动作实际只针对这一行。多个变形器合并显示成一行时，菜单标题指向某个变形器，删除动作却传入整条合并链。需要先让菜单名称、选择高亮和实际操作范围一致。

**较长菜单需要能滚动。** 图集目标页继续直接列出，重点检查小窗口或较大界面缩放下能否通过滚动条访问全部内容。

**同一个对象在树上和画布上的菜单不够一致。** 例如前后景拆分，在树里能进入首次设置，在画布里主要提供已有拆分的快速操作；选中曲面变形器后，树里的创建操作也比画布里完整。需要逐项决定哪些差异确有必要，其余统一。

## 现在有哪些地方已经有右键菜单

当前共找到 **17 处独立的右键菜单实现**。一处实现可能服务多种位置，例如素材库的树、卡片和列表共用一套菜单，因此不是说整个界面只有 17 个可右击的位置。

| 在哪里右击 | 现在大致能做什么 | 建议 |
|---|---|---|
| 主编辑画布 | 调当前工具、操作当前选择；选中参考图时显示参考图操作 | 保留，明确操作对象和数量 |
| 素材独立编辑窗口的画布 | 调绘画工具、处理素材绘画 | 保留，与主画布同类工具一致 |
| 层级树的变形器行 | 创建父子变形器、摆动、导入、展开折叠、删除 | 保留，先说明删除单个还是整条链 |
| 层级树的网格对象行 | 转参考图、显隐、创建、拆分、绘制顺序、删除 | 保留，分组并缩短一级菜单 |
| 层级树的独立前景或背景参考图行 | 切显示位置、显隐、透明度、锁定、钉选、移除 | 保留，显示位置改为单选子菜单 |
| 素材库的目录、素材和空白区域 | 编辑、放置、导入、整理目录、参考图、删除等 | 保留，区分素材、文件夹和空白 |
| 开始页的最近文件卡片或列表行 | 打开或生成、显示目录、移除最近记录 | 保留，目前结构基本合适 |
| 参数面板的文件夹行 | 重命名、新建子项、标签颜色、删除文件夹 | 保留，把颜色收进子菜单 |
| 参数快照按钮 | 覆盖、重命名、删除 | 保留，不需要再套子菜单 |
| 动作列表行 | 编辑、播放、复制、恢复、删除，自定义动作可重命名 | 保留，整理恢复与删除的位置 |
| 物理组列表行 | 复制、打开摆动编辑、调整顺序、恢复或删除 | 保留，补上重命名 |
| 模拟体列表行 | 烘焙、清除烘焙、删除 | 保留，当前短菜单合适 |
| 纹理图集的图块或空白 | 密度、旋转、移页、锁定、排列、保存和视图操作 | 保留，目标页平铺，超高时加滚动条 |
| 停靠面板的标题文字或标签 | 浮动、返回停靠、关闭当前或同组面板 | 保留，标明关闭范围 |
| 停靠标签之间的空白和组拖动握柄 | 只有关闭全部 | 保留，是面板组操作入口 |
| 顶部工作区标签 | 重命名、复制、关闭当前、其他或右侧工作区 | 保留，与关闭面板区分 |
| 日志表头 | 显示或隐藏时间、来源、标签，恢复默认列布局 | 保留，统一菜单样式 |

此外还有五种“右击直接做事、不会先弹菜单”的控件：参数名称打开属性、一维参数轨道吸附到关键值、二维参数板吸附到交点、参数关键点轴直接删除、绘制顺序标尺打开数值窗口或拖动平移。它们需要单独判断，不能全部当成菜单缺失。

## 编辑画布：保留就近操作，稳定菜单位置

### 现在是什么样

画布菜单跟着当前模式和工具变化：选择时提供对象、选择和创建操作；编辑网格时有拆分、细分、连接、合并等；用笔刷时有大小、强度、硬度等；绘画时有大小、不透明度和清空绘画；骨骼、权重、粘合工具也各有内容。

主画布和素材编辑窗口中同类绘画工具共用菜单，这种重复合理。工具栏和右键菜单都能调笔刷也合理：用户不需要为了改一下大小离开正在画的位置。

### 哪里需要调整

- 普通网格右击继续操作当前选择，不调整对象选取规则。菜单顶部可优化名称、选择数量和常用项的呈现，这是信息组织优化，不是交互缺陷。
- 空白处可以继续提供当前工具或当前选择的操作；不要仅因右击位置为空白，就要求换成另一套对象选取规则。
- 有些分组会随着菜单变长，自动从一级收进二级；内容稍有变化，又会展开回来。建议让“创建”“网格”“素材”“镜像”等分组保持固定位置和层级。
- 网格编辑菜单中，“删除”目前夹在“合并”和“复制”之间。应把复制放在普通编辑操作附近，删除移到这一组最后，并加分隔。
- 用户把右键设成其他鼠标命令后，主画布和图集对菜单、鼠标命令的先后处理不同。应统一为先尊重当前手势与鼠标绑定，再决定是否打开菜单。

### 建议的排列方式

菜单从上往下依次是：当前任务的完成、撤回一步和取消；工具种类；大小、强度等常调设置；当前对象的动作；创建、网格、镜像等子菜单。

删除或清空放在相关组最后。正在创建路径时的“取消”仍应靠近“完成”，不必因为它也是取消动作，就挪到对象删除区。

### 顶部菜单另行优化

顶部菜单可以继续梳理功能分组、常用操作的先后顺序，以及与工具栏、右键菜单的对应关系。这一项单独整理具体方案，不以改变普通网格右击行为为前提，也不把保留多处入口本身当成问题。

## 层级树：先说清楚对象，再组织操作

### 网格对象行

现在一张菜单同时放了转换参考图、显隐、创建变形器、摆动、路径、导入、前后景拆分、绘制顺序、网格拆分和删除，一级偏长。

建议保留以下顺序：

1. 对象名、转换为参考图。
2. 显示或隐藏、独显。
3. “创建”子菜单：父级曲面变形器、父级旋转变形器、路径、摆动等适用动作。
4. “网格”子菜单：重建、拆分独立网格、前后景拆分等适用动作。
5. 绘制顺序、导入到此处。
6. 分隔后放删除图层。

多选时必须明确“只处理右击这一项”还是“处理全部所选”。不能保持多选高亮，却让没有范围提示的删除只删其中一个。若某种对象没有任何可用动作，不应只弹出一个对象名。

### 变形器行

创建父级、子级变形器可收进“创建”子菜单；摆动、导入、展开和折叠单独成组；删除放最后。

最先要确认合并显示的变形器链：右击其中一个名字后，到底是删除这个变形器，还是删除整条链。两种行为应分别叫“删除当前变形器”和“删除整条链”，选择提示也要对应。不能只写“删除变形器”，却让用户猜范围。

合并行中不同名字片段的右键位置也需要检查，保证菜单出现在实际点击处，而不是偏到行左侧。

### 参考图行

树和画布都能操作参考图应保留，它们本来就在服务同一个对象。

建议顺序是：名称、类型转换；显隐、透明度、锁定；显示位置、参数钉选；最后是移除。

“背景、层内、前景”是三选一，适合合成“显示位置：当前值”，展开后用单选标记。透明度保留滑条，调整时菜单保持打开。“参数钉选”继续保留专门的轨道或二维板，不应展开成很长的参数值文字列表。

### 层级树空白

这里目前缺一个容器菜单。建议提供“导入图层到根级”“全选”“取消选择”“展开全部”“折叠全部”。没有具体目标时，不提供“给当前对象添加父级”这类动作。

## 图层表格：这是优先补右键的地方

图层表格已有选择、显隐、前后移动、转换参考图、标签和素材链接等能力，但名称区域没有对应的右键菜单，很多动作要回工具栏找。

建议在名称和行背景上补菜单：先显示图层名或选择数量，再提供类型转换、显隐和独显、排列、素材操作、标签，最后放删除。排列只对允许在图层堆叠中移动的对象开放，不能把它与生成后网格的绘制顺序混为一谈。

标签、参数名等可编辑单元格仍应按自身内容处理右键，不要在用户编辑文字时突然弹出整行的图层菜单。

## 参数面板：把“调值”和“管理参数”分开

### 参数名称

现在左击和右击都打开属性窗口，右键没有多提供任何内容。这是明确的重复入口。

建议左击继续打开属性；右击显示“属性”“重置当前值”“锁定或解锁”“复制参数”“复制参数编号”，最后放“删除参数”。删除继续走已有的删除流程，不要右击即删。

### 参数关键值与关键点编辑

参数面板上一维轨道、二维交点的右击用于快速切到关键值；关键点编辑窗口里的右击用于直接删点。两者分别沿用 Cubism 和 Photoshop 的逻辑，控件和操作任务不同，保留各自行为，不统一成一张关键点菜单。已有键盘删除继续保留。

### 参数文件夹

菜单应先放“新建子参数”“新建子文件夹”，再放重命名与标签颜色，最后放删除文件夹。颜色收进子菜单，里面保留无色、预设色块和自定义颜色。

色块需要有颜色名称或提示，不能只让人凭颜色猜。删除文件夹是否同时影响成员需要先核对清楚，再决定文案和危险提示。

### 参数快照

现在的“覆盖、重命名、删除”已经很短，不需要二级。可以把“应用快照”补到第一项，接着是“用当前值覆盖”“重命名”，分隔后删除。

左键应用、右键管理本身是合理分工，不属于需要删除的重复。

## 动画：动作有菜单，轨道和关键帧还缺

### 动作列表

现有菜单基本完整。行上的编辑、播放按钮与右键里的同名操作可以同时保留，按钮方便高频操作，菜单方便辨认和查找。

建议顺序是：编辑、播放或暂停；重命名、复制；恢复默认；删除。内置动作与自定义动作的内容应有区别：内置动作可以复制为自定义、恢复默认；自定义动作可以重命名和复制。恢复与删除不要紧挨着放成含义模糊的一组。

### 轨道行

目前主要靠行内按钮添加关键帧、移除轨道，缺右键入口。建议补“聚焦轨道”“在播放头处添加关键帧”，分隔后放“移除轨道”。这里不该出现“删除整个动作”。

### 时间线和曲线关键帧

已有复制、粘贴、删除、全选等能力，但缺菜单入口，是优先补充的地方。

右击关键帧时，建议提供复制、粘贴、插值方式、重置贝塞尔手柄，最后删除选中帧。插值方式适合二级菜单。右击空白时，提供粘贴、给当前姿态打关键帧、全选和适配视图。

已选择多个关键帧后，右击其中一个应保留选择，让菜单操作全部所选；右击未选关键帧则应明确是否切换选择。

## 物理与模拟：保留短菜单，补齐管理动作

### 物理组

物理组列表右键已有复制、排序、恢复和删除；编辑器标题的“更多”还提供重命名。建议把重命名补到列表右键里，用户不必先进入编辑器再改名。

建议排列为：重命名、复制、编辑摆动；上移、下移；恢复生成值或删除自定义组。菜单短，没必要增加二级。

“恢复默认”和“删除”不应合并。前者把修改过的自动生成组恢复回去，后者移除用户创建的组。它们针对不同来源，应按来源显示或禁用，并把含义写清楚。

### 模拟体

现有“烘焙或重新烘焙、清除烘焙、删除”结构合适，保留即可。清除结果与删除模拟体要有分隔，忙碌时说明为什么不能操作。不必为了与动作列表对称，硬加没有实际需求的子菜单。

## 骨骼树与历史树：对象能选中，却缺少就地管理入口

骨骼树的骨骼行目前主要支持选择和展开，增删在工具栏；绑定网格的解绑靠行内按钮。建议给骨骼行补“添加骨骼”“展开或折叠”“删除骨骼”，给绑定网格行补“选择图层”和“解绑”。只读或姿态模式下，不应开放结构编辑。

历史树目前单击查看、双击切换版本，标题、注释和隐藏等要到详情里操作。可以补“查看详情”“切换到此版本”“编辑标题和注释”“隐藏或显示”“复制节点编号”。不要借这次整理增加删除历史分支等新能力。

这两处都适合在对象名称和行背景右击，不能让展开箭头、输入框等子控件的操作被抢走。

## 素材库：入口够了，主要整理内容和范围

### 素材条目

树、卡片和列表使用同一张素材菜单是合理的，应继续保留。建议把常用动作放前面：编辑、放置、替换所选图层、添加参考图；之后放定位引用，再放重命名、标签、默认参考状态和矢量分辨率；移动、删除靠后。

“添加参考图”有背景、层内、前景三种去向，保留二级菜单合理。它们是否进入模型应继续明确说明。

**“定位引用图层”需要纠正文案与行为。** 菜单可能显示有多个引用，但当前动作只定位第一个。建议单引用时直接定位，多引用时让用户选具体引用；若暂时不做选择器，就明确写“定位第一个引用”。

### 文件夹

建议顺序是：打开、放置其中素材；新建子目录、导入文件、导入文件夹；重命名、标签等整理操作；导出、移动；最后删除。

文件夹“添加参考图”目前只有层内这一种有效去向，没有必要再让用户展开一层。可以直接写“作为层内参考图放置”。涉及文件夹内全部素材的动作，要说明包含哪些内容。

### 空白区域

空白处的“新建文件夹、导入文件、导入文件夹”有用，应保留。视图设置放后面：网格和列表只能选一个，应使用单选；显示目录树是独立开关，应使用勾选。

面包屑路径目前没有右键。已有树和空白入口足够，不急着补；以后若增加，就要针对被右击的那一级目录，不能误用当前打开的目录。

## 纹理图集：按图块和页面分别整理

### 右击图块

建议先显示所选图块名称或数量，把“聚焦所选”放前面；接着是密度、旋转、移到页、锁定；后面放排列所选和单图块替换图像。

“密度”是否收成一组可按整体长度判断。“移到第几页”继续平铺，按通常不超过六页的使用规模设计，不要求多点一层。菜单超出窗口可用高度时提供滚动条，保证目标页和其他操作都可访问。

多选时，锁定状态可能不一致，应该能看出“部分锁定”，不能简单画成全部已锁或全部未锁。

### 右击空白

页面菜单建议依次为：当前页名称；全选本页、适配本页；排列全部；保存当前页。

图块菜单负责所选图块，空白菜单负责页面。即使用户之前还选着别的图块，也要让当前菜单的范围一眼可见。

## 面板、工作区、日志与最近文件

### 面板标题与工作区标签

两者都出现“关闭”并不算多余，因为关闭的是不同东西。面板菜单应写“关闭当前面板”“关闭同组其他面板”“关闭本组全部面板”；顶部标签写“关闭工作区”“关闭其他工作区”“关闭右侧工作区”。

面板的浮动或返回停靠放在关闭动作前面。菜单应靠近点击处出现，并统一外观。标题内部的视图选项、背景等按钮仍按自身职责操作，不应顺带打开面板菜单。

标签之间的空白和组拖动握柄保留“关闭全部”。这是操作整组面板的入口，与单个标签菜单中的同名动作并存合理，不列为多余触发。

### 日志

表头右键有用，应保留。时间、来源、标签是三个独立开关，可以连续勾选；“恢复默认列布局”单独放在分隔线后。外观和其他右键菜单统一。

日志正文已经能选文字，也有复制入口，不能说它完全缺少复制。以后需要“复制整条记录”或“按此来源筛选”时，再补行菜单，避免覆盖用户选中文字后的正常复制。

### 最近文件

保留“打开或生成”“显示所在目录”，分隔后“从最近记录移除”，不需要二级菜单。卡片和列表都支持同样的操作是合理的。

移除最近记录不等于删除磁盘文件，文案不要混淆。

## 哪些重复该保留，哪些需要改

| 重复出现在哪里 | 判断 |
|---|---|
| 工具栏和画布右键都能调笔刷 | 保留，用户需要就近调整；数值范围和操作结果应一致 |
| 树和画布都能管理参考图 | 保留，是同一个对象的两个工作位置 |
| 树和画布都有网格、创建操作 | 保留入口，统一同名动作；目前部分能力差异需要核对和说明 |
| 素材的树、卡片、列表都有菜单 | 保留，换浏览方式不应丢失功能 |
| 动作行按钮与右键都有编辑、播放 | 保留，高频按钮与完整文字菜单互补 |
| 物理组右键与标题“更多”都有管理动作 | 保留，补齐列表重命名，使两处能力一致 |
| 最近文件可双击打开，也能从菜单打开 | 保留，是正常的快捷与显式入口 |
| 绘制顺序标尺右键短按和双击都能开数值窗口 | 可以保留，前提是短按和拖动区分可靠 |
| 参数名称左键和右键都只打开属性 | 调整，右键应提供更多参数动作 |
| 相同对象在不同位置菜单名称、能力和排列不同 | 统一无必要的差异，必要差异说明原因 |
| 有些菜单的行高、高亮、滚动和开合方式与其他菜单不同 | 统一，用户不应在每个面板重新适应 |

## 哪些地方不必补右键菜单

检查器数值、网格设置、工具详情、物理参数、内部效果表单，继续使用直接编辑和已有重置按钮即可，不必每个字段右击都弹一张对象菜单。输入框原有的复制粘贴也应保留。

设置导航、帮助正文、开始页空白、生成导出配置不必复制建模命令。工具条、视图开关、拖动柄和分隔条应完成自己的点击或拖动，不应把右键传到下面的画布。

预览画布可以考虑增加适配视图、重置视图、播放暂停，但优先级低。它已有直接入口，也不需要编辑画布的建模菜单。

## 菜单内部统一成什么样

**顺序上，先用、再管、最后删。** 对象菜单先放打开、编辑、播放等主要动作，再放重命名、复制、整理，最后才是删除。创建中的完成和取消按任务放在一起，不照搬对象管理顺序。

**二级菜单按任务分组，位置固定。** 创建、网格处理、镜像等可以按任务分组；只有一个有效选项时直接放一级。三四个动作的短菜单不再套层。图集目标页保留平铺，长菜单提供滚动条。子菜单展开方向随窗口空间变化，但不要把一级菜单推走。

**控件要表达真实关系。** 三选一用单选；互不影响的开关用勾选；大小、强度、透明度用滑条并显示数值，需要精确值时允许输入；色块有名称；多选的不同状态要能显示“部分”。菜单不是完整检查器，不把整页表单塞进去。

**操作结束后，焦点回到该去的地方。** 普通动作执行后收起菜单；调透明度或连续勾选时保持菜单；打开重命名框或新窗口时保留输入焦点。动画操作后回时间线，不要所有动作都抢回主画布。

**禁用要说明原因，空菜单不弹。** 忙碌、没有目标、对象不支持、素材仍被引用等情况应有可理解的提示。子菜单全部不能操作时，不应看起来仍能正常使用。

## 建议分三步处理

第一步先核对操作范围：变形器链删除范围、多选菜单实际作用范围、多引用却只定位第一个、右键鼠标命令被菜单抢占。参数控件不同的右键行为、普通网格右击操作当前选择均按现有逻辑保留。

第二步整理现有菜单：优化顶部菜单的信息组织与排列，统一同类菜单样式和位置，整理必要分组。图集保留目标页平铺并完善滚动条，停靠空白处保留“关闭全部”；参考图位置是否收为单选子菜单按实际使用再评估。

第三步补缺失入口：优先是图层表格、参数名称、动画关键帧、动画轨道、骨骼树；之后是历史节点和层级树空白。预览画布、素材路径、日志正文按实际需要再补。

这份说明基于源码阅读。菜单在小窗口、不同语言与缩放、鼠标和键盘操作下的实际表现仍需后续界面验收；本文不将这些建议标为已经完成。
