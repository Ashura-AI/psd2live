# Layout 的 AI 辅助（后续，不在基础 Layout 范围内）

[文档目录](../../README.md) · [素材与 Layout 工作区](MATERIAL_LAYOUT_WORKSPACE.md) · [路线图](../ROADMAP.md)

本页是**设计稿**，尚无实现。它收集 Layout 工作区里依赖外部 AI 生成部件的那一部分：参考系、自动摆放、对比辅助、抠图、部件补全与补全指标、局部修复、绘画拆分。基础 Layout（素材、摆放、语义标签、先摆放后生成）见 [素材与 Layout 工作区](MATERIAL_LAYOUT_WORKSPACE.md)，本页的功能都建立在它之上；基础 Layout 已经实现。

设计依据：外部 AI 辅助建模流程的实测记录（两个全身角色，各 27 与 41 层），以及一次把整个角色全部整部件重新生成的失败尝试（见"部件补全"）。

验证原则沿用基础 Layout：看得见的验证第一，质量检查只提示、不阻止。

## 参考系与头部特写

全身图里的脸太小，实际流程里常另出一张头部高清特写。两者是两个参考系，Layout 应一等支持：

- 一个 Layout 可有多个参考项，每个参考项有自己的显示变换与参考系标签（`FULL_BODY`、`HEAD_CLOSEUP`、`PART`）。
- 头部特写到全身的映射是一个**相似变换**。部件层摆在特写的坐标里，由映射换到画布；映射只在一个地方存一份，改映射就整体带动所有头部层。
- 头部特写是小部件（眼、眉、嘴、铃铛）的像素来源，不只是一个参考：母版上这些部件只有几十像素，特写里则有数百。部件的位置与颜色以母版为准，像素以特写为准，对齐在母版分辨率下评估（见"像素来源按部件大小分档"）。
- 这个映射的旋转应接近 0。实测中一张本身偏 1.7° 的特写，被配准带入 3° 旋转后眼线倾斜到 -4.7°，成品"脸歪"。所以映射的求解默认把旋转锁为 0，需要旋转时明确打开，并显示结果眼线角。

## 自动摆放

目标：把一个部件摆到参考图上正确的位置与大小。实测的核心困难是生成工具每次都按自己的尺度重绘：偏移十到数十像素，缩放约 0.6 到 1.4 倍。已被证明有效的手段是 SIFT 配合相似变换求解、带缩放搜索的 ECC、借用配对部件的变换、地标、镜像；也证明了数值指标会互相矛盾，必须靠叠图复核。下面在此基础上改进。

### 评分：只在"本层可见"的像素上比较

自动摆放的目标函数不应拿整层去比整张参考，因为部件的一部分被别的层遮住或是补画出来的（参考里根本没有）。

- 令 `V(p)` = 摆放后本层在布局合成中处于最上方可见的像素集合（由层序与其他层的 alpha 算出），再排除用户标记的"补画区域"。
- 评分 = 在 `V(p)` 内，本层颜色与参考颜色的稳健差（Charbonnier 或截断 L1，Lab 空间），加上本层边缘与参考边缘的距离变换项。
- 这样同一个函数既可作为优化目标，也可作为之后的验收指标和可视化热力图，不会出现"对齐置信度很高但叠图看错位"。

### 分阶段求解

1. **粗配准**：在 alpha 轮廓与边缘图上做傅里叶-梅林（对数极坐标相位相关），一次给出尺度、旋转、平移的候选，不依赖纹理。动漫图纹理少、大面积平涂，纹理特征点常常不够；轮廓与线稿更稳定。
2. **特征点**：纹理足够时（点数、内点数达标）用 SIFT / AKAZE 加 RANSAC 求相似变换，替代粗配准的结果。
3. **精配准**：在评分函数上做由粗到细的优化，例如 Powell 或 CMA-ES，自由度为平移、旋转、等比缩放，可选两轴缩放；先在低分辨率金字塔上求解，再逐级细化。每级只在上一级结果附近搜索，避免跑偏。
4. **可选学习式匹配**：LoFTR 一类稠密匹配可作为插件，不作为必需依赖。

### 配对与对称约束

- 配对部件（眼白、虹膜、睫毛、眉、耳、腿、鞋）联合求解：共享一个中线，左右变换满足镜像关系加小的残差；单边不可靠时（眼白、眉毛在实测中独立对不准）借用同侧可靠部件的变换。
- 对称轴是 Layout 的一等对象：可以由两只虹膜中心或脸底层的轮廓估计，并显示参考线。眼睛整体偏离中线 12 px 这类问题一眼可见。
- 镜像摆放：姿势不对的一侧可用另一侧镜像，镜像后按评分只微调平移，不改缩放。

### 置信度与失败路径

- 输出的不是单个数字，而是：最优评分、次优候选与最优的比值（可区分度）、评分曲面在最优点附近的曲率（沿哪个自由度不确定）。
- 低可区分度时，在界面里展示多个候选让用户选，而不是静默采用第一名。
- 评分与曲率条件不满足时直接报告"不可靠"并回到手动模式，不输出猜测值。
- 所有自动摆放结果都是一次可撤销的编辑，叠加热力图默认打开一次。

### 地标模式

选两三个点（例如下巴、两侧脸颊）做横纵不同比例的缩放，脸底层常用。地标可以吸附到轮廓上的曲率极值点，减少手点误差。

## 对比辅助

Layout 里的参考图与部件都可单独调整显示，用于人看和给 AI 看：

- **不透明度**与**单色模式**：把参考染成一个色（如青）、部件染成互补色（如红）后叠加，重合处变中性、错位处显出彩边。单色模式可选取"亮度"或"线稿"（先提取边缘），后者更适合比较线条位置。
- **差值**、**卷帘**（左右滑动分隔线）、**闪烁**（两帧快速切换）、**轮廓线**模式。
- **误差热力图**：前述评分在 `V(p)` 上的逐像素稳健差。
- **一键导出对比图**：参考 / 合成 / 差值并排，带坐标网格与编号标注的层包围盒，可直接附给 AI；对比图的内容完全由捕获的 Layout 版本渲染，不读实时 GUI 状态。
- **度量**：眼线角、两耳高度差、两侧部件对称轴偏移、头身比例，超出阈值给出提示（见发送前检查）。

## 抠图与边缘处理

### 背景用白色，不再默认绿色

实测流程用纯绿底生成再色键。改用白底更好：

- 生成工具对白底最稳，母版本身就是白底，部件图与母版的色调更一致；绿底会让工具把绿色混入发丝、半透明阴影与高光。
- 绿色必须做去溢色，且无法保留真正是绿色的内容（绿瞳、绿衣）。
- 白底的缺点是前景本身有白色（白发、白袖、白纱），与背景难以区分。解决办法见下面的"背景可选 + 连通判别"，而不是回到固定的绿色。

### 白底抠图管线

目标：得到直通 alpha（straight alpha）与去污染的前景色。

1. **确定背景**：从图像边框做泛洪，选取与背景色足够接近、且与边框连通的像素为确定背景。前景内部的白色（白发、白袖）若不与边框连通，就不会被误判为背景。
2. **确定前景**：对非背景区域做腐蚀；用户可涂抹加入或排除，应对白色前景直接接触边框、或白色区域由细线隔开的情形。
3. **未知带**：背景与前景之间的窄带。
4. **前景颜色估计**：对未知带像素，从邻近的确定前景估计前景色 `F`（多级前景估计或邻域加权，保证不引入背景色）。
5. **alpha 求解**：已知背景色 `B` 时，观测 `C = αF + (1−α)B`，则 `α = ((C−B)·(F−B)) / |F−B|²`，截断到 [0, 1]。`F` 与 `B` 接近时分母趋零，这类像素按连通判别与邻域平滑决定，不用公式。
6. **可选闭式抠图**：未知带宽、发丝多时，用闭式（Levin）或其近似求解，三值图由上面几步给出，不要求用户画三值图。
7. **颜色去污染**：未知带内输出颜色取估计的 `F`，不保留与背景混合的颜色。这是去掉白边的关键。
8. **小连通块**：面积小于阈值的残留块删除（同类缺陷实测过：3% 到 10% 的低透明度噪点会让导入把整个包围盒当成网格）。阈值与 alpha 阈值在预览里直接显示，被丢弃的像素以半透明红叠加。

### 背景色选择

生成任务包可选背景色。默认白；当部件以白色为主（白发、白袖、白纱）时，建议改用与部件最远的颜色：统计部件颜色，在候选色里取"与所有前景色距离的最小值最大"的那个，在导出任务包时提示。此时抠图管线步骤 1 的背景色取该色，其余不变。

### 双背景精确抠图（可选）

对同一个部件，若能取得白底与另一底色（如黑底）两版**像素对齐**的图，则 `α = 1 − |C_w − C_b| / |B_w − B_b|`，前景色可闭式还原。外部生成工具给不出像素对齐的两版时，这条路用不上；它只用于程序自己合成的素材（例如由 PSD 子层合成对比）。作为可选模块，不是主路径。

### 边缘处理

- 收缩 / 扩张（亚像素），羽化（高斯，半径以像素的小数计）。
- 去色边：按估计前景色重染边缘，而不是整体压暗。
- 光晕（halo）检测：边缘外圈亮度与背景差在阈值内但与前景差大，提示。
- 线稿保护：线稿像素的 alpha 不被羽化冲淡。
- 半透明素材（腮红、阴影）不走抠图：以白底出图，用"正片叠底"层导入，记录在 `Placement.blend`。

## 部件补全

**补全是必须的。** 一个部件如果只是和原画严格匹配而没有补出被遮挡的部分，对 Rig 是严重错误：转头、摆动、隐藏上层时会露底。所以评价补全结果的第一位是"补了多少"，其次才是"和原画有多像"。

### 一次失败的尝试（已撤回的结论）

本页早先的版本把"让外部 AI 一次性画出整个部件"定为所有部件的主路径，依据是同一角色里手臂一次成功、腿用遮罩补画反复失败。随后用外部 AI 把一个全身角色的 40 多个部件全部这样重新生成、对齐并拼合，结果**单个部件基本可用，拼合后的整体明显不如"保留母版可见像素、只补被遮挡部分"的做法**：

- 逐部件各自重新设计，偏差累积：腿变细、靴子变窄、尾巴变瘦、表情变了、腰带细节丢失；袖子变短后，原本挂在袖摆下的挂饰悬在半空。
- 两腿之间出现竖缝；`coverage` 报告参考前景有 11.7% 没被任何层覆盖，最大的缺口在两腿之间、袖摆下与尾巴旁。
- 所有部件仍在母版分辨率上，小部件的像素不足没有解决。

教训：

1. 手臂能成功，是因为它是单一材质的凸管，被遮的部分在袖口之下，接缝与截断都看不见。这个结论不能推广到细节丰富、边界长而复杂的部件（裙、袖、尾巴、头发、靴、头饰）。
2. 重新生成会改变设计。它适合"可见部分本来就少"的部件，不适合"可见部分细节丰富"的部件：后者的母版像素本身就是最好的参考，重画只会引入偏差。
3. 此前"遮罩补画失败"的原因是遮罩形状（又长又不规则，边界落在仍然可见的地方，混着多种材质、投影和勒痕），不是"保留可见像素"这个思路本身。把接缝放在上层图层之下，可以避开这个问题（见下）。
4. 数值验收（逐像素一致率）和观感验收是两件事。无论哪条路径，最终都要看拼合后的整体图。

### 修正后的原则

1. **母版负责位置与颜色，不负责清晰度。** 部件的像素来自它所需分辨率的来源，母版只作对齐与颜色的依据。
2. **能保留母版的可见像素就保留**，只补被遮挡的延伸部分（混合部件，见下）。这样整体与母版一致，偏差只出现在看不见的区域。
3. **整部件替换只用于**原画可见部分很少，或形状简单、被遮挡为主的部件：手臂皮肤、脖子、大腿肤色、后发、母版里完全看不见的部件。是否可以替换，看它与母版的 `overlap_fidelity` 和拼合后的整体图；偏差明显时退回混合部件。
4. **局部修复**仍只用于小缺陷。
5. 任何一条路径的产出，都要在拼合后的整体图上与母版逐区域对照。

### 像素来源按部件大小分档

母版上该部件的大小决定像素从哪里来（数值是起点，需要标定）：

| 母版上的大小 | 例子 | 像素来源 | 理由 |
| --- | --- | --- | --- |
| 较大，约 150 px 以上 | 裙、袖、尾巴、后发、腿、靴 | 母版像素经 2× 超分（工程已有的[纹理高清化](../guide/TEXTURE_UPSCALE.md)，或同类模型） | 线条与色块清楚，超分只补细节，不改设计 |
| 中等，约 60 到 150 px | 前发、耳、头饰、手 | 基于母版同一区域生成的高清特写，对齐回母版 | 超分在这个尺寸开始编造细节，边缘会变形 |
| 很小，约 60 px 以下 | 眼、虹膜、眉、嘴、铃铛、流苏 | 头部高清特写 | 母版里没有足够信息；超分只会重画一个新的 |

- 高清来源只负责细节。对齐与保真度在**母版分辨率**下比较：把高清候选缩到母版尺度再比，"更清晰但位置没变"才算合格。
- 摆放的缩放只是排布大小，高清来源的像素原样保留（见"核心价值"）。
- 超分与重新生成都是补细节，不是还原；验收标准是风格一致、位置对，不是像素一致。
- 没有可用的超分模型时明确报错，不用普通插值冒充。

### 混合部件：可见像素 + 延伸

对细节丰富的部件，图层 = 可见部分的像素来源 + 延伸部分 `E`：

- `E` 取自整部件生成的结果（对齐后），只取"原画轮廓之外、位于上层图层之下或其附近"的像素。
- 可见与延伸的**交界故意落在上层图层的边缘之下**：原画抠图沿被遮挡的边界多往上层下面延伸几像素，`E` 从那里开始。静止姿态下交界被上层盖住，只有上层移动时才会露出来。
- 先对 `E` 做低频颜色匹配（只校正整体偏色，保留生成图自己的细节），再在 `E` 一侧的窄带里羽化，不在可见区域里做任何改动。
- 延伸区域的风格一致性由 `style_drift` 与 `seam_score` 提示去看，不由数字放行。
- 交界之外仍然可见的边界（例如两腿相贴处、袜口）不属于这种做法的适用范围，这类部件应整体评估是否改用整部件替换或局部修复。

### 部件的拆分方式

任务按**语义与材质**拆分，而不是按遮挡区域拆分：

- 腿：肤色大腿 / 丝袜 / 吊袜带与挂饰 / 靴，各是一个部件。一次生成内不要混多种材质。
- 成对部件每个任务只含一侧，另一侧不入画。左右对称的可用一侧镜像，再微调。
- 参考用带上下文的整图或较大的裁切，让模型理解部件在人物中的位置；要求输出里只有该部件、纯白背景。
- 上层对它的影响（投影、勒痕）不应出现在部件里，提示词明确要求。

### 任务包

对每个部件任务生成一个目录：参考图（原画，含上下文）、`part.json`（部件、侧别、槽位、画布尺寸、背景色、策略）、提示词模板（补到根部、自然收口、无投影）、可选的"原画抠图"素材。外部处理后导回一张图。

一种待验证的变体"完成式"：主参考不是整图，而是只含该部件、被遮挡处残缺的原画抠图，整图仅作上下文，提示词要求保持可见部分的姿势、比例不变，只补残缺的一端。它仍是一次生成、没有回贴，但可见部分的比例由输入锚定。是否比整图参考更稳，尚无实测结论。

### 导回

1. 白底抠图（见"抠图与边缘处理"）。
2. 自动摆放到原画上（评分只在可见重叠区进行，见"自动摆放"）。允许比原画更好：对齐只用相似变换，不强行把新图的轮廓拉到原画上；比例漂移严重（`overlap_fidelity` 低、轮廓距离大）时视为该结果不可用，重做，不硬采用。
3. 按部件的策略入库：整部件替换，或取 `E` 做混合部件。
4. 作为衍生素材入库，与原画抠图建立 `PartPair`。

### 两项指标

对一个 `PartPair`（原画抠图 `O`、新图层 `N`，均已摆放到同一画布坐标）计算，作为 MCP 与 GUI 共用的读取操作返回。

**重叠区域：原画重合度 `overlap_fidelity`**，范围 0 到 1。衡量新图层在原画可见区域上与原画有多接近。

- 逐像素相似度 `s(p) = exp(−ΔE(p)/ΔE₀)`：`ΔE` 在 Lab 空间，比较前对两者做同样的小半径模糊，并在 ±2 px 内取最近邻，避免亚像素偏移被重罚；线稿像素按边缘距离额外比较。
- `overlap_fidelity = Σ min(αO, αN)·s / Σ αO`。同时返回分量 `coverage = Σ min(αO, αN) / Σ αO`（原画可见部分被新图层覆盖了多少）与 `color_similarity`。
- 不是越接近 1 越好：原画本身有缺陷（线条抖动、色块、残留的投影）需要修复时，降到约 0.7 可能更好。所以它只是参考，不阻止任何操作；是否接受由看图决定，用户或 Agent 可设自己的提示下限。

**新图层总体积：原画 `completion_ratio`**，须大于 1。

- `completion_ratio = Σ αN / Σ αO`（二维下"体积"即 alpha 质量）。
- 部件有被遮挡的部分时，补全后必须大于 1；接近 1 说明只是在复述原画，没有补全。
- 不是每个部件都应该超过 1：完全没有被遮挡的部件（例如孤立的饰品）可以等于 1。用 `hidden_boundary_fraction` 判断：原画抠图轮廓中，紧贴上层图层边缘（而不是紧贴真背景）的比例。比例高而 `completion_ratio ≈ 1`，给出 `NOT_COMPLETED` 提示（最醒目的一条），并附上原画轮廓中贴着上层的位置图，由人看图确认是否真的需要补。部件可显式声明 `fully_visible` 豁免。

配套的诊断（同一操作返回）：

- `hidden_gain`：新增面积中落在上层图层之下的部分，占 `Σ αO` 的比例，是合理的补全。
- `visible_spill`：新增面积中**没有**被上层覆盖、因此会改变合成观感的部分。大于零时合成图与原画不同，需要确认是修复还是漂移。
- `composite_fidelity`：用新图层替换原画抠图后，整体合成与参考的相似度。部件之间没有露底、没有风格割裂时接近 1。
- `style_drift`：新增区域与原画区域在风格统计上的距离（调色盘分布、边缘梯度直方图、线宽分布，可选图像嵌入的余弦距离）。新图层可以比原画更好，但风格不能迁移，这项用来提示去看。
- `seam_score`：新增区域与原画区域交界处的颜色与梯度突变。

返回结构（`resultSchema` 严格声明）：

```
{ pair_id, overlap_fidelity, coverage, color_similarity,
  completion_ratio, hidden_boundary_fraction, hidden_gain, visible_spill,
  composite_fidelity, style_drift, seam_score,
  flags: [ { rule, level, detail, evidence? } ],
  images: { compare_sheet, overlay, heat, ... } }
```

`flags` 的 `rule` 与等级由规则枚举确定（见"发送前提示"），不由本地化文本推断；`evidence` 指向可以直接看的图与位置。`images` 与数字一同返回，Agent 应当先看图再解读数字。

### 局部修复（遮罩补画）

仍保留，用于小范围缺陷：一个接缝、一块污点、一小块露底。流程是任务包（背景色底 + 可见像素 + 保留色遮罩）→ 外部处理 → 导回，遮罩外像素不被改动，遮罩内取生成像素，窄带边界融合。它是硬约束的局部工具，不用于补出整个部件。导回前先在遮罩外区域标定配准，并校验遮罩外是否被改动、遮罩内是否残留保留色。

**不在遮罩内做模糊或取色填充冒充生成**：外部工具有时会这样交付，所以导回只信图像生成的像素，必要时取其中间轮次的原始生成图。

## 绘画与拆分

继续使用[绘画系统](PAINT_SYSTEM_ARCHITECTURE_AND_PRD.md)的栅格引擎与会话，工具增加：

- 选区：套索 / 魔棒（带容差与连通）/ 矩形，加减与羽化。
- 克隆、涂抹、修复笔，用于人工细节修复。
- 对称绘画：沿 Layout 对称轴镜像笔画。
- 图层拆分：
  - 按 alpha 列最小处拆成左右两半（成对部件）。
  - 按连通块拆分。
  - 沿手绘线拆分。
  - 拆出的子层各自成为衍生素材，保留与原素材的关系。
- 合并与整理：合并若干层为一个素材，保留原图以便还原。
