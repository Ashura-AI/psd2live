# 菜单与层级节点交互约定

本页描述菜单及对象转换的共享交互。颜色、尺寸和动效的跨界面要求仍以 [CLAUDE.md](../../../CLAUDE.md) 为准。

现有右键菜单的入口、内容顺序、重复与缺口，以及后续整理建议见 [右键菜单盘点](CONTEXT_MENU_AUDIT.md)；该盘点区分源码现状与待实现方案，不替代本页交互约定。

## 菜单

- 画布及层级树的右键菜单用 `PressMenu`，内容用 `GlidingColumn`、`FloatingMenuSection` 与 `FloatingMenuRow`。ArtMesh、参考图及变形器使用相同宽度、行高、高亮和滚动机制。
- 成组菜单只有一条滑动高亮。危险动作通过共享行的 `danger` 标记呈现；列容器同时收到危险行及可用性信息，统一文字、图标和悬停背景。禁用行不响应，也不保留高亮。
- 普通动作先收起菜单、执行操作，再把焦点交回画布。打开对话框或编辑窗口的动作标为 `opensDialog`，执行后保留该窗口的焦点。`keepsMenu` 动作保留菜单与键盘焦点。
- 位置不足时一级菜单及二级菜单向可用方向展开；不得为显示二级菜单移动一级菜单。
- 对象菜单在名称下说明作用范围：多选时写明“仅作用于本项 · 已选 N 项”；改变内容的动作按实际范围命名（当前对象、整条链、此图层），不能只写含义模糊的“删除”。
- 参数名称左键打开属性，右键提供参数管理菜单（属性、重置当前值、锁定/解锁、复制参数、复制参数 ID、删除参数…）；删除与复制复用属性对话框的确认流程，不在菜单里直接执行。
- 右键优先级统一为：控件已消费 → 当前手势/鼠标绑定 → 上下文菜单；主画布与图集一致，打开菜单不改变选择或姿态。

## 层级节点

层内参考图与 ArtMesh 都通过 `DrawableTreeItem` 渲染，只替换类型图标与专属标记。两者共享：

- 单击、Ctrl/Cmd 切换选择、Shift 范围选择、Alt 取消选择。
- 悬停反馈、预览定位、祖先连线、拖放登记与父节点变更。
- 按图层 ID 选中、按实际 Rig 对象 ID 修改层级；二者不得混淆。

前景及背景参考图没有 Rig 父节点，使用独立的参考图节点。它们与模型选取仍保持互斥。

## 参考图与 ArtMesh 转换

- 单项入口位于对象名下第一行，使用目标类型的图标及“转换为参考图 / 转换为 ArtMesh”文案。工具栏、画布和层级树读取同一份转换可用性。
- 工具栏对批量转换显示目标和数量；全部为参考图时转换成 ArtMesh，否则转换成参考图。包含任何不可转换项时禁用整个操作，避免静默修改部分选择。
- 上下移层与类型转换分别判断可用性。已生成的用户创建网格可以转换，即使它不能作为待生成图层上下移动。
- 类型徽标只表示状态，不执行隐藏的转换；快捷键名称表达双向切换，按钮文字表达这一次的目标。
- 一次转换只提交一个历史节点，保持原对象的选择；不因显示类型变化丢失其对象 ID。

## 回归入口

`ReferenceHierarchyInteractionTest` 覆盖节点选取、悬停、拖放及历史/保存恢复，`ReferenceConversionMenuTest` 覆盖单项和批量转换，`MenuActionsTest` 覆盖焦点生命周期，`MenuDangerStyleTest` 覆盖危险及禁用状态，`ContextMenuScopeTest` 覆盖层级删除范围与素材定位行的选择。`UiConsistencyTool` 使用合成内容输出明暗主题及界面/字体缩放截图。
