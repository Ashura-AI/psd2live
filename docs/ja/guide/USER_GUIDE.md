# 操作早見表

[ドキュメント一覧](../../README.md) · [中文](../../zh/guide/USER_GUIDE.md) · [English](../../en/guide/USER_GUIDE.md)

まず `F1` でヘルプページの **チュートリアル** を開いてください。対話型チュートリアルは操作箇所を強調し、関連パネルに切り替え、現在のキー設定で操作を案内します。このページはその文字版で、振り返り用です。ボタンを一つずつ説明するものではありません。

## 基本の流れ

PSD をインポート（`Ctrl+Shift+O`）→ 分類とプレビューを確認 → 編集 → 保存（`Ctrl+S`）→ 書き出し（`Ctrl+G`）。既存の `.psd2live` は `Ctrl+O` で開きます。

既存の Cubism モデルは **ファイル → 新規作成 → CMO3 から新規プロジェクト…** または **モデル → CMO3 で現在のモデルを置き換え…** から開きます。**CMO3 で現在のモデルを置き換え…** はファイル内のオブジェクトを ID で置き換えて新しいオブジェクトを追加し、ファイルにない内容は残します。**CMO3 から新規プロジェクト…** は現在のモデルを消してから読み込み、モデルの内容はその CMO3 だけになります。どちらもプリセットを自動生成せず、読み込んだパラメータ、キーフォーム、デフォーマ、テクスチャ、物理演算はプロジェクトに保存できます。

## スタート・ヘルプ・設定ページ

ワークスペースタブの先頭にはアプリ自身のページ **スタート**、**ヘルプ**、**設定** があります。プロジェクトには保存されず、ダイアログでもありません。ページ上のパネルはエディターと同じように、見出しをドラッグしてドッキングし直したり、タブとしてまとめたり、フローティングウィンドウにしたり、閉じたりできます。閉じたパネルは **ウィンドウ** メニューから再び開け、メニュー末尾の **レイアウトをリセット** で既定の配置に戻ります。ページの配置はローカルの設定に保存され、次回起動時も保たれます。

**スタート** は起動時に表示され、プロジェクトを開く・読み込む・新規作成するとそのワークスペースへ切り替わり、「スタート」タブは折りたたまれます。**ファイル → スタートページ** か、空のキャンバスの **スタートへ** で再び開けます。3 つのページは同じ構成で、左に目次、中央に選んだ内容があります。スタートページには右に詳細パネルもあり、操作で何が起こるかを示します。内容パネルの見出しは選んだ項目名になり、スタートページでは下の操作バーの主ボタンを `Enter` でも実行できます。目次は ↑ / ↓ で切り替えられます。

- **PSD から生成**：詳細パネル上部でプリセット（最小 / 標準 / フル）を選び、必要なら項目ごとに調整してから、PSD をウィンドウのどこかへドロップするか、ビューポートまたは **生成…** を押してファイルを選びます。生成後は編集ワークスペースが開きます。ビューポート下の **最近の PSD** では、クリックでビューポートにプレビューし、ダブルクリック（またはプレビュー後に **生成**）で現在のプリセットで生成します。サムネイルの大きさは変えられます。プリセットは記憶され、メニュー・最近使ったファイル・ドロップから読み込んだ PSD にも使われます。**生成** ボタンのメニューでプリセットを切り替えたり、**現在のモデルに適用** したりできます。1 枚に描かれた左右のパーツは **モデル → メッシュごとにレイヤーを分割…** で分けます。
- **レイアウトプロジェクト**：キャンバスのプレビューとサイズ設定は 1 つのパネルにまとまっています。左に縮尺どおりのプレビュー、右によく使うサイズ（ダブルクリックで作成）と幅・高さの入力があり、どのサイズにも当てはまらないときは「カスタム」と表示されます。**レイアウトプロジェクトを作成** を押すか `Enter` で作成します。詳細パネルでは取り込み・配置・生成の 3 ステップとキャンバス単位の意味を説明します。
- **CMO3 から読み込み**：現在のモデルを消して Cubism モデルから新規作成します。詳細パネルには取り込み後に残る内容が表示され、モデルを開いているときは **CMO3 で置き換え…** で現在のモデルのオブジェクトを ID で置き換えられます。
- **最近**：スタートページを開いたときの場所です（最近のファイルがまだないときは「PSD から生成」を開きます）。素材パネルと同じように最近のプロジェクトと PSD をグリッドまたはリストで表示し、検索、種類の絞り込み、サムネイル、更新日時、サイズを表示します。プロジェクトのサムネイルは保存時に書き込まれ、PSD は埋め込みサムネイルか合成画像を使います。ダブルクリックで開き、詳細パネルからフォルダーを開いたり一覧から削除したりできます。
- **新機能**：バージョンごとの更新内容を文章で読めます。詳細パネルにバージョン一覧があり、クリックで移動します。対話型チュートリアルがある項目からはチュートリアルを開け、**すべての更新履歴** でリリースページを開きます。

タイトルバーのメニューは **ファイル**・**表示**・**モデル**・**ヘルプ** です。**モデル** にはモデル全体に作用する操作（PSD の再解析、CMO3 での置き換え、メッシュごとのレイヤー分割、テクスチャ高解像度化、生成結果の更新）があり、**ヘルプ** メニューの **ヘルプ** でヘルプページを、**オンライン** で GitHub リポジトリ・ドキュメント・サンプルリポジトリ・リリース・不具合の報告を開きます。タイトルバー右側にはサイドバーの切り替え、言語、明暗テーマ、**設定**（歯車）が並びます。

**ヘルプ**（`F1`、もう一度押すとワークスペースに戻る）の目次はチュートリアル、レイヤー仕様、ショートカット（絞り込み可）、サンプル、コミュニティ・リンク、サードパーティのライセンス、概要です。**設定**（`Ctrl+,`）の目次は拡大縮小と表示、テーマ、言語、キャンバス操作、確認ダイアログ、ショートカット、ファイルとデータ、MCP で、変更はすぐに反映されます（MCP のポートやトークンなどは **適用して再起動** が必要）。「ファイルとデータ」では最近使ったファイルの消去、前回の書き出し先を開くこと、インストール先・ワークスペース・ランタイム・高解像度化キャッシュ・エラーログ・コマンドライン MCP の場所とサイズの確認、高解像度化キャッシュとログの消去、以前の異常終了でシステムの一時フォルダーに残ったファイルの消去ができ、設定の保存先も表示されます。「MCP」は以前の **ツール → MCP…** ダイアログの内容です。**ファイル → フォルダーを開く** でプロジェクト・元ファイル・出力のフォルダーと、ワークスペースの保存先、アプリのデータのフォルダーを開けます。「拡大縮小と表示」ではディスプレイに合わせた推奨拡大率をワンクリックで使え、解像度とシステムの拡大率も表示されます。目次の下の **デフォルトに戻す** ですべての設定をリセットします。ヘルプと設定のタブには、ホバー中か表示中に閉じるボタンが出ます。

プロジェクトがないとき、ほかのワークスペースのキャンバスにはヒントと **スタートへ** だけが表示されます。

## ワークスペース

画面は上部のワークスペースタブで構成され、タブごとにキャンバスとパネルの配置を持ちます。タブバー右端の **+** から、八つのプリセットまたは空白レイアウトで新規作成できます。右側にレイアウトと用途のプレビューが表示されます（スクリーンショットは中国語 UI）。

![新規ワークスペースメニュー](../../imgs/workspace-presets.webp)

| プリセット | 用途 |
| --- | --- |
| 編集 | 一枚の編集キャンバスでデフォーマ、キーフォーム、ボーンを扱う。プロパティパネルがそろう |
| メッシュ | 階層ツリー、編集キャンバス、メッシュパネルでトポロジーを編集 |
| リギング | 編集キャンバスとライブプレビューを並べ、パラメータパネルを常時表示 |
| アニメーション | モーション一覧、プレビューキャンバス、アニメーションエディタ |
| プレビュー | 大きなプレビューとモーション一覧のみ |
| 物理演算 | プレビューキャンバスとパラメータ・物理パネル。モデルを動かしながら調整 |
| テクスチャ | アトラスのページ、編集キャンバス、テクスチャパネル。各レイヤーのピクセルサイズを確認・調整 |
| 履歴 | 履歴ツリーと操作リストのみ。履歴の閲覧と切り替え |
| 空白 | 空のドック。**ウィンドウ** メニューから必要なキャンバスとパネルを追加 |

**レイアウトをリセット** で現在のワークスペースをプリセットの配置に戻します。

### テクスチャワークスペース

各レイヤーには三つのサイズがあります。キャンバス上で覆う矩形（キャンバス単位）、レイヤー自身のラスターのピクセル、テクスチャアトラス内のタイルのピクセルです。「テクスチャ」ワークスペースはこれらを並べて表示し、レイヤーごとに調整します。

- **アトラス**（左）：ページ画像がビュー全体に表示され、編集キャンバスと同じ操作で扱えます。ホイールでズーム、中ボタンまたは Space + ドラッグでパン、`F` で選択範囲にフォーカス、`Home` / `0` でページ全体を表示、`Ctrl+A` でページのタイルをすべて選択します。タイルをクリックするとそのレイヤーを選択し、空白をドラッグすると矩形選択になります（Shift で追加、Alt で除外。編集キャンバスと同じ）。選択はキャンバスやレイヤー一覧と同期します。**タイルをドラッグ** するとピクセルがポインターに合わせてリアルタイムに動き、離すとその位置に置かれます。他のタイルのメッシュ（矩形ではなくメッシュが実際に使うセル）と重なる位置やページ外では移動せず、タイルは赤く表示されます。選択タイルには編集キャンバスと同じ変形ボックスが付きます。上辺の外にある **丸いハンドル**、またはホバーで矢印付きの弧が現れる角の外側をドラッグすると、**アンカー** を軸に任意の角度で回転します（Shift で 15° 刻み）。回転後もメッシュで重なりを判定します。アンカー（円付きの十字）は最初タイルの中心にあり、ドラッグで自由に動かせ、中心・角・辺の中点に吸着します。移動・拡大縮小・回転は描画モードと同じ **編集セッション** で、ページ上の表示だけを変えてモデルを再構築しないため常に滑らかです。変更があるとページ上部中央にセッションバー（ペイントモードと同じバー）が下りてきて変更タイル数を示し、元に戻す／やり直し（Ctrl+Z / Ctrl+Shift+Z）、破棄、**適用**（Enter）ができ、適用するとすべての変更が 1 ステップ（再構築 1 回、履歴 1 件）でコミットされます。ビューが狭いときはボタンがアイコンだけになり、ホバーで名前が出ます。セッション中は配置、自動配置、予算、ロック、画像の置き換えは使えません。**選択タイルの角をドラッグ** すると、対角までの距離に応じて密度を変更し、段階なく連続的に変わり、つかんだ角の対角（Alt を押すとアンカー）は動かず、ドラッグ中は新しいサイズで表示します。複数選択では他のレイヤーも同じ比率で変わり、離すとセッションに入ります。拡大して他のタイルのメッシュと重なると赤く表示され、離しても適用されません。移動も吸着せずポインターに追従します。テクスチャパネルの密度スライダーをドラッグしたときも、ページとサイズカードに新しいサイズがリアルタイムに表示されます。タイルをダブルクリックするとフォーカスします。タイルを右クリックすると密度の 2 倍・半分・リセット、90° 回転・回転のリセット、複数ページではページ N への移動（そのページの左上から、他のタイルのメッシュと重ならない最初の空きへ置き、セッションに入ります。空きがなければ拒否して通知）、サイズのロック／ロック解除（選択の一部がロック済みのときは件数を示し、残りをロック）、選択タイルの配置、画像の置き換えができ、空白を右クリックするとすべてのタイルの配置、このページの PNG 保存（書き出しと同じバイト列）、全選択、ページ全体の表示ができます。セッションに変更があるときは、メニューの先頭に先に適用か破棄が必要なことを表示します。ページ番号のツールチップにはページのサイズ、タイル数、使用率が表示されます。左上には編集キャンバスのモードバーと同じフローティングバーがあり、一度だけ配置して結果を保つ **配置** ボタン（隣のドロップダウンには配置オプションだけがあり、配置方法をメッシュ形状（既定。メッシュが実際に覆う領域でタイルを入れ子にし、最もコンパクト）か矩形から選び、範囲を「すべてのタイル」か「選択タイルのみ」から選びます）、**自動配置** ボタン（押すとオンになって点灯し、もう一度押すとオフ。オンでは変更のたびに矩形（MaxRects）で再配置、オフ（新規プロジェクトの既定）では現在の配置を保ち、新しいレイヤーと元の位置に収まらないタイルは黙って空き領域に置かれます。置かれた位置は保たれ、他のタイルを移動・縮小して空いた場所に後続のタイルが詰められることはありません）、複数ページではページ番号が並びます。右上はアトラス予算（ページサイズ 1024–16384、最大ページ数、余白）です。右下は編集キャンバスと同じ表示バーで、ホバーで展開します：テクスチャ、メッシュのワイヤーフレーム、枠線、**密度ヒートマップ**（既定はオフ。キャンバス単位あたりのアトラスピクセル。1 未満は青、約 1 は緑、1 超はオレンジ、凡例は ¼–4）、左下のステータスはポインター下またはドラッグ中のタイル、それ以外はフィットと占有率を表示します。フィットが 100% 未満なら予算に収まらず、ロックされていないタイルがまとめて縮小されます。その説明はログパネルにのみ記録されます。削除したレイヤー（分割前の元レイヤーを含む）はアトラスを占有せず、表示もされません。
- **テクスチャパネル**（右）：「キャンバス → 元画像 → アトラス」の三つの枠で、選択レイヤーのキャンバス矩形、元画像のピクセル、タイルサイズを示し、実効密度をヒートスケール上に表示します。**テクスチャ密度** のスライダーと ½× / 2× / リセットで倍率（元画像 1 ピクセルあたりのアトラスピクセル、1/64–16、複数選択に一括適用）を変更し、**サイズをロック** はアトラス縮小時もサイズを保ちます。単一選択では **回転** にタイルの角度を入力でき（**まっすぐに** で 0 に戻す）、ページ上での回転と同じくセッションに入ります。**画像を置き換え…** は任意の解像度でピクセルを置き換え、キャンバス上の矩形を保ちます（引き伸ばし／全体を収める、メッシュ再構築は任意）。**テクスチャ高解像度化…** はプロジェクトの高解像度化設定を開きます。キャンバス矩形の数値は **キャンバス矩形の数値** に折りたたまれています。何も選択していないときはアトラスの概要（ページごとのサイズ・タイル数・使用率、空き領域、ページが使う VRAM（RGBA）、ロック数、フィットとその意味）と予算を表示します。予算もセッションの適用または破棄を待ちます。書き出し画面はアトラスの概要だけを表示し、テクスチャワークスペースへ移動できます。アルファ閾値はメッシュパネルの全体設定に移りました。
- **元画像のピクセルのプレビュー**：編集キャンバス右下の表示バーの **元画像のピクセル** をオンにすると、そのキャンバスはアトラスのタイルではなく各レイヤー自身のラスターを描画し、パック後の鮮明さと比較できます。キャンバスごとに保存され、オンの間そのキャンバスはソフトウェア描画になります。プレビューキャンバス（Cubism または PSD2Live ランタイム）と書き出しは常にアトラスのピクセルを使います。

作者の編集、バインド、実体化されたメッシュを持つレイヤーでは、キャンバス矩形の移動やメッシュ再構築を伴う画像置き換えは拒否され、理由がアトラスページ上部に表示されます。変更はそれぞれ一つの履歴ノードになり、元に戻せます。対応する Agent 操作は中国語の [MCP_AUTHORING.md](../../zh/agent/MCP_AUTHORING.md#纹理与纹理集) を参照してください。

## 対話型チュートリアルで学ぶ

カタログは全 20 テーマで、初心者コースは下記の 19 講座です。Cubism 経験者コースは用語対応の章から始まり、一部の入門講座を省略します。「基本フロー」以外の講座は、モデルが開かれていなければ最初に PSD の読み込みかプロジェクトを開くよう求めます。

| 講座 | テーマ | 要点 |
| --- | --- | --- |
| 1 | 基本フロー | レイヤー分けした PSD を読み込み、パーツとモデルプリセットを確認して書き出す。テクスチャアトラスは書き出し画面で設定する。 |
| 2 | ワークスペース | 編集・プレビュー・履歴を使い分ける。各キャンバスタブは独立した視点と表示設定を持つ。 |
| 3 | 階層とモード | 検索、選択、親の変更。透過画像をツリーへ入れて配置を確定する。描画順と変形の親子関係は別。 |
| 4 | 差分 | 「差分なし」はタグの部位を自動で組み込み、オンオフ差分は表示/非表示、切替差分は同じパラメータと異なる ID で択一。 |
| 5 | 素材とレイアウト | レイアウトプロジェクトを作るか PSD を読み込み、素材パネルで素材を読み込んで整理し、キャンバスへドラッグして配置、タグで部位を指定して「生成」。後から追加・タグ変更して「再生成」しても編集は保持されます。[素材とレイアウト](../../zh/guide/LAYOUT.md)（中国語）参照。 |
| 6 | パラメータとキーフォーム | スライダーや XY を操作し、キーの印を右クリックして吸着。キーフォームを編集する前に対象のキーへ値を合わせる。 |
| 7 | オブジェクト | キャンバスとツリーで対象を選ぶ。選択だけでは形状は変わらない。 |
| 8 | デフォーマ作成 | 対象選択 → ツールバーの「作成」グループまたはツリーの右クリック → 配置を調整 → 確定。 |
| 9 | 変形 | 現在のパラメータ姿勢で点やブラシを操作。ワープデフォーマでは「頂点」と「ベジェ」のレベルを切り替え（1 / 2 キー）、メッシュは頂点・辺・面で選択する。 |
| 10 | 編集 | メッシュの細分化・接続・切断・削除後、既存の姿勢を確認する。 |
| 11 | 描画 | レイヤーを選び画素を編集。セッション内で元に戻せる。最後に適用か破棄。 |
| 12 | インスペクター | 選択対象の名前、所属、マスク、描画順、不透明度や色を調整する。 |
| 13 | ツールオプション | キャンバス左下のツールオプションバーで使用中のツールの半径・硬さ・強さ等を設定。右クリックメニューには同じ値とツールの操作。「ツール詳細」パネルは詳細設定のみ。 |
| 14 | ボーンと編集 | ボーンモードでボーンを作成・押し出し・複製・ミラーし、ArtMesh を一括バインド。FK/IK でポーズを付け、スキンウェイトをペイント・整理してポーズを保存。パネルでサンプリング許容値とキー上限を設定。書き出し時に Cubism パラメータ・デフォーマ・キーフォームへベイク。 |
| 15 | アニメーション | プリセットごとの調整項目で生成モーションを調整。タイムラインでパラメータトラックとキーを編集。自動キーフレーム、標準ベジェ補間、トラックのキー表示、複数キャンバス間のポーズ共有に対応。 |
| 16 | 物理演算 | 入力、振り子、出力を設定し、実測範囲から出力倍率を調整する。 |
| 17 | 布と髪のシミュレーション | モデルプリセットの「物理・シミュレーション」で髪と衣装のシミュレーションを作り（なければ最初に作る）、髪の 3 モードと衣装の設定を確認。シミュレーションパネルで物体を確認し、シミュレーションモードで固定点・剛性・形状保持・質量・減衰のウェイトを描いて意味を理解し、接着、材質プリセットと各値、入出力、焼き込み設定を調整してパラメータ・キーフォーム・Cubism 振り子へ焼き込む。書き出されるのは焼き込み結果だけ。 |
| 18 | プロジェクトと履歴 | 保存、コンパクトな履歴ツリーでの検索・ブランチ強調・ダブルクリック復帰。専用の「履歴」プリセットに対応。「ファイル → 最近使ったファイル」で最近のプロジェクトや PSD を開き直し、「モデル → 生成結果を更新」で編集を今のバージョンの生成結果にマージする。 |
| 19 | 高解像度化 | ローカル環境を設定して 2× / 4× を選び、輪郭・半透明部・出力を確認する。 |

## 間違えやすい点

髪・衣装のシミュレーション、固定点ウェイトの調整、ベイクと書き出し結果の確認は、[シミュレーション図解チュートリアル（中国語）](../../zh/guide/SIMULATION_TUTORIAL.md)を参照してください。

- **保存と書き出し**：保存はワークスペースと履歴を保持し、書き出しは対象ソフトが使うモデルファイルを作ります。`.psd2live.json` はレポートで、プロジェクトではありません。CMO3 を書き出すと、モデルのモーションが同名の `.can3` にも書き出され、Cubism Editor のアニメーターで cmo3 と一緒に開いて編集できます。両方を同じフォルダーに置き、同じ書き出しで作られたものを使ってください。
- **書き出し完了**：Live2D モデル、PSD、「形式を指定して書き出し」の各形式の書き出しが終わると、書き出し画面が閉じて「書き出し完了」が表示され、出力先と警告（またはその形式で保持できない内容）を示し、**フォルダーを開く** ことができます。**閉じて今後表示しない** を選ぶと、以後はログとステータスバーだけで知らせます。**設定 › 確認ダイアログ** には「今後表示しない」を選べるウィンドウ（インポート後のスタート画面を含む）が並び、個別に再表示するか **すべて再表示する** ことができます。
- **キーフォームとキーフレーム**：パラメータのキー上のキーフォームはモデリングに属し、キー間でモデルの形が補間されます。キーフレームはアニメーションのタイムライン上にあり、ある時刻のパラメータ値を記録します。
- **変形と編集**：変形は形状を、編集は制御メッシュの構造を変えます。描画は画素を変え、独立した適用・破棄のセッションを持ちます。
- **表示と差分**：ツリーでの一時的な単独表示やレイヤーの静的な表示切り替えは編集時の確認用です。パラメータで切り替えるには差分か不透明度のキーフォームを設定します。

### 前後分層：あるレイヤーを別のパーツに通す

たとえば襟が 1 レイヤーしかないのに「後ろ襟 → 首 → 前襟」の重なりが必要な場合、階層ツリーで襟を右クリックして **前後に分層…** を選ぶか、襟と首を複数選択して襟を右クリックし **「襟」を前後に分層** を選びます。元レイヤーは前後 2 つの新しいレイヤーに置き換わり、前レイヤーはグルーで後ろレイヤーに追従します。続けて前レイヤーから後ろ襟の部分を消しゴムで消し、適用します。手順の図解と詳細は[前後分層の図解チュートリアル（中国語）](../../zh/guide/DEPTH_SPLIT.md)を参照してください。

## 生成結果と古い記録

**古いプロジェクトの分割記録**：以前のバージョンで行った分割（連結成分・多角形・前後分層）は、分割時の状態をパーツに固定しています。こうしたプロジェクトはそのまま開けます。最初の編集で現在のモデルが固定データとして保存され、以後は古い記録を再生しません。それらのパーツは自分のメッシュとして、加えた変更とともに残ります。新しい分割にはこの違いがありません：パーツは元レイヤーの位置で生成に参加し、元レイヤーに加えたキーフォーム・パス・ウェイト・グルーはパーツに引き継がれ、後から顔の設定・立ち姿・スケルトン・分類を変えるとパーツにも反映されます。

**生成結果を更新**：髪のシミュレーションの有効化、スケルトンの追加や変更、レイヤーの分割など自動生成の結果を変える操作は、既存の編集を新しい生成結果にマージし、その結果を固定したデータとして保存します。アプリを更新してもこれらは自動では変わりません。新しい生成器の改良を取り入れるには **モデル → 生成結果を更新** を使います。編集していない部分は新しい生成結果に置き換わり、編集はそのまま残ります。きれいに移せなかった箇所はステータスバーに件数が表示され、インスペクターに一覧されます。以前のバージョンが誤ってマージした箇所（スケルトン追加後に腕のメッシュがボーンに付いていない、前腕を曲げると腕が肩から離れる、読み込んだ画像が上半身と一緒に回らない など）は新しいバージョンでマージし直され、その後の編集は残ります。プロジェクトを開いたときや生成結果が変わったとき、こうしたマージ結果がないかバックグラウンドで確認し、見つかると編集キャンバス上部に通知し、そこから **生成結果を更新** や **変更をプレビュー** を実行できます。閉じた通知は、生成結果が再び変わるまで表示されません。生成結果が同じなら履歴は増えません。更新は 1 回の取り消し可能な履歴です。先に変化を確かめるには **モデル → 生成結果の更新をプレビュー** を使います。更新でリグが変わるかと確認が必要な項目数がステータスバーに表示され、プロジェクトは変わりません。

## 初期ショートカット

以下は初期設定（Photoshop 風）のキーです。**設定**で Blender 風・Cubism 風のプリセットに切り替えたり、個別に変更したりできます。現在の割り当てはヘルプページの **ショートカット** で確認できます。キーのほか、修飾キー付きのホイール（上 / 下 / 左 / 右）、マウスの中ボタンとサイドボタン（`MouseBack` / `MouseForward`）も任意のコマンドに割り当てられます。記録中の欄の上でホイールを回すかボタンを押してください。**キャンバスのマウスジェスチャー**（パン、ドラッグでズーム、ブラシ調整）には押してドラッグするボタンを割り当て、左右のボタンも修飾キー付きなら使えます。修飾キーなしのホイール・左ボタン・右ボタンは、スクロールとズーム、ツール、右クリックメニュー用に予約されています。Windows は横ホイールを Shift + ホイールとして報告するため、`Shift+WheelUp` / `Shift+WheelDown` として記録されます。

| 操作 | キー |
| --- | --- |
| プロジェクトを開く / PSD をインポート | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 別名で保存 | `Ctrl+S` / `Ctrl+Shift+S` |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` または `Ctrl+Y` |
| モデルを書き出し / PSD を書き出し | `Ctrl+G` / `Ctrl+Shift+E` |
| PSD を再解析 | `Ctrl+R` |
| テクスチャ高解像度化 | `Ctrl+U` |
| ヘルプ / 設定 | `F1` / `Ctrl+,` |
| 拡大縮小 / 移動 | ホイール / 中ボタン（または `Shift+MouseMiddle`）ドラッグ、または Space + 左ドラッグ |
| ドラッグでズーム | `Ctrl+MouseMiddle` で上下にドラッグ |
| ブラシ調整：サイズ・硬さ / 不透明度・角度 | `Alt+MouseRight` / `Shift+Alt+MouseRight` でドラッグ |

## 確認とトラブルシューティング

| 症状 | まず確認すること |
| --- | --- |
| パーツが正しく動かない、動かない | [素材命名](../spec/PSD_LAYER_SPEC.md)と「レイヤー」表の種類・左右、マスク、親 |
| 静止ポーズは正常だが動くと破綻する | アニメーション・物理パネルで再生して確認（静止ポーズ 1 枚では動きは分からない） |
| パネルが見えない | ウィンドウメニューのパネル表示、または右上の「レイアウトをリセット」 |
| キャンバスにモデルが見えない | キャンバスを合わせ（`F` / `Home`）、レイヤーの表示を確認 |
| 書き出しに失敗する、変換の警告が出る | ログパネル、`.psd2live.json` レポート、書き出し対象バージョン |

問題を報告するときは、バージョン、OS、再現手順、関連する素材を添えてください。
