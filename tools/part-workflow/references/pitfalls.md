# 坑点清单

来自外部 AI 辅助建模流程的实测记录（两个全身角色，各 27 与 41 层），已去掉与具体环境相关的内容。

## 生成

| 坑 | 做法 |
| --- | --- |
| 生成工具按自己的尺度重绘：偏移十到数十像素，缩放约 0.6 到 1.4 倍 | 不要求位置不变；用 `ingest` 自动对齐，看对比图复核 |
| 手臂姿势与母版不同 | 用另一侧水平镜像（`--mirror`）；左右比例不一致的角色要分别生成 |
| 完全看不见的部件尺度不准 | 手工 `--init`；必要时人工缩放 |
| 补出的顶端被画成一条直线或渐隐 | 提示词写明"补到根部、自然收口、不要直线、不要渐隐" |
| 两个同类部件同框 | 每个任务只含一个部件的一侧 |
| 用遮罩补画整个部件，接缝、竖棱、碎片、左右风格不一 | 改用整部件生成；遮罩补画只做局部修复 |
| 工具用代码模糊或取色填充冒充补画 | 提示词要求像素来自生成输出；`repair-paste` 只取遮罩内像素；必要时取中间轮次的原始生成图 |
| 被内容审核拒绝 | 不改写绕过。换工具，或镜像另一侧、取母版像素，并在报告写明 |
| 并发过高出现 "model is at capacity"，或单次超时 | 降低并发，捕获超时后只重跑缺失的部件 |
| 额度用完（HTTP 402）后所有任务失败 | 把关键、易被拒的任务优先发给宽松的工具，尽早做 |

## 抠图

| 坑 | 做法 |
| --- | --- |
| 低透明度噪点：导入时被当成整个包围盒的网格，渲染出整块色块 | `matte` 默认删小于 40 px 的连通块；检查 `bbox_fraction` 与 `touches_border` |
| 边缘白边、绿边 | 用已知背景色求 α 并估计前景色（`matte` 已做）；必要时 `--shrink 0.05` |
| 白色前景贴着白底 | 靠与边框连通判别；仍不行就换背景色（`suggest-bg`、`task --bg`）重新生成 |
| 生成图背景有渐变或非纯色 | `matte` 估计背景色并用容差；渐变严重时重新生成，别硬抠 |
| 腮红、半透明阴影被抠坏 | 不做抠图层；白底出图后以正片叠底导入 |
| 细发丝丢失 | 降低 `--tol`，增大 `--band`；仍丢则让生成工具在更大尺寸出图 |

## 对齐

| 坑 | 做法 |
| --- | --- |
| 低纹理部件（眼白、眉毛、鼻子）自己对不准 | 借用同侧可靠部件（睫毛）的变换；`--init` 手工 |
| 数字指标彼此矛盾 | 以 `sheet.png` 与隐藏上层后的渲染为准 |
| 头部特写放回全身带入旋转，脸歪 | 特写眼线水平（< 1°）；默认锁旋转为 0 |
| 眼睛整体偏离脸的中线 | 以脸的中线为轴左右对称摆放 |
| 脸底层被画得过长 | 地标做横纵不同比例缩放（当前工具只支持相似变换，需另行处理） |

## 装配与导入

| 坑 | 做法 |
| --- | --- |
| 大腿截断、渐隐、两腿中间有空隙 | 补全到大腿根；两侧遮罩不要互相排除；看隐藏裙子后的渲染（`exposure`） |
| 脖子上缘是 V 形缺口，低头露底 | 脖子延伸到下巴后面，上缘是平直的被遮边 |
| 母版上的投影、勒痕留在可见像素里，动起来跟着部件走 | 提示词要求不画上层的影响，投影另作阴影层 |
| 同一 role 多层，PSD 顺序与网格编号不一致（`tail 1` → `ArtMeshTail2`） | 导入后 `workspace_inspect` 查网格名再写 swing 目标（不带 `mesh:` 前缀） |
| `import_psd` 每次新建工程，手工 swing、物理、腿部参数全部丢失 | 每次重做后重建；保存新版本用新文件名；这正是后续"增量发送"要解决的问题 |
| 张嘴/闭嘴出现双线 | 关闭 `mouthOutlineEnabled`；同时提供 `mouth close` 与 `mouth open` |
| 刘海比参考更遮眼 | 眼白、虹膜、睫毛放在前发之上 |
| 用户会放大看细节（袜子错位、截断、膝盖浅色线） | 交付前自己先查：隐藏上层、左右摆动、膝盖和接缝特写 |

## 工作方式

- 每做完一版备份，新版本用新文件名；中间产物（生成图、抠图、对齐结果）也要保留。
- 看图预览按路径缓存时，每次换文件名。
- 只汇报已经完成且能看到的结果；没开始的事不要说"已开始"。
