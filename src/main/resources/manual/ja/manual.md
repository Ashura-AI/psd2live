@@ workflow | 制作フロー
PSD2Live は分割済みの PSD から動く初期モデルを自動生成し、同じワークスペースで形の修正、リギング、物理演算とシミュレーションの追加、アニメーション編集を行い、最後に Cubism やほかの形式へ書き出します。Cubism のようにまず手作業で組み立ててから動かす流れとは異なり、最初のステップでメッシュ、デフォーマ、パラメータ、モーション、物理演算がすべて揃います。
## 基本の流れ
1. **PSD を用意する**：パーツごとにレイヤーを分け、レイヤー名はできるだけ認識できる名前にします（[[precautions-for-psd-data]] を参照）。
2. **プリセットを選んで生成する**：スタートページの **PSD から生成** でプリセット（最小 / 標準 / フル）を選び、PSD をウィンドウにドラッグするか {key:OPEN_PSD} を押します。生成後は自動的に編集ワークスペースに入ります（[[psd-import]]、[[model-presets]] を参照）。
3. **認識結果を確認する**：**レイヤー** パネルで各レイヤーのタグ（パーツ、左右）と差分設定を確認し、誤認識があればその場で修正します（[[layers-palette]] を参照）。
4. **プレビューする**：キャンバスモードメニューで **プレビュー** を選ぶか「プレビュー」ワークスペースに切り替え、待機やまばたきなどのモーションと物理演算を確認します（[[preview-canvas]] を参照）。
5. **必要に応じて編集する**：編集キャンバスで変形、編集、ボーン、描画などのモードを使ってキーフォーム、メッシュ、ピクセルを修正し、物理演算パネルやシミュレーションパネルで揺れを調整します（[[canvas-modes]] を参照）。
6. **プロジェクトを保存する**：{key:SAVE_PROJECT} で `.psd2live` として保存します。元画像、すべての編集、分岐履歴が含まれます。
7. **書き出す**：{key:GENERATE} で **Live2D モデルを書き出し…** を開き、`.moc3` / `.cmo3` を書き出します。ほかの形式は **ファイル → 形式を指定して書き出し** にあります。
{tutorial=BASIC}
## ほかの 2 つの始め方
- **レイアウトプロジェクト**：空のキャンバスから始め、画像、PSD、SVG 素材を読み込んで配置とタグ付けをしてから生成します（[[layout-project]] を参照）。
- **CMO3 から読み込み**：既存の Cubism モデルを開いて編集を続けます。プリセットの自動生成は行いません（[[cmo3-import]] を参照）。
## 再生成と編集
キャンバス上の修正はすべて再生可能な編集として保存されます。あとでレイヤーのタグやモデルプリセットを変更したり、プログラムを更新したりすると、モデルは元画像から再生成され、編集が順番どおりに再適用されます。そのため再生成で編集が失われることはありません。新しいバージョンのジェネレーターを採用したいときは **モデル → 生成結果を更新** を使います（[[update-generated-rig]] を参照）。
## Cubism との違い
- Cubism：素材分け → Editor でメッシュ、デフォーマ、パラメータを手作業で作成してキーフォームを作る → Animator でアニメーションを作る → 書き出し。
- PSD2Live：素材分けのあとジェネレーターが一度に初期モデルを作り、モデリング、物理演算、アニメーションを同じプログラム・同じプロジェクトで行います。保存されるのは最終モデルそのものではなく、再生可能な編集と履歴です。
- Cubism に渡す場合は `.cmo3` を書き出せば Cubism Editor で仕上げを続けられます。ランタイムだけで使う場合は `.moc3` 一式を書き出します。
*> Cubism の経験がある場合は、まずインタラクティブチュートリアルの用語対照の章を読んでください。

@@ file-type-and-extension | ファイルの種類と拡張子
PSD2Live が読み書きする主なファイルは次のとおりです。プロジェクト本体は `.psd2live` で、それ以外の多くは読み込む素材か書き出す成果物です。
## プロジェクトとレポート
| 拡張子 | 説明 |
|---|---|
| `.psd2live` | PSD2Live プロジェクト。暗号化されていない ZIP で、元の PSD または CMO3、素材、設定、すべての編集と分岐履歴を含み、元の PSD のパスに依存しない |
| `.psd2live.json` | 書き出し時に添付されるレポート（書き出しウィンドウでオフにできる）。損失と警告を記録する。プロジェクトではない |
## 読み込み
| 拡張子 | 説明 |
|---|---|
| `.psd` | 分割済み PSD。モデル生成の元画像 |
| `.cmo3` | Cubism Editor のモデルファイル。新規プロジェクトの作成または現在のモデルの置き換えに使える |
| `.png` `.webp` `.tiff` `.bmp` | 階層にドラッグするか **レイヤーをインポート…** で単一レイヤーとして追加 |
| `.svg` などの画像 | レイアウトプロジェクトの素材ライブラリに読み込む |
## 書き出し
| 拡張子 | 説明 |
|---|---|
| `.cmo3` / `.can3` | Cubism Editor のモデルファイル。モーションがある場合は同名の `.can3`（Animator のファイル）も書き出す。両方を同じフォルダーに置く必要がある |
| `.moc3` `.model3.json` など | Cubism ランタイム用ファイル一式：モデル、設定、物理演算、モーション、表示情報、テクスチャ。`.model3.json` から読み込む |
| `.vtube.json` | `.moc3` 一式と一緒に VTube Studio 向けに書き出す |
| `.p2lrt` | PSD2Live ランタイムモデル。Web プレイヤーにも使う |
| `.p2lunity` | Unity プレハブ書き出しのモデルデータ |
| `.psd` | 指定したポーズの分割済み PSD、または生成レイヤーを含む元の PSD |
| `.png` `.gif` `.apng` `.webp` `.mp4` `.webm` `.mov` | 連番画像、スプライトシート、アニメーション画像、動画 |
## Cubism との違い
- Cubism のモデルファイルは `.cmo3`、アニメーションファイルは `.can3` です。PSD2Live は独自の `.psd2live` でプロジェクトを保存し、`.cmo3` / `.can3` は読み込みまたは書き出しの形式としてのみ扱います。
- `.cmo3` を書き出す際、ジェネレーターの設定と編集履歴は書き込まれません。PSD2Live で編集を続けるには `.psd2live` を保存してください。
*> 各書き出し形式の内容と制限は [[export-moc3-motion3-files]] と [[exporting-images]] を参照してください。

@@ fault-map | Editor／Viewerが正常に起動しない場合の確認事項
PSD2Live の起動に失敗した、表示がおかしい、実行中にエラーが起きたといった場合は、次の表を順に確認してください。
## よくあるケース
| 症状 | 確認事項 |
|---|---|
| 編集キャンバスが真っ黒、ちらつく、表示が乱れる | **設定 → キャンバス操作** で「編集キャンバスとアトラスページをソフトウェアで描画」をオンにします。同じ場所に現在 GPU とソフトウェアのどちらで描画しているかが表示されます。グラフィックカードがマルチサンプリングに対応していない場合や GPU 描画に失敗した場合は、自動的に互換方式に切り替わります |
| プレビューキャンバスで Cubism SDK が使えない | 利用できる Cubism SDK のネイティブライブラリがない場合は、プレビューキャンバスの **プレビューランタイム** で PSD2Live ランタイムに切り替えます。Linux で XWayland のない純粋な Wayland 環境や musl のシステムでは自動的にフォールバックします |
| パネルが見当たらない | ワークスペースのタブバー右側の **ウィンドウ** メニューで再表示するか、**レイアウトをリセット** を選びます |
| キャンバスにモデルが見えない | {key:FRAME_VIEW} で選択範囲に合わせるか {key:RESET_CAMERA} でカメラをリセットし、レイヤーの表示状態を確認します |
| プログラムが異常終了した | 次回起動時に未保存の編集を復元するか確認されます（[[autosave]] を参照） |
| 設定や画面の状態がおかしい | 設定ページの目次の一番下で **デフォルトに戻す** をクリックします。またはプログラムを終了してから `--clear-user-data` 引数を付けて一度起動し、設定とローカルデータを消去します |
## 情報を集める
1. **ログ** パネルを開き、レベルとソースでエラーを絞り込み、**ログをコピー** をクリックします。
2. **設定 → ファイルとデータ** で **エラーログ** の場所を確認します。ここでは以前の異常終了でシステムの一時フォルダーに残ったファイルも削除できます。
3. ヘルプページの **概要** にバージョンと実行環境が表示されます。
4. **ヘルプ → オンライン → 不具合の報告** から問題を報告し、バージョン、OS、再現手順、関連する素材を添えてください。
## Cubism との違い
- Cubism の確認事項は主にライセンス、グラフィックドライバー、OpenGL の設定です。
- PSD2Live にはライセンスがありません。表示の問題はソフトウェア描画のオプションで切り分け、Cubism SDK プレビューが使えない場合は同梱のランタイムに切り替えられます。

@@ performance | SDKでモデルを扱うときのパフォーマンスについて
書き出したモデルのランタイムでの負荷は、主にメッシュの頂点、キーフォームの数、テクスチャサイズ、マスクから生じます。PSD2Live では生成時と書き出し時に、これらを確認・制御できる場所がいくつかあります。
## 確認と調整
| 要因 | 確認・調整する場所 |
|---|---|
| メッシュの頂点数 | **メッシュ** パネルに選択レイヤーの頂点数と辺の長さが表示され、グローバル既定またはレイヤーごとの上書きでメッシュ設定を調整できる。**レイヤー** の情報にも頂点数が表示される |
| テクスチャサイズと VRAM | 「テクスチャ」ワークスペース：レイヤーを選択していないとき、テクスチャパネルにページごとのサイズ、タイル数、使用率、VRAM（RGBA）が表示される。右上でアトラス予算（ページサイズ、最大ページ数、間隔）を設定し、レイヤーごとにテクスチャ密度を調整する（[[texture-atlas-edit]] を参照） |
| キーフォームの数 | シミュレーションのベイクでモードをキーフォーム軸として書き込むと、メッシュのキーフォーム数はモードのキー数倍になる。「ブレンドシェイプ」（Cubism 4.2+）を選ぶと回避でき、「自動」はキーフォームが 64 を超えるとブレンドシェイプを使う（[[simulation]] を参照） |
| ターゲットバージョン | 書き出し時に選択した SDK ターゲットに応じて非対応機能を取り除き、ダウングレード項目を一覧表示する（[[target-version-selection]] を参照） |
## エディター内のプレビュー負荷
プレビューキャンバスでは **フレームレート上限** でフレームレートを制限できます（またはディスプレイに合わせる）。プレビューメニューの「拡張モード」は PSD2Live ランタイム専用で、オンにすると布と髪のシミュレーションをリアルタイムで実行するため負荷が高くなります。
## Cubism との違い
- Cubism のマニュアルでは SDK のパフォーマンスに影響する要因が説明されており、メッシュとテクスチャは制作者が Editor で自分で管理します。
- PSD2Live のメッシュ、アトラス、シミュレーションのベイクは設定に従ってジェネレーターが作り、パフォーマンス関連の数値はメッシュパネル、テクスチャワークスペース、シミュレーションパネルにまとめて表示されます。書き出しレポート `.psd2live.json` にダウングレードと損失が記録されます。

@@ home | ホーム
スタートページは起動時に表示されるページで、プロジェクトの新規作成、オープン、更新内容の確認に使います。プロジェクトを開く、読み込む、新規作成すると対応するワークスペースに自動で切り替わり、「スタート」タブは折りたたまれます。**ファイル → スタートページ** または空のキャンバスの **スタートへ** から再度開けます。
## ページの構成
スタートページはヘルプページや設定ページと同じく、左に目次、中央に選択した内容、右に現在の操作で何が行われるかを説明する詳細パネルがあります。内容の下部にある操作バーがメインボタンで、{kbd:Enter} でも実行されます。目次は矢印キーで移動できます。これらのパネルはエディターのパネルと同様にドラッグ、結合、閉じることができ、**ウィンドウ** メニューの **レイアウトをリセット** で既定に戻ります。

| グループ | 項目 | 役割 |
|---|---|---|

| 開く | 最近 | 最近のプロジェクトと PSD をグリッドまたはリストで表示。絞り込みと検索ができ、ダブルクリックで開く |

## Cubism との違い
- Cubism のホームは起動時のウィンドウで、ファイルの新規作成やオープン、Modeler / Animator の選択、お知らせの確認に使います。

@@ target-version-selection | ターゲットバージョン選択
ターゲットバージョンは、書き出す `.moc3` / `.cmo3` でどの Cubism 機能を使えるかを決めます。PSD2Live ではモデルの新規作成時ではなく、書き出しウィンドウで選択します。
## 選択方法
1. {key:GENERATE} で **Live2D モデルを書き出し…** を開きます。
2. **SDK ターゲット** のドロップダウンで Cubism 3.0、3.3、4.0、4.2、5.0、5.3 のいずれかを選びます（既定は 5.0）。
3. 現在のモデルがターゲット非対応の機能を使っている場合、ウィンドウに「使用中の機能は書き出し時にダウングレードされます」が表示され、形式、機能、対象が項目ごとに並びます。
## ダウングレードされる機能（例）
| 機能 | 説明 |
|---|---|
| 四隅の変形方式 | 古いターゲットは新しいワープ変形方式に対応しない |
| 反転マスク | 新しいターゲットが必要 |
| ブレンドシェイプ | ブレンドシェイプ関連の機能はバージョンごとに段階がある |
| 乗算色 / スクリーン色 | 古いターゲットは対応しない |
| 拡張ブレンドモード、パーツのオフスクリーン合成 | 新しいターゲットが必要 |
ターゲットバージョンは生成にも影響します。たとえばターゲットにブレンドシェイプがない場合、シミュレーションのモードはキーフォーム軸として書き込まれます。
## Cubism との違い
- Cubism ではモデルの新規作成時、またはその後ダイアログでターゲットバージョンを選び、編集中はターゲット非対応の機能を使えません。
- PSD2Live では書き出し時に選び、ターゲットに応じて非対応機能を取り除いてレポートに一覧表示します。同じプロジェクトを異なるバージョンにそれぞれ書き出せます。

@@ solo | Solo機能
Solo（単独表示）は選択したレイヤーだけを表示してほかのレイヤーを一時的に隠し、隠れているパーツを確認しやすくします。
## 使い方

2. 「表示」グループで **このレイヤーのみ表示** を選びます。メニュー項目の横に `SOLO` マークが表示されます。

*> 単独表示は編集中の一時的な表示切り替えで、パラメータで切り替わる差分とは異なります。パラメータに応じて表示・非表示を切り替えたい場合は、差分または不透明度のキーフォームを設定してください（[[variants]] を参照）。内部造形パネルには別に「単独表示・中央」があります。

- PSD2Live：階層で 1 つのレイヤーを右クリックして単独表示し、現在のキャンバスにだけ作用します。

@@ edit-level | 編集レベル

## 使い方
1. ワープデフォーマを選択し、変形モードに入ります。
2. モードバーで **頂点**（{key:PICK_OPTION_1}）または **ベジェ**（{key:PICK_OPTION_2}）を選びます。

- PSD2Live には頂点とベジェの 2 段階だけがあり、ワープデフォーマにのみ有効です。アートメッシュの頂点は常に点、辺、面の選択で編集します。

@@ palatte-basic-operation | パレットの基本操作

| 操作 | 方法 |

@@ autosave | 自動バックアップ機能
PSD2Live は編集中、未保存の変更をローカルのワークスペースのストレージに書き込み続けます。プログラムが異常終了した場合、次回起動時にこれらの変更を未保存のプロジェクトとして復元できます。
## 復元の手順
1. 保存または変更の破棄の前にプログラムが異常終了したら、PSD2Live をもう一度起動します。
2. 「未保存の編集を復元」ウィンドウが表示されたら **復元** を選びます。
3. プロジェクトは履歴、パラメータのポーズ、スナップショット、ワークスペースを含めて未保存の状態で開きます。{key:SAVE_PROJECT} で保存して残してください。
**破棄** を選ぶと復元しません。正常に保存または破棄してから終了した場合、復元データは消去されます。
## 保存場所
**設定 → ファイルとデータ** にワークスペースのストレージの場所とサイズが表示され、開いたプロジェクトの履歴がそこに保存されています。以前の異常終了でシステムの一時フォルダーに残ったファイルもここで削除できます。
## Cubism との違い
- Cubism は設定した間隔でモデルをバックアップファイルとして保存し、必要なときに手動でバックアップを開きます。
- PSD2Live はバックアップファイルを作らず、復元用のチェックポイントを残して次回起動時に復元するか確認します。バックグラウンドジョブの記録は復元されますが、自動的に再実行はされません。
!> 復元した内容はまだ未保存です。早めに `.psd2live` として保存してください。

@@ divide-the-material | 素材分けについて
イラストを動かすには、別々に動く部分や互いに重なる部分を別のレイヤーに描く必要があります。この工程を素材分けと呼びます。PSD2Live は素材分けした PSD を読み込み、レイヤー名でパーツを認識してメッシュ、デフォーマ、パラメータを自動生成するため、分け方の細かさが生成結果を直接左右します。
## 分け方の基本
- パーツごとに 1 レイヤー：白目、瞳、上まつげ、眉、鼻、口、前髪、後ろ髪、顔、首、上着など。
- 瞳はまぶたに隠れる部分も含めて完全な円で描きます。白目は瞳の表示範囲を制限するために使います。
- 口は最大限に開いた状態で描き、閉じた口はプログラムが生成します。口の中は 1 枚にまとめても、上の歯、下の歯、舌に分けてもかまいません。
- 前髪と後ろ髪は分け、隠れる部分を多めに描いて、動いたときに下地が見えないようにします。
- 左右で対になるパーツ（両目、両耳、両腕）は左右 2 枚のレイヤーに分け、名前に左右を明記するのが望ましいです。
## 分割が足りない場合の対処
同じレイヤーに描かれた左右のパーツは、読み込み時に自動では分けられず、1 つのパーツとして生成されます。読み込み後に [[split-by-mesh]] で独立したレイヤーに分けられます。1 つのレイヤーが別のパーツの前と後ろの両方に来る必要がある場合（襟が首の周りを回り込むなど）は [[depth-split]] を使います。
## Cubism との違い
- Cubism：分け方は完全に制作者次第で、読み込み後にメッシュ、デフォーマ、パラメータを 1 つずつ手作業で作ります。
- PSD2Live：素材分けのあと、レイヤー名（または読み込み後にレイヤー表で修正したタグ）に従ってリギング一式を自動生成するため、名前付けとレイヤー分けは [[precautions-for-psd-data]] の取り決めに従う必要があります。
- PSD2Live では PSD を使わずに、[[layout-project]] で個別の画像をキャンバスに配置してから生成することもできます。
*> 名前で認識できなかったレイヤーも破棄されず、通常どおりメッシュが生成されてフォールバックの所属が使われます。読み込み後にレイヤー表でタグを修正してください。

@@ reimport-psd | インポートPSDの作り方
このページでは、PSD2Live 用の PSD ファイルを用意する際の形式と構造の要件を説明します。要件を満たす PSD はそのまま読み込んでモデルを自動生成できます。
## ファイル形式
- RGB、8 ビット、透明背景の分割済み PSD を使います。
- テキスト、ベクター、レイヤースタイル、調整効果は先にラスタライズするか、対応するピクセルレイヤーに結合します。
- 体は基本的にまっすぐ立たせます。頭は少し傾いていてもかまいませんが、基準の自動推定はプレビューで確認してください。
## レイヤー名
ジェネレーターはレイヤー名でパーツを認識します。英語、中国語、日本語、韓国語の名前が使え、たとえば `front hair`、`前发`、`eyelash-l`、`左睫毛` などです。名前の対照表は [[precautions-for-psd-data]] を参照してください。認識結果は初期値にすぎず、読み込み後に「レイヤー」パネルの「タグ」列でいつでも変更できます。
## 左右と番号
- 左右はキャラクター自身から見た向きです：キャラクターの左側は通常、画面の右側にあります。
- 名前の数字（`front hair 1` など）は同種の素材を区別するために使います。Photoshop の一部のコピー接尾辞は取り除かれます。
- 数字だけでは表情の切り替えは作られません。パラメータで切り替えたいレイヤーには、読み込み後に [[variants]] を設定します。
## キャンバスサイズ
メッシュ設定の既定は「ドキュメントサイズに合わせる」です。長さは長辺を固定サイズに縮尺したドキュメントを基準に計算されるため、大きな PSD でも同じ密度のメッシュになります。精細さはレイヤー自身のピクセルから決まります。
## Cubism との違い
- Cubism：PSD のレイヤーとフォルダー構造がそのままアートメッシュとパーツになり、名前は表示にのみ使われます。
- PSD2Live：レイヤー名によってジェネレーターがどのパーツとして扱うかが決まります。パーツはジェネレーターが部位に応じて自動で作り、PSD のフォルダーでは分けません。
*> PSD がない場合でも、外部ツールで分けた画像を Layout マニフェスト（JSON または zip）に書き出して直接開けます。[[layout-project]] を参照してください。

@@ precautions-for-psd-data | PSD作成上の注意点
自動生成はレイヤー名とレイヤーの分け方に依存します。以下は描画時に問題になりやすい点と、ジェネレーターが自動認識できるレイヤー名の表です。
## 描くときの注意
- まつげのレイヤーには上まつげだけを描き、下まつげや下まぶたの線を混ぜないでください。混ぜると目を閉じたときに下まぶたが引っ張られることがあります。
- 口は最大限に開いた状態で描きます。閉じた口の形にこだわりがある場合は別に `mouth_close` を描きます。閉じた口の原画からは、存在しない口の中を変形で再現できません。
- 前髪と後ろ髪は分け、隠れる部分に十分な重なりを残します。
- 閉じた目はあらかじめ `eye_close` として描いておくことも、まつげの閉眼カーブに任せることもできます。
!> 名前が認識されたからといって、造形が合格というわけではありません。読み込み後に、ニュートラル、目と口の開閉、首振り、髪の動きを確認し、レイヤー順、左右、マスク、下地の露出を確認してください。
*> 認識結果は「レイヤー」パネルの「タグ」列で変更できます。[[psd-import]] を参照してください。

@@ split-by-mesh | メッシュごとにレイヤーを分割
1 つのレイヤーに互いにつながっていない部分がいくつも描かれている場合（両目が同じレイヤーに描かれているなど）、メッシュの連結領域ごとに独立したレイヤーに分け、それぞれに専用のメッシュ、変形、タグを持たせることができます。
## 開き方
- **モデル → メッシュごとにレイヤーを分割…**：すべてのレイヤーを走査し、独立したメッシュを含むレイヤーを一覧表示します。**すべて選択** / **選択解除** してから **選択したレイヤーを分割** をクリックします。
- 階層でレイヤーを右クリック → **独立したメッシュを分割…**、またはオブジェクト、編集、描画モードのキャンバスの右クリックメニューの **メッシュ** から選ぶと、そのレイヤーだけを処理します。
- レイヤーを読み込んだあと、プログラムから分割するかどうか尋ねられることがあります。ダイアログで今後表示しないをオンにするか、**設定 › 確認ダイアログ** の「レイヤーのインポート時にメッシュ分割を提案」で切り替えます。
## 分割の手順
1. **メッシュごとにレイヤーを分割** ダイアログを開き、各メッシュ領域のプレビューを確認します。
2. 名前の付け方を選びます。2 つの場合は `L / R`、`T / B`、`1 / 2`、**名前を指定** から選べ、それ以上の場合は番号付けか名前の指定になります。
3. **レイヤーを分割** をクリックします。分割しない場合は **1 レイヤーのまま**、一括処理では **すべて1レイヤーのまま** をクリックできます。
`L / R` の名前付けはキャラクター自身の左右に従います：画面の左側の部分に `-r` 接尾辞が付いて右側とされ、もう一方が `-l` になります。
## 分割後の結果
パーツが元のレイヤーに置き換わり、メッシュは元のメッシュの対応部分から取られます。元のレイヤーにあったキーフォーム、ブレンドシェイプ、パス、ウェイト、グルーはパーツに引き継がれます。その後パーツのメッシュ設定を変更すると、パーツ自身のピクセルからメッシュが再生成され、これらのバインドが移行されます。
!> CMO3 から読み込んだモデルはメッシュごとに分割できません。
## Cubism との関係
Cubism ではレイヤーを PSD で分けてから読み込み、読み込んだあとはアートメッシュを分割できないため、描画ソフトに戻って PSD を修正し、再インポートする必要があります。PSD2Live ではエディター内で直接分割でき、PSD を修正する必要はありません。連結領域ではなく任意の形で分けたい場合や、前後の差し込みが必要な場合は [[depth-split]] を参照してください。

@@ depth-split | 前後に分層
1 つのレイヤーの異なる部分を、別のパーツの前と後ろにそれぞれ置きたいことがあります。たとえば後ろ襟は首の後ろに隠れ、前の襟は首の前にかかります。**前後に分層** はレイヤーを前後 2 枚に複製して間のオブジェクトを挟み、描画順を自動で設定し、グルーで 2 枚を一緒に変形させます。あなたは前のレイヤーで後ろに隠すべき部分を消すだけです。
## 操作手順
1. 編集キャンバスを **オブジェクト** モードに切り替え、分層するレイヤー（上着など）を選択し、{kbd:Shift} を押しながら間に挟むオブジェクト（首など）を追加選択します。
2. 分層するレイヤーを右クリックし、**「レイヤー名」を前後に分層** を選びます。メニューに表示される名前が複製されるオブジェクトなので、クリック前に確認してください。
3. プログラムが「`レイヤー名 · 後`」と「`レイヤー名 · 前`」の 2 枚を作って元のレイヤーと置き換え、前のレイヤーを自動選択して **描画** モードの **消しゴム** に切り替えます。
4. 間のオブジェクトの縁に沿って、前のレイヤーで隠れるべき部分を消します。消しすぎたら描画セッションの取り消しで戻せます。
5. **適用** をクリックします。前のレイヤーは元のメッシュと変形を保持し、メッシュの再生成は不要です。
6. パラメータパネルで首振りや体の回転などのポーズを確認し、必要なら前のレイヤーに戻って縁を修正します。
レイヤーを 1 つだけ選択している場合は、階層でそれを右クリックして **前後に分層…** を選び、ポップアップの **間に挟むパーツ** で間のオブジェクトを選び、前／中間／後の関係を確認してから **作成して消しゴムへ** をクリックします。
## 注意事項
- 一度に分層できるレイヤーは 1 つです。間のオブジェクトは複数追加選択でき、前後のレイヤーの間にまとめて置かれ、互いの順序は保たれます。
- 作成直後は見た目は変わりません。新しい前のレイヤーは最初は完全な複製なので、消してはじめて遮蔽の効果が出ます。
- 未確定の描画セッションがある場合は、先に適用するか破棄してから作成してください。
!> CMO3 から読み込んだモデルは、現在のところ前後の分層に対応していません。

## Cubism との関係
Cubism では通常、描画ソフトに戻って素材を前後 2 枚に分け、再インポートしてそれぞれ変形を設定するか、グルーでつなぎます。PSD2Live ではエディター内で複製、並べ替え、接着を一度に行い、後ろのレイヤーは完全なピクセルを保持し、元のレイヤーの変形データは 2 枚に複製されます。

@@ layout-project | Layout プロジェクトと素材ライブラリ
Layout プロジェクトでは、まずキャンバスにパーツを配置してからリギングを生成します。生成後も画像の追加やタグの変更を続けて再生成でき、既存の編集は保持されます。素材ライブラリ（**素材** パネル）にはプロジェクトで使うすべての画像が保存され、レイヤーに表示されるピクセルは関連付けられた素材から来ます。
## Layout プロジェクトを始める
- **空のキャンバスから始める**：スタートページで **レイアウトプロジェクト**（または **ファイル → 新規 → 新規レイアウトプロジェクト…**）を選び、よく使うサイズを選ぶか幅と高さを入力して **レイアウトプロジェクトを作成** をクリックします。新しいプロジェクトにはまだリギングがなく、レイアウトワークスペースに切り替わります。
- **PSD から始める**：通常どおり PSD を読み込みます。プロジェクトはリギングを直接生成し、同時に PSD の各レイヤーが素材パネルに現れ、キャンバス上のレイヤーと関連付けられます。
- **Layout マニフェストから始める**：外部ツールが書き出したマニフェスト（JSON、またはルートにそれを置いた zip）を PSD を開くのと同じ方法で開くと、レイヤーがマニフェストどおりに配置され、まだ生成されていない状態になります。
## 素材パネル
- **読み込み**：**読み込み** または **フォルダーを読み込む** をクリックするか、ファイルをパネルにドラッグします。PNG、BMP、TIFF、WebP、JPEG、PSD、CMO3 内の分割済み画像と SVG に対応します。PSD は 1 つのフォルダーになり、レイヤーグループはサブフォルダーになります。
- **整理**：素材をほかのフォルダーへドラッグすると移動できます。右クリックで名前の変更、フォルダーの新規作成、削除ができます。レイヤーで使用中の素材は削除できません。
- **素材ウィンドウ**：素材をダブルクリックすると独立したウィンドウが開き、表示、描画、反転、色調整ができます。その素材を使うすべてのレイヤーが一緒に更新されます。
## 配置と生成
1. 素材またはフォルダー全体をキャンバスにドラッグするか、右クリックで **キャンバスに配置** します。
2. **オブジェクト** モードで変形ボックスを使ってレイヤーを移動、拡大縮小、反転します。配置と拡大縮小ではピクセルは再サンプリングされません。
3. 「レイヤー」パネルの **タグ** 列でパーツと左右を指定し、**差分** 列で差分トグルや差分切替を設定します。
4. 編集キャンバス右上の生成バーの **生成** をクリックします。その後に新しく配置したレイヤーやタグを変更したレイヤーは「生成待ち」と表示され、**再生成** でリギングに取り込みます。
まだ生成していないレイヤーは {key:LAYER_FORWARD} / {key:LAYER_BACKWARD} で 1 つ上 / 下へ、{key:LAYER_TO_FRONT} / {key:LAYER_TO_BACK} で最前面 / 最背面へ移動できます。生成後は、生成済みレイヤーの前後関係を [[draworder]] で調整します。
*> キャンバスの単位がモデルの大きさと比率を決め、精細さは素材自身のピクセルから決まります。レイヤーを小さく配置するほど、テクスチャは密になります。
{tutorial=LAYOUT}
## Cubism との関係
Cubism は PSD からしかモデリングできず、素材を増減するには描画ソフトに戻って PSD を修正し、再インポートする必要があります。Layout プロジェクトは「素材の整理、配置、名前付け」もエディターに取り込んだもので、素材が複数のファイルから来る場合やプログラムで分割した場合に向いています。参照レイヤーは [[sketch]] を参照してください。

@@ psd-import | PSDのインポート
分割済み PSD を読み込むと、PSD2Live はレイヤー名でパーツを認識し、メッシュ、デフォーマ、パラメータ、モーション、物理演算を自動生成して編集ワークスペースに入ります。生成内容は [[model-presets]] で決まり、読み込み前に選ぶことも、あとで変更することもできます。
## 読み込み方法
- **ファイル → 新規 → PSD から新規プロジェクト…**（{key:OPEN_PSD}）でファイルを選びます。
- PSD をウィンドウの任意の場所にドラッグします。
- スタートページの **PSD から生成**：まず詳細パネルでプリセット（**最小** / **標準** / **フル**）を選び、必要に応じて項目ごとに調整してからファイルを選びます。**最近の PSD** でダブルクリックすると直接生成します。
プリセットは記憶され、メニュー、最近使ったファイル、ドラッグ＆ドロップで読み込んだ PSD はすべてそれで生成されます。読み込み後、髪と衣装のシミュレーションが順にベイクされ、進行状況はステータスバーに表示されます。
## 読み込み後の確認
1. **レイヤー** パネルを開き、各レイヤーで認識された **タグ**（パーツと左右）を確認します。違っていればタグを開いて修正します。生成済みのレイヤーは再生成後に新しいタグが使われます。
2. **差分** 列で、パラメータに応じて表示・非表示や切り替えが必要なレイヤーに [[variants]] を設定します。
3. プレビューに切り替え、まばたき、口の動き、首振り、髪の動きを確認します。
4. {key:SAVE_PROJECT} で `.psd2live` プロジェクトとして保存します。PSD の各レイヤーは同時に素材としても登録されます。[[layout-project]] を参照してください。

## Cubism との違い
- Cubism：PSD を読み込んでもアートメッシュとパーツが作られるだけで、メッシュ、デフォーマ、パラメータは手作業または補助機能で 1 つずつ作る必要があります。
- PSD2Live：読み込むだけで動く完全なモデルが得られ、その後エディターで修正します。すべての修正は編集記録として保存され、再生成時に再適用されます。
- Cubism のパーツは PSD のフォルダーに従って作られます。PSD2Live は認識したパーツに応じて自動でパーツを作ります。
- 既存の Cubism モデルは [[cmo3-import]] で開けます。

@@ psd-re-import | PSDの再インポート
原画を修正したら、新しいピクセルを既存のプロジェクトに取り込む必要があります。PSD2Live にはレイヤーの対応関係に従って PSD 全体を再インポートする機能はなく、必要に応じて次の方法を選びます。
## 個別のレイヤーのピクセルを差し替える（編集を保持）
1. 素材パネルで修正した PSD を **読み込み** ます。新しい素材フォルダーになります。
2. キャンバスまたはレイヤー一覧で、更新するレイヤーを選択します。
3. 新しい素材を右クリックして **選択レイヤーの画像を差し替え** を選びます。キャンバス上のレイヤーの位置とサイズは変わらず、ピクセルとアトラスのタイルだけが変わります。
4. 生成バーの **再生成** をクリックします。画像を差し替えたレイヤーは既定で新しいピクセルからメッシュが再生成されます。元のメッシュを保持したい場合は、生成ボタンのドロップダウンで **差し替えた画像のメッシュは保ったまま生成** を選びます。
**テクスチャ** パネルの **画像を置き換え…** で単一レイヤーを差し替えることもできます。[[png-file-export-replacement]] を参照してください。
## 新しいレイヤーを追加する
新しい素材をキャンバスにドラッグして配置し、タグを付けて **再生成** します。既存の編集は保持されます。[[layout-project]] を参照してください。
## 最初から再生成する
**モデル → PSD を再解析**（{key:REANALYZE}）は現在の PSD を読み直し、現在のプリセットで新しいプロジェクトを生成します。未保存の変更がある場合は先に保存するか確認されます。元のプロジェクトの編集は新しいプロジェクトに引き継がれません。
## Cubism との違い
- Cubism：PSD の再インポート時にレイヤー名または手動指定で対応関係を決め、既存のアートメッシュのテクスチャを差し替えます。メッシュを保持するかどうかも選べます。
- PSD2Live：PSD 全体の対応関係の設定はなく、素材の差し替えでレイヤーごとにピクセルを更新します。新しいレイヤーは配置して追加し、再生成します。
!> 作者の編集、バインド、実体化されたメッシュがあるレイヤーでは、画像を差し替えてメッシュを再構築する操作が拒否されることがあります。理由はアトラスページの上部に表示されます。

@@ model-presets | モデルプリセット
**モデルプリセット** パネルは、何を自動生成するかとその量を決めます：リギング・口形状、リグの数値、モーション、物理・シミュレーション。変更するとモデルは新しい設定で再生成され、既存の編集は通常どおり再適用されます。
## 設定する場所
- 読み込み前：スタートページの **PSD から生成** の詳細パネルで、**最小** / **標準** / **フル** のプリセットを選んでから項目ごとに調整できます。生成ボタンのメニューでプリセットを切り替えたり、**現在のモデルに適用** したりできます。
- 読み込み後：**モデルプリセット** パネル（**ウィンドウ** メニューから再度開けます）。上部のツールバーですべて展開 / 折りたたみができ、**デフォルトに戻す** ですべてのモデルプリセットを既定値に戻します。
## 各グループの内容
| グループ | 内容 |
|---|---|
| リギング・口形状 | 目鼻口の移動デフォーマのオン・オフ、頭部と体の変形量（0–4 倍）、上下の唇の輪郭線の生成と線幅・色、口形状の設定 |
| リグの数値 | 体 X（左右の回転）、体 Y、身体の前後傾、頭身（デフォルメ）、体 Z と呼吸、立体と透視。**詳細** には頭の向き、目、眉、口 |
| モーション | **基本モーション**、**ボーンモーション** の 2 グループ。オフにするとそのグループのモーションはアニメーションパネル、プレビュー、書き出しから除かれる |
| 物理・シミュレーション | 前髪、後ろ髪それぞれに **シミュレート** / **従来の揺れ** / **オフ** を選ぶ。**衣装** シミュレーション（ゆったりした部分だけ）。瞳のゼリー揺れ。Pin 物理ウェイトを自動設定 |
**選択のみ** をオンにすると、物理演算とシミュレーションのプリセットは選択したレイヤーにだけ作用します。
## 使い方のヒント
1. まずは既定値のまま生成してプレビューします。
2. 調整が必要な場合は 1 回に 1 項目だけ変え、プレビューの変化を確認します。
3. テクスチャアトラスのパラメータはここではなく、書き出しウィンドウで設定します。

## Cubism との関係
Cubism には対応するパネルはありません。デフォーマ、パラメータ、モーション、物理演算はすべて制作者が手作業で作るか、[[auto-generation-of-deformer]]、[[face-auto-edit]]、[[auto-generation-of-sway-motion]] などの補助機能をそれぞれ使います。PSD2Live のモデルプリセットはこれらの生成ステップを 1 か所にまとめ、変更後はいつでも再生成できます。

@@ update-generated-rig | 生成結果を更新
髪のシミュレーションのオン、スケルトンの有効化、レイヤーの分割など、自動生成の結果を変える操作を行うと、既存の編集が新しい生成結果にマージされて固定データとして保存されます。以降はプログラムを更新しても、これらの結果は自動では変わりません。新しいバージョンのジェネレーターの改善を取り入れたい場合は **生成結果を更新** を使います。
## 操作
1. まず **モデル → 生成結果の更新をプレビュー** で確認します。ステータスバーに更新でモデルが変わるかどうか、確認が必要な項目がいくつあるかが表示され、プロジェクト自体は変わりません。
2. **モデル → 生成結果を更新** を実行します。あなたが変更していない部分は新しいバージョンの生成結果に置き換わり、あなたの変更は保持されます。
3. きれいに移行できなかった箇所は、ステータスバーに件数が表示され、インスペクタの **生成結果の上書き** に一覧表示されます。
プロジェクトを開いたときや生成結果が変わったとき、プログラムは古いバージョンで誤ってマージされた結果がないかバックグラウンドで確認し、見つかった場合は編集キャンバスの上部に通知します。そこから直接「生成結果を更新」または「変更をプレビュー」をクリックできます。通知を閉じると、生成結果が再び変わるまでは表示されません。
## 注意事項
- 生成結果に変化がなければ履歴は作られません。更新は 1 ステップの履歴で、取り消せます。
- ジェネレーターが生成したキーフォーム上で行ったキャンバス編集は、生成結果への上書きとして保存され、更新時に新しい結果と 3 方向マージされます。
## Cubism との関係
Cubism ではモデルデータは制作者が手作業で作った結果そのものなので、更新が必要な生成部分は存在しません。PSD2Live のモデルは生成結果とあなたの編集から成り、この機能はジェネレーターの改善後に両者をマージし直します。

@@ cmo3-import | CMO3 から読み込み
既存の Cubism モデルファイル（`.cmo3`）を PSD2Live に読み込んで、編集、プレビュー、書き出しを続けられます。読み込んだパラメータ、キーフォーム、デフォーマ、テクスチャ、物理演算はプロジェクトと一緒に保存されます。

| 方法 | 入口 | 結果 |
|---|---|---|
| CMO3 から新規プロジェクト | **ファイル → 新規 → CMO3 から新規プロジェクト…**、またはスタートページの **CMO3 から読み込み** | 現在のモデルを消去してから読み込む。モデルの内容はそのファイルだけから来る |
| CMO3 で現在のモデルを置き換え | **モデル → CMO3 で現在のモデルを置き換え…**、またはスタートページの **CMO3 で置き換え…** | 現在のプロジェクトを保持し、ID に従ってモデルのオブジェクトを CMO3 のオブジェクトで置き換え、新しいオブジェクトを追加する。CMO3 にないオブジェクトはそのまま |
どちらの方法でもプリセットの自動生成は行いません。読み込み後は、パラメータとキーフォーム、デフォーマとレイヤーの階層、テクスチャとメッシュ、物理演算が保持されます。
## 注意事項
- 素材パネルでも CMO3 を読み込め、その中の分割済み画像を素材として使えます。
- Cubism で下絵として指定されたパーツは、moc3 の書き出し時に既定では書き出されません。必要な場合は書き出しウィンドウで **ガイド画像 Part を書き出す** をオンにします。
!> CMO3 から読み込んだモデルでは [[split-by-mesh]] と [[depth-split]] を使えません。
## Cubism との違い
- Cubism：`.cmo3` は Cubism Editor のネイティブなモデルファイルで、直接開いて編集します。
- PSD2Live：`.cmo3` は読み込み形式で、読み込み後は PSD2Live のプロジェクト（`.psd2live`）に変換されます。全体を読み込むことも、ID に従って現在のモデルのオブジェクトを置き換えることもできます。CMO3 を書き出せば、再び Cubism Editor で編集できます。

@@ texture-atlas-edit | テクスチャアトラス編集
テクスチャアトラスは、書き出し時にすべてのレイヤーのピクセルをまとめたテクスチャページです。PSD2Live では **テクスチャ** ワークスペースにアトラスが表示され、レイヤーごとにタイルの位置、密度、回転を調整し、ページの予算を設定できます。
## 3 種類のサイズ
各レイヤーには 3 種類のサイズがあります：キャンバス上で覆う矩形（キャンバス単位）、レイヤー自身のラスターのピクセル、アトラス内のタイルのピクセルです。**テクスチャ** パネルは選択レイヤーのこの 3 つを「キャンバス → 元画像 → アトラス」の 3 つの枠で並べて表示します。
## アトラスページでの操作
- タイルをクリックすると対応するレイヤーを選択し、空白部分をドラッグすると範囲選択します。選択はキャンバスとレイヤー一覧と同期します。
- **タイルをドラッグ** して位置を移動します。ほかのタイルのメッシュと重なるかページからはみ出すとタイルが赤く表示され、離しても移動しません。
- 選択したタイルの角をドラッグすると比率を保って密度を調整し、上辺の外にある丸いハンドルをドラッグすると回転します。{kbd:Shift} を押していると 15° 刻みになります。
- タイルを右クリックすると、密度の 2 倍 / 半分、90° 回転、ほかのページへの移動、サイズのロック、選択タイルの配置、画像の置き換えができます。
移動、拡大縮小、回転はまず調整セッションに入り、ページ上部にセッションバーが表示されます。取り消し、やり直し、**破棄** ができ、**適用** をクリックすると 1 ステップの履歴として確定します。
## 配置と予算
- 左上の **配置** は、メニューの選択に従って一度に配置して保存します：**メッシュ形状で（タイルを入れ子に）** または **矩形で**、範囲は **すべてのタイル** または **選択タイルのみ**。
- **自動配置** がオンの場合は変更のたびに矩形で配置し直します。オフの場合（新しいプロジェクトの既定）は現在のレイアウトを保ちます。
- 右上の **アトラス予算** でページサイズ、最大ページ数、間隔を設定します。「フィット」が 100% を下回るのは収まらないことを示し、ロックされていないすべてのタイルが一緒に縮小されます。**サイズをロック** したレイヤーはサイズを保ちます。
## テクスチャパネル
**テクスチャ密度** のスライダーと ½× / 2× / リセットのボタンで、元画像の 1 ピクセルあたりのアトラスのピクセル数（1/64–16）を調整します。レイヤーを選択していないときは、ページごとのサイズ、タイル数、使用率、VRAM の見積もりなどの概要が表示されます。
## Cubism との違い
- Cubism：テクスチャアトラス編集ダイアログでアートメッシュを手作業で配置・拡大縮小し、テクスチャサイズごとにアトラスを設定します。
- PSD2Live：アトラスはモデルとともに自動でまとめられ、テクスチャワークスペースでいつでも調整できます。重なりはメッシュが実際に覆う領域で判定されます。書き出しダイアログにはアトラスの概要だけが表示されます。
*> 編集キャンバス右下の表示バーの **元画像のピクセル** をオンにすると、キャンバスがレイヤー自身のラスターを直接サンプリングし、まとめたあとの精細さと比較できます。

@@ png-file-export-replacement | PNGファイルの書き出し差し替え
テクスチャを画像として書き出して外部ソフトで修正し、モデルに差し戻します。PSD2Live にはページ全体の書き出し、単一レイヤーの差し替え、PSD の書き出しの 3 つの方法があります。
## 書き出し
- **このページを PNG で保存…**：[[texture-atlas-edit]] のアトラスページの空白部分を右クリックします。書き出される内容は、書き出したモデルのテクスチャとバイト単位で一致します。
- **ファイル → 形式を指定して書き出し → 元の PSD…**（{key:REEXPORT_PSD}）：分割済み PSD を書き出します。1× または高解像度化の倍率を選べ、**生成された補助レイヤーを含める** こともできるので、描画ソフトでレイヤーごとに細かく修正できます。
- 素材パネルでフォルダーを右クリックして **フォルダを PSD に書き出し…**。
## 差し替え
1. 差し替えるレイヤーを選択します。
2. **テクスチャ** パネルで **画像を置き換え…** をクリックします（またはアトラスページでタイルを右クリック）。
3. フィット方法として **引き伸ばし** または **全体を収める** を選び、**新しいピクセルからメッシュを再構築** するかどうかを選びます。
新しい画像は任意の解像度でよく、キャンバス上の矩形は変わりません。大きな画像ほどレイヤーの密度が上がります。素材パネルの右クリックの **選択レイヤーの画像を差し替え** でも差し替えられます。
!> 作者の編集、バインド、実体化されたメッシュがあるレイヤーでは、画像を差し替えてメッシュを再構築する操作は拒否されます。理由はアトラスページの上部に表示されます。
## Cubism との違い
- Cubism：アトラスページごとに PNG を書き出し、修正後にページ全体を差し戻します。
- PSD2Live：ページ全体の PNG は出力専用です。差し替えはレイヤー単位で行い、アトラスは自動でまとめ直されるため、タイルの位置を保つ必要はありません。
*> 数か所のピクセルを直すだけなら、エディター内で [[paint-mode]] を使うほうが手軽です。

@@ texture-upscale | テクスチャ高解像度化
テクスチャ高解像度化は、アトラスにまとめる前にレイヤーごとにテクスチャを拡大する機能で、原画の解像度が低めの場合に向いています。既定ではオフで、元の PSD、キャンバスサイズ、リギングは変更しません。プレビューと書き出しには処理後のテクスチャが使われます。
## 設定
**モデル → テクスチャ高解像度化…**（{key:TEXTURE_UPSCALE}）を開くか、**テクスチャ** パネルで **テクスチャ高解像度化…** をクリックします。
| 項目 | 内容 |
|---|---|
| Python | nunif の依存関係をインストールした Python の実行ファイル |
| nunif ディレクトリ | `nunif` と `waifu2x` のサブディレクトリを含むローカルのソースディレクトリ |
| モデルディレクトリ | Art の `.pth` 重みを置いたディレクトリ |
| 倍率 | 1 でオフ。2× または 4× で拡大 |
| ノイズ除去 | -1 は拡大のみ。0–3 はノイズ除去レベルで、既定は 1 |
| ニューラル Alpha | 既定でオン。オフにすると Alpha をバイリニアで拡大する |
| 入力タイル | 64–512、既定は 256。VRAM が足りない場合は小さくする |
適用するとプレビューが再構築され、設定はプロジェクトと一緒に保存されます。別のコンピューターに移した場合はローカルのパスを確認し直す必要があります。
## 注意事項
- 配布パッケージには推論環境が含まれないため、Python、PyTorch、nunif と対応する重みを自分で用意する必要があります。
- 対応するモデルがない場合はエラーになり、通常の補間で代用はしません。
- ニューラル Alpha は半透明の輪郭を変えることがあります。明るい背景と暗い背景で、髪の毛、まつげ、唇の線、動いているときのマスクの縁を確認してください。

## Cubism との関係

@@ paint-mode | 描画モード
描画モードはレイヤーのピクセルを直接修正し、縁の修正、色の補足、消去に使います。ストロークはまず独立した描画セッションに保存され、確定してはじめて 1 ステップの履歴としてプロジェクトに書き込まれます。
## 描画を始める
1. キャンバスまたはレイヤー一覧でレイヤーを 1 つ選択します。
2. キャンバス左上のモードメニューで **描画**（{key:MODE_PAINT}）を選びます。
3. 左側のツールバーでツールを選び、左下のツールオプションバーでサイズ、硬さ、不透明度などの数値を調整します。
## ツール
| ツール | ショートカット |
|---|---|
| ブラシ | {key:TOOL_PAINT_BRUSH} |
| 鉛筆 | {key:TOOL_PAINT_PENCIL} |
| 消しゴム | {key:TOOL_PAINT_ERASER} |
| 塗りつぶし | {key:TOOL_PAINT_BUCKET} |
| スポイト | {key:TOOL_PAINT_EYEDROPPER} |
| 図形（直線 / 矩形 / 楕円） | {key:TOOL_PAINT_LINE}、{key:PAINT_SHAPE_CYCLE} で図形を切り替え |
ブラシサイズは {key:BRUSH_RADIUS_DOWN} / {key:BRUSH_RADIUS_UP}、硬さは {key:BRUSH_HARDNESS_DOWN} / {key:BRUSH_HARDNESS_UP}、不透明度は {key:PAINT_OPACITY_DOWN} / {key:PAINT_OPACITY_UP} で変えられ、{key:BRUSH_ADJUST_DRAG} でドラッグするとその場で調整できます。ツールオプションバーの先頭は前景色 / 背景色で、{key:AXIS_CONSTRAIN_X} で入れ替えます。
## 適用と破棄
最初のストロークを描くと、キャンバス上部中央にセッションバーが表示され、描画中のレイヤーとストローク数が示されます。取り消し、やり直し、**破棄**、**適用** ができます。「ツール詳細」パネルにも **変更を破棄** と **適用** があります。セッション中の {key:UNDO} はストロークだけを取り消します。
## メッシュの外に描いた場合
キャンバス全体に描けます。適用時にはレイヤーのメッシュで切り分けられます：メッシュ上の部分はレイヤーに残り、メッシュ、キーフォーム、バインドは変わりません。メッシュの外の部分は新しいレイヤーに分けられ、名前は元のレイヤー名に「+」を付けたものになり、元のレイヤーのすぐ上に置かれて同じ親に従って動きます。レイヤー自身のメッシュで新しく描いた範囲を覆いたい場合は、メッシュパネルで **現在のピクセルから再構築** をクリックします。
*> 素材に関連付けられたレイヤーでは描画は素材そのものに書き込まれ、その素材を使うすべてのレイヤーが一緒に変わります。[[layout-project]] を参照してください。

@@ parts | パーツについて
パーツはアートメッシュとデフォーマをまとめて分類する単位で、オブジェクトの整理、まとめての表示切り替え、書き出し時のグループ分けに使います。PSD2Live はモデル生成時に、認識したパーツの部位に応じてパーツを自動で作ります。
## 自動生成されるパーツ
ジェネレーターは「頭部」「後ろ髪」「顔」「前髪」「頭部アクセサリ」「その他」「身体」などのパーツを作り、レイヤーはタグに従って対応するパーツに入ります。認識できなかったレイヤーは「身体」に入ります。
## パーツと階層
PSD2Live の **階層** に表示されるのはデフォーマとアートメッシュの親子関係（変形の継承を決める）で、パーツのツリーではありません。パーツの所属は **インスペクタ** で確認します：アートメッシュを選択すると、**パーツ** のドロップダウンに所属するパーツが表示されます。
## Cubism との違い
- Cubism：PSD のフォルダーが読み込み後にパーツになり、パーツパレットでパーツとオブジェクトをツリー表示して編集します。
- PSD2Live：パーツは部位に応じて自動で作られ、PSD のフォルダー構造とは無関係です。独立したパーツパレットはなく、デフォーマの階層は階層で編集します。
- moc3 の書き出し時には、書き出しウィンドウの **非表示 Part を書き出す** で非表示のパーツを書き出すかどうかを決めます。
*> CMO3 から読み込んだモデルは元のパーツ構造を保持します。

@@ edit-parts | パーツの編集
このページでは、オブジェクトが所属するパーツを変更する方法を説明します。
## アートメッシュの所属パーツを変更する
1. キャンバスまたは階層でアートメッシュを選択します。
2. **インスペクタ** の **パーツ** ドロップダウンで移動先のパーツを選ぶか、**(なし)** を選んで最上位に移します。
変更は 1 ステップの履歴として記録され、取り消せます。
## デフォーマ作成時にパーツを指定する
オブジェクトモードで Warp を作成するとき、「ツール詳細」パネルの **挿入するパーツ** で新しいデフォーマの所属パーツを選びます。既定は **選択から継承** です。
## Cubism との違い
- Cubism：パーツパレットでパーツの新規作成、削除、名前の変更を行い、オブジェクトをドラッグして所属を変えます。
- PSD2Live：パーツはジェネレーターが作り、画面上で変更できるのはアートメッシュと新規デフォーマの所属パーツだけです。デフォーマの親子関係は **階層** でドラッグして変更します。[[partspalatte]] を参照してください。

@@ edit-parts-sketch | 下絵パーツ
原画や下書きなど、見比べるためだけの画像は参照に設定できます。キャンバスには表示されますが、生成には使われず、書き出しもされません。PSD2Live では「参照レイヤー」が Cubism の下絵パーツの役割を果たします。
## 参照に設定する
1. レイヤーを選択します。
2. 「レイヤー」パネルのツールバーの **参照として扱う** をクリックするか、{key:LAYER_TOGGLE_REFERENCE} を押します。キャンバスの右クリックメニューにも **参照として扱う** の切り替えがあります。
参照レイヤーの名前の後ろには参照アイコンが付き、クリックするとモデルのレイヤーに戻ります。生成済みのレイヤーは参照に設定できません。戻した参照レイヤーは次回の生成でモデルに加わります。
## 表示
参照レイヤーは既定でモデルの下に敷かれます。キャンバス右下の表示バーの **参照レイヤーを上に表示** でモデルの上に重ねられます。異なる角度の参照は右クリックの **キーフォームに固定** で、対応するパラメータ値のときだけ表示できます。
## Cubism との違い
- Cubism：パーツを下絵パーツに設定し、書き出し時には書き出されません。
- PSD2Live：パーツ単位ではなくレイヤー単位で設定します。参照レイヤーは生成にも使われず、書き出しもされません。
- CMO3 から読み込んだモデルの下絵パーツは、moc3 の書き出し時に既定では書き出されません。書き出しウィンドウで **ガイド画像 Part を書き出す** をオンにすると書き出されます。
新しい下絵の配置は [[sketch]] を参照してください。

@@ variants | 差分
差分はパラメータに応じてレイヤーを表示、非表示、または相互に切り替えるもので、頬の赤み、涙、眼鏡など「有 / 無」のパーツや、表情、手、衣装など「どれか 1 つ」の造形に使います。「レイヤー」パネルの **差分** 列で設定します。
## 差分の種類
| 種類 | 役割 | 用途 |
|---|---|---|
| 差分なし | タグに従って対応するパーツを生成する | 通常のレイヤー |
| 差分トグル | 1 つのパラメータでそのレイヤーの表示・非表示を制御する | 頬の赤み、涙、眼鏡、光と影 |
| 差分切替 | 同じパラメータで、一度に 1 つの ID に対応するレイヤーだけを表示する | 表情、手、衣装 |
## 差分トグルを設定する
1. 「レイヤー」パネルでその行の **差分** を **差分トグル** にします。
2. **パラメータ連動** にパラメータ名（`blush` など）を入力します。同じパラメータ名で複数のトグルレイヤーを駆動できます。
## 差分切替を設定する
1. 関係するレイヤーをすべて **差分切替** にします。
2. **パラメータ連動** に同じパラメータ名を入力します。ドロップダウンから既存の切替パラメータを選ぶこともできます。
3. 横の ID を順に 0、1、2… に設定します。たとえば `expression`：0 通常 / 1 笑顔。
対応するパラメータをドラッグすると、編集とプレビューで効果を確認できます。
!> レイヤー名の数字では差分は自動で作られません。差分トグルにはパラメータの指定が必要で、差分切替ではパラメータを共有して異なる ID を設定する必要があります。

## Cubism との関係
Cubism では、差分は通常アートメッシュの不透明度をパラメータ上のキーフォームで切り替えて実現します。PSD2Live の差分はレイヤー上で宣言し、生成時に対応するパラメータと表示制御が自動で作られます。ツリーでの一時的な単独表示は編集中の確認用で、差分とは異なります。

@@ artmesh | アートメッシュ
@@ concept-of-artmesh | アートメッシュについて
アートメッシュ（ArtMesh）は、頂点と三角形からなるメッシュにテクスチャを貼ったオブジェクトで、頂点を動かすと画像が変形します。PSD の各レイヤーは読み込み後に 1 つのアートメッシュになります。
## メッシュの構成
- 頂点：メッシュ上の点で、変形時に動かす対象です。
- 辺と三角形：頂点をつなぎ、頂点に応じて画像がどう伸びるかを決めます。
- 輪郭：レイヤーの不透明なピクセルの縁に沿います。メッシュの外のピクセルは表示されません。
頂点が密なほど変形は細やかになりますが、編集時と実行時の負荷も大きくなります。PSD2Live は読み込み時にレイヤーの Alpha に従ってメッシュを自動生成します。[[mesh-edit]] を参照してください。部分的に調整する場合は [[mesh-edit-manual]] を参照してください。
## プロパティ
アートメッシュを選択すると、**インスペクタ** に名前、ID、パーツ、デフォーマ、クリップ ID、反転マスク、描画順、不透明度、乗算色、スクリーン色、ブレンドモード、カリング、ユーザーデータが表示されます。
{tutorial=LIVE2D_BRIDGE}
*> ワープデフォーマ（Warp）と回転デフォーマはアートメッシュを全体として変形させます。[[deformer]] を参照してください。

@@ mesh-edit | メッシュの自動生成
PSD2Live は PSD の読み込み時に各レイヤーのメッシュを自動生成します：まずレイヤーの Alpha に沿って輪郭をなぞり、設定に従って縁の点と内部の点を配置して三角形分割します。メッシュの密度と形状は **メッシュ** パネルの設定で決まり、全体に設定することも、パーツごとに上書きすることもできます。
## メッシュパネル
**メッシュ** ワークスペースまたは **ウィンドウ** メニューから **メッシュ** パネルを開きます：
- **グローバル既定** は、個別に上書きしていないすべてのパーツに適用されます。
- ArtMesh を選択すると、パネルにそのパーツ自身の設定が表示され、変更するとそのパーツに「カスタム設定」と表示されます。
- メッシュが一部の可視ピクセルを覆っていない場合は、パネルにその割合が表示されます。**現在のピクセルから再構築** をクリックすると含められます。
## 主な設定
| グループ | 設定 | 役割 |
|---|---|---|
| 輪郭の位置 | 単層 / 2 層 / 3 層の縁、外縁の距離、縁のメッシュ幅 | 輪郭付近に頂点を何周置くかとその位置 |
| 点の密度 | 縁の点の距離、内部の密度 | 輪郭の頂点間隔と内部の点の間隔 |
| 内部の充填アルゴリズム | 漸減ポアソン充填（既定）、バランス四分木充填、正三角形フラクタル分割、輪郭レイヤー敷き詰め、単純三角形充填 | 内部の点の並べ方 |
| 接続トポロジー | 縁の点同士をまたぐ接続線を抑制 | 隣接しない縁の点を内部の点経由でつなぐ |
| 単位 | ドキュメントサイズに合わせる、テクスチャのピクセルで輪郭をなぞる、包み込み | 長さの単位、輪郭をなぞる精度、閉じたまつげなど細い突起の間の隙間 |
設定を変更するとメッシュが再構築され、既存のキーフォーム、パス、ウェイト、グルーは新しいメッシュに移行されます。
## Cubism との違い
- Cubism：読み込み後、選択したアートメッシュに対してメッシュの自動生成を実行し、プリセットから選んで余白と点の間隔を調整します。
- PSD2Live：読み込み時にすべてのレイヤーのメッシュが生成済みで、設定はグローバル既定とパーツごとの上書きとして保存され、いつでも変更・再構築できます。
- PSD2Live には多層の縁と複数の内部充填アルゴリズム、テクスチャのピクセルでの輪郭なぞりと包み込みトポロジーがあります。
*> 設定パネルの **説明を表示** で各オプションの説明を展開できます。

@@ mesh-edit-manual | メッシュの手動編集
自動生成されたメッシュが合わない場合は、**編集** モードでメッシュのトポロジーを手動で修正できます：再分割、接続、結合、複製、削除、切断です。トポロジーを修正すると、UV、キーフォーム、ブレンドシェイプ、グルーの頂点参照も同時に更新されます。
## 編集モードに入る
1. アートメッシュを 1 つ以上選択します。
2. モードメニューで **編集**（{key:MODE_EDIT}）を選びます。編集モードではメッシュが表示されます。
3. モードバーで点 / 辺 / 面（{key:PICK_OPTION_1}–{key:PICK_OPTION_3}）を選び、選択ツールで選ぶ要素を決めます。
## 操作
| 操作 | 結果 |
|---|---|
| 再分割（{key:TOOL_SUBDIVIDE}） | 当たった辺に点を追加して三角形を組み直す。隣接する面の継ぎ目も同時に処理する |
| 接続 / 結合 | 選択した点の間に接続を作るか、選択した頂点を 1 点にまとめる |
| 複製 | 選択した頂点とそれが完全に覆う面を複製し、新しい複製が選択範囲になる |
| 削除（{key:DELETE_SELECTION}） | 選択範囲を削除し、穴の再構築を試みる。正しいトポロジーを作れない場合は拒否する |
| ナイフ（{key:TOOL_KNIFE}） | 点を順に指定して折れ線を作る。点や辺に近づくとスナップし、{kbd:Shift} で一時的にスナップをオフにする。{key:FINISH_PATH} で完了、{key:CANCEL} でキャンセル |
## 複数メッシュの編集
編集モードは選択したすべてのアートメッシュに同時に作用します。あるメッシュの頂点をクリック選択するとそのメッシュがメインメッシュになり、ナイフと辺 / 面の選択はメインメッシュにだけ作用します。
{tutorial=EDIT_MODE}
## Cubism との違い
- Cubism：メッシュの手動編集モードで頂点を 1 つずつ追加・削除して線をつなぎ、終わったらモードを抜けて確定します。
- PSD2Live：再分割や切断などのトポロジー操作で既存のメッシュを修正し、各操作は直接履歴に入ります。キーフォームがすでにあるメッシュでも修正できます。
!> 輪郭の点を削除すると境界が変わります。修正後は複数のパラメータのポーズで確認してください。日常的な形の調整は変形モードで行ってください。

@@ clipping-mask | クリッピングマスク
クリッピングマスクは、アートメッシュを別のアートメッシュの範囲内だけに表示させます。たとえば瞳を白目の中だけに表示します。
## 設定
1. マスクされるアートメッシュを選択します。
2. **インスペクタ** の **クリップID** でマスクとなるアートメッシュを指定します：ID を直接入力する（複数はカンマ区切り）、リストボタンの **リストからクリッピングマスクを選択** をクリックする、または照準ボタンの **キャンバスからマスクを関連付け** をクリックしてからキャンバスでマスクのアートメッシュをクリックします。
1 つのアートメッシュを複数のマスクで同時に制限できます。
*> モデル生成時には、よく使うマスクが自動で設定されます：瞳は同じ側の白目で、歯や舌など口の中のパーツは口でマスクされます。反転の効果は [[reversed-mask]] を参照してください。

@@ reversed-mask | マスクの反転
反転マスクは、アートメッシュをマスクの範囲の外だけに表示させます。[[clipping-mask]] と逆の効果です。
## 設定
1. **クリップID** を設定済みのアートメッシュを選択します。
2. **インスペクタ** の **反転マスク** をオンにします。
変更は 1 ステップの履歴として記録され、取り消せます。

@@ sketch | 下絵の配置
原画、下書き、ほかの角度の参照画像をキャンバスに置いて見比べます。参照に設定したレイヤーはキャンバスに表示されますが、生成には使われず、書き出しもされません。
## 下絵を配置する
1. 素材パネルで参照画像を **読み込み** ます。
2. 素材を右クリックして **参照レイヤーとして配置** を選びます。**既定で参照として配置** をオンにすると、その素材からキャンバスにドラッグしたレイヤーはすべて参照レイヤーになります。
3. 変形ボックスで位置とサイズを調整します。
すでにキャンバス上にあるレイヤーは、「レイヤー」パネルのツールバーの **参照として扱う** または {key:LAYER_TOGGLE_REFERENCE} で切り替えられます。[[edit-parts-sketch]] を参照してください。
## ポーズに応じて表示する
異なる角度の参照（正面、横、あおり）を同じ位置に重ね、それぞれ対応するキーフォームでだけ表示できます：
1. 参照レイヤーを右クリック → **キーフォームに固定**。
2. メニューに固定する価値のあるパラメータと現在値が並びます。ピンをクリックするとその値で固定または解除します。**現在のポーズに固定** で並んだパラメータをまとめて固定し、**固定を解除** でどのポーズでも表示される状態に戻します。
## Cubism との違い
- Cubism：下絵の配置機能で画像を下絵パーツとしてモデルに追加します。
- PSD2Live：下絵は素材で、配置すると参照レイヤーになり、キーフォームに固定して対応するポーズでだけ表示できます。
- 参照レイヤーは既定でモデルの下に敷かれ、キャンバス右下の表示バーの **参照レイヤーを上に表示** で上に重ねられます。

@@ blend-mode | ブレンドモード
ブレンドモードは、アートメッシュの色を下にすでに描かれた内容とどう合成するかを決めます。
## 設定
アートメッシュを選択し、**インスペクタ** の **ブレンドモード** で選びます：
| モード | 効果 |
|---|---|
| 通常 | 通常どおり上に重ねる |
| 乗算 | 下の色と掛け合わせる。影に使う |
| 加算 | 下の色に加える。発光やハイライトに使う |
## PSD 読み込み時
PSD レイヤーのブレンドモードは読み込み時に変換されます：覆い焼き（リニア）- 加算などの加算系モードとリニアライトは加算に、乗算、焼き込み（リニア）、焼き込みカラーは乗算に、それ以外は通常として扱います。
## Cubism との違い
- Cubism 5.3 以降ではより多くのブレンドモード（スクリーン、オーバーレイなど）があり、オフスクリーン描画と組み合わせられます。
- PSD2Live のインスペクタには通常、乗算、加算の 3 種類だけがあります。オフスクリーン描画はまだありません。
*> ブレンドの方法を変えずに色を調整したい場合は、インスペクタの **乗算色** と **スクリーン色** を使えます。

@@ interior-shape | 内部造形
内部造形は任意で使えるメッシュのキーフォームジェネレーターです。レイヤー内部のテクスチャを仮想の曲面に沿って伸縮・偏らせ、服や髪などの大きなパーツが回転するときに立体感を持たせます。新しいテクスチャや影は生成せず、布のシミュレーションでもありません。
## 使い方
1. 生成済みのレイヤーを選択し、**内部造形** パネルを開きます。
2. **有効** をオンにすると、プログラムが内部造形を生成して試し動かしを始めます。
3. **造形** で横 / 縦の量、曲面の膨らみ、偏り、折り目の強さ、輪郭の保持を調整します。
4. 動きにイージングが必要な場合は **追従・伝達** を開き、イージング時間、伝達時間、伝達の強さ、**伝達方向** を設定します。
5. **試し動かし** で 2 次元のパラメータパッドをドラッグするか **マウス追従** をオンにして効果を確認します。**単独表示・中央** はこのレイヤーだけを表示してキャンバスの中央に置きます。
ドラッグを終えると履歴が 1 件記録されます。生成に失敗した場合は、下書きとそれ以前の有効な結果が保持されます。
## 設定
| 設定 | 範囲 | 意味 |
|---|---|---|
| 横 / 縦の量 | 0–2 | 2 方向それぞれの造形の総量 |
| 曲面の膨らみ / 偏り | 0–2 | 仮想のアーチ面とその偏りの度合い。どちらかが 0 なら曲面の変位はない |
| 折り目の強さ | 0–2 | **局所折り目** の寄与。局所折り目がなければ効果はない |
| 輪郭の保持 | 0–1 | 0 で見える輪郭を解放し、1 で原画の輪郭を守る |
| イージング時間 | 0–0.6 秒 | 第 1 段階の応答時間 |
| 伝達時間 | 0–0.5 秒 | 後方の領域が前方の領域に対して伝わる時間 |
| 伝達の強さ | 0–1 | 後方の領域の重み。0 で領域を分けない |
**詳細設定** の横 / 縦のマウス倍率はマウスでの試し動かしにだけ影響し、キーフォームの量や書き出されるパラメータの範囲は変えません。**入力パラメータ** では既存のパラメータか **新規パラメータ** を選べます。
## 注意事項
- **有効** をオフにすると設定は残りますが、変形は適用されません。**効果を削除** はレシピとその物理演算を取り除き、取り消せます。
- メッシュ、素材、入力パラメータが変わると、パネルに再生成または再バインドの案内が出ます。無効になった効果は書き出し時にスキップされ、警告に一覧表示されます。
- イージングにはプロジェクトの物理演算グループを使い、標準の物理演算設定として書き出されます。
## Cubism との関係
Cubism で同様の立体感を出すには、複数のパラメータキーでメッシュの頂点を手作業で調整するか、デフォーマを組み合わせる必要があります。内部造形はこれらの変形を自動生成し、Cubism ネイティブのブレンドシェイプと物理演算設定として書き出します。

@@ deformer | デフォーマについて
デフォーマは、アートメッシュをまとめて変形させる「入れ物」です。メッシュはデフォーマの下に置かれ、デフォーマがパラメータに応じて形を変えると、その下のメッシュや子デフォーマも一緒に変形します。PSD2Live には Cubism と同じく 2 種類のデフォーマがあります。ワープデフォーマ（Warp）と回転デフォーマ（Rotation）です。
## 2 種類のデフォーマ
| 種類 | 画面上の名前 | 働き | 向いている用途 |
|---|---|---|---|
| ワープデフォーマ | ワープデフォーマ / Warp | 制御点の格子で子オブジェクトを包み、制御点を動かすと中身がなめらかに変形する | 顔の向き、体の曲げ、髪の揺れ |
| 回転デフォーマ | 回転デフォーマ / Rotation | 原点を中心に全体を回転させる（拡大縮小も可）。子オブジェクトは剛体のまま | 腕、首、アクセサリーなど関節で回る部品 |
## PSD2Live で確認する
- 階層ツリーにはデフォーマとアートメッシュが親子関係に沿って並び、クリックはキャンバスの選択と同期します。
- キャンバス右下の表示バーにある「デフォーマ Warp」「回転デフォーマ Rotation」スイッチで、キャンバス上のデフォーマの表示を切り替えます。
- PSD を読み込むと、レイヤーの分類に沿ってデフォーマ構造一式（体、頭、顔、髪など）がすでに生成されているので、通常はゼロから組む必要はありません。[[auto-generation-of-deformer]] を参照してください。
*> ワープデフォーマは変形モードで「頂点」と「ベジェ」の 2 つの編集レベルを切り替えられます。[[making-and-placement-of-warp-deformer]] を参照してください。

@@ making-and-placement-of-warp-deformer | ワープデフォーマ
ワープデフォーマ（Warp）は Cubism のワープデフォーマにあたります。行×列の制御点の格子で選択したオブジェクトを包み、制御点を動かすとオブジェクトがなめらかに曲がります。PSD2Live ではキャンバス上で枠をドラッグして作成し、配置プレビューがそのまま最終的な格子になります。
## 作成
1. 階層ツリーまたはキャンバスで、デフォーマに入れたいアートメッシュを選択します（複数選択する場合は同じ親デフォーマを持っている必要があります）。
2. オブジェクトモードの左ツールバーの最後のグループで「Warp作成」（{key:TOOL_CREATE_WARP}）を選びます。キャンバスの右クリックメニュー「作成」から選ぶか、階層ツリーの右クリックで「親 · ワープ」/「子 · ワープ」を選ぶこともできます。
3. キャンバス上で矩形をドラッグします。ドラッグ中にホイールで変換の分割数を切り替えます。「選択範囲から作成」を押して、選択したオブジェクトの範囲からそのまま生成することもできます。
4. 左下の配置パネルで追加先、挿入するパーツ、サイズを確認します。枠内をドラッグすると移動、角や辺の中点をドラッグすると拡大縮小します。
5. モードバーの「作成」を押すか {key:FINISH_PATH} でプロジェクトに書き込みます。「キャンセル」または {key:CANCEL} で破棄します。
## 配置オプション
| オプション | 内容 |
|---|---|
| 追加先 | 選択オブジェクトの親にする / 選択デフォーマの子にする（空）/ 親デフォーマを指定 |
| 挿入するパーツ | 新しいデフォーマを入れるパーツ。デフォルトは選択範囲のパーツを引き継ぐ |
| サイズ | 選択に合わせる（+5%）/ キーフォーム包絡を含める / 選択の中心に合わせる |
| 連続作成 | 作成後、続けて次のデフォーマを配置する |
## 編集レベル
変形モードで対象がワープデフォーマの場合、モードバーで「頂点」と「ベジェ」を切り替えられます（数字キー 1 / 2）。頂点レベルでは格子の点を編集します。ベジェレベルではシアンのアンカーと琥珀色のハンドルだけをドラッグでき、細かい格子は薄く表示されて編集できません。インスペクタではベジェの分割数、「ベジェ制御点をリセット」、「デフォーマ変換(3.2方法)」を設定できます。
## Cubism との違い
- Cubism ではダイアログで名前と分割数を入力して作成します。PSD2Live ではキャンバス上で枠をドラッグして作成し、分割数はドラッグ中にホイールで調整し、追加先とサイズは配置パネルで選びます。
- Warp の配置枠は矩形で作成され、移動と拡大縮小のみ可能で、回転はできません。
- 「ツール詳細」パネルに Warp / Rotation の作成時のデフォルト値が保存されます。モデルプリセットにも、キャンバスでデフォーマを作成するときのデフォルトの分割数があります。
{tutorial=CREATE_DEFORMER}

@@ making-and-rotation-of-rotationdeformer | 回転デフォーマ
回転デフォーマは、その下のオブジェクトを 1 つの原点の周りでまとめて回転させます。腕、首、アクセサリーなど関節で回る部品に向いています。形は原点、角度、拡大率で決まり、パラメータがどの値でも正確な剛体回転になります。
## 作成
1. 回転させたいアートメッシュまたはデフォーマを選択します。
2. オブジェクトモードのツールバーで「回転作成」（{key:TOOL_CREATE_ROTATION}）を選ぶか、キャンバスの右クリックメニュー「作成」、階層ツリーの右クリック「親 · 回転」から選びます。
3. キャンバス上で回転の中心から方向の端点へドラッグします。Shift を押すと角度が 15° 単位でスナップします。
4. 新しいデフォーマは選択したオブジェクトの直接の親として挿入されます（元の親は保たれます）。キャンバスには付け替わるオブジェクトがハイライト表示され、配置パネルには影響するデフォーマとアートメッシュの数が表示されます。
5. {key:FINISH_PATH} を押すか「作成」で確定し、{key:CANCEL} でキャンセルします。
## 編集
変形モードで、原点をドラッグすると平行移動、端点をドラッグすると回転します。デフォルトでは Shift で角度をスナップし、Alt + 端点ドラッグで拡大率を調整します。回転デフォーマには変形ブラシを使えないので、移動、回転、拡大縮小ツールを使ってください。
## Cubism との違い
- Cubism ではまずダイアログで作成してから位置を調整します。PSD2Live では 1 回のドラッグで原点と向きを同時に決め、選択したオブジェクトの親として自動で挿入します。
- ハンドルの向きは Cubism の慣例に従い、0° で上向き、時計回りが正です。
- ボーンのベイクでは、四肢、しっぽ、翼に回転デフォーマが自動生成されます。[[skeleton]] を参照してください。
{tutorial=CREATE_DEFORMER}

@@ system-of-parent-child-relation | 親子関係の仕組み
オブジェクトは、置かれているデフォーマに従って動きます。これが親子関係です。子オブジェクトの形は親のローカル空間で評価されるため、親が変形すると子はまとめて運ばれ、その上に子自身のキーフォームが重なります。
## 継承のルール
- ワープデフォーマの下のオブジェクト：形全体が親の格子と一緒に曲がります。
- ワープデフォーマの下のワープデフォーマ：子デフォーマの制御点が親によって変換され、内部は自分の格子で補間されます。
- ワープデフォーマの下の回転デフォーマ：原点の位置と角度だけを継承し、親の非剛体な曲げはその下に伝わりません。
- 回転デフォーマの下のオブジェクト：原点に合わせて剛体として回転します。
## 親と直接の割り当て
オブジェクト自身に割り当てられたパラメータはそのオブジェクトの形を決め、親のパラメータは階層を通じて伝わります。編集時には、変えたいのがオブジェクト自身の軸なのか親から来る動きなのかを先に確認し、親のポーズをオブジェクトの直接の割り当てと取り違えないようにします。
*> 階層ツリーの「親」バッジは、選択したオブジェクトの祖先を示します。
関連：[[setting-of-parent-child-relation]] · [[combintion-of-parent-child-relation]] · [[keyform-parent-chilid-relation]]

@@ setting-of-parent-child-relation | 親子関係の設定
オブジェクトをどのデフォーマの下に置くかを設定します。PSD2Live では主に階層ツリーでのドラッグで設定し、デフォーマの作成時に追加先を直接指定することもできます。
## 階層ツリーで設定する
1. 階層ツリーでアートメッシュまたはデフォーマの行を押さえます。
2. 目的のデフォーマの上にドラッグして離すと、その下に入ります。「最上位へ移動」の領域にドラッグするとルートへ移動します。
3. 親の変更は 1 ステップの履歴で、元に戻せます。
## そのほかの入口
- 階層ツリーの右クリック：「親 · ワープ」「子 · ワープ」「親 · 回転」で、選択したオブジェクトの上または下に新しいデフォーマを挿入します。デフォーマを削除すると子は上の階層に移ります。
- Warp 作成時の「追加先」：選択オブジェクトの親にする / 選択デフォーマの子にする（空）/ 親デフォーマを指定。
- インスペクタには、オブジェクトが属するパーツとデフォーマが表示されます。
!> 透明な画像を階層ツリーにドラッグするのはレイヤーの読み込みで、親の変更とは別の操作です。
## Cubism との違い
- Cubism ではインスペクタや「親の設定」ダイアログで親を選びます。PSD2Live では階層ツリーのドラッグ＆ドロップが中心で、デフォーマの作成時に親子関係も同時に指定できます。
- 生成されたモデルで親を変更したあとに再生成（モデルプリセットやスケルトンの変更など）しても、変更は 3 方向マージで保持されます。[[update-generated-rig]] を参照してください。
{tutorial=HIERARCHY}

@@ combintion-of-parent-child-relation | 親子関係の組み合わせ
複数のデフォーマを入れ子にすると、複雑な動きをいくつかの単純な動きの層に分けられます。外側の層が大きな向きの変化を、内側の層が局所的な曲げや回転を担当し、各層は必要なパラメータだけを割り当てます。
## 生成モデルでの組み合わせ
PSD2Live が生成する体はこのように層に分かれています：
1. `DeformBodyXY`：体 X / Y。上半身全体の向きと、腰に合わせた移動。
2. `DeformBodyLean`：体の前後傾と頭身（デフォルメ）。
3. `DeformBodyZBreath`：体 Z と呼吸。
4. その下に頭の回転と顔の経緯格子、さらにその下に顔パーツと髪があります。
各層は自分のパラメータだけを処理し、下の層は上の層の動きを自動で継承します。たとえば頭の回転は体の向きにも同時に引っ張られます。実際の構造は階層ツリーで確認してください。
## 組み合わせるときの注意
- 粗い格子の上位デフォーマは下位の形を再サンプリングするため、細かい曲げはメッシュに最も近い層に置きます。
- ワープデフォーマの下の回転デフォーマは原点と角度しか継承しないので、曲げに追従させたい部品はワープデフォーマの下に置きます。
*> スケルトンを有効にすると、胴体の曲げと四肢の回転デフォーマがこのチェーンの末端につながります。[[skeleton]] を参照してください。

@@ auto-generation-of-deformer | デフォーマの自動生成
PSD2Live は PSD を読み込むと、レイヤーの分類に沿ってデフォーマ、パラメータ、キーフォーム一式を自動生成します。Cubism のように 1 つずつ作成したりテンプレートを適用したりする必要はありません。
## 自動生成される内容
- 体のチェーン：体 X/Y、前後傾、体 Z と呼吸。立ち姿の全身キャラクターには脚のデフォーマも加わります。
- 頭：頭の回転と頭殻の追従、顔の経緯格子、顔の輪郭と顔パーツの移動。[[face-auto-edit]] を参照してください。
- 髪：前髪と後ろ髪の追従と揺れの分岐。別途 [[auto-generation-of-sway-motion]] やシミュレーションを生成することもできます。
- スケルトン（有効時）：胴体の曲げと四肢の回転デフォーマ。[[skeleton]] を参照してください。
## 生成結果の調整
1. 「モデルプリセット」パネルで変形の幅やリグの数値などを調整すると、モデルがそれに合わせて再生成されます。
2. 生成結果に対して行った編集は、新しい生成結果にマージされて保持されます。
3. 新しいバージョンのジェネレーターの改良を取り込みたいときは、「モデル → 生成結果を更新」を使います。
## 手動作成時の自動サイズ
「Warp作成」で「選択範囲から作成」を押すか、配置パネルでサイズ（選択に合わせる / キーフォーム包絡を含める / 選択の中心に合わせる）を選ぶと、デフォーマは選択したオブジェクトに合わせて自動でサイズが決まります。
## Cubism との違い
- Cubism の自動生成は、選択したオブジェクトに対して単一のデフォーマ構造を作ります。PSD2Live は読み込み時にモデル全体のデフォーマチェーンとキーフォームを一度に生成します。
- 生成される構造はモデルプリセットによって変わります。具体的なオブジェクトは階層ツリーで確認してください。
関連：[[model-presets]] · [[update-generated-rig]] · [[psd-import]]

デフォーマ構造を確認するときは、あるオブジェクトがどこに置かれ、どのデフォーマやパラメータの影響を受けているかを知る必要がよくあります。PSD2Live では、これらの情報をキャンバスの表示バー、階層ツリー、パラメータパネルにまとめています。

| 階層ツリー | 選択オブジェクトの祖先を示す「親」バッジ、デフォーマとレイヤーの検索、すべて展開 / 折りたたみ |

## Cubism との違い

@@ parameter | パラメータについて
パラメータは、角度 X や目の開閉のように、モデルの動きを駆動する数値スライダーです。オブジェクトはパラメータのいくつかのキーごとに形（キーフォーム）を 1 つ記録し、パラメータが中間の値をとると形が自動で補間されます。アニメーションも物理演算も、最終的には時間に沿ってパラメータの値を変えています。
## パラメータパネル
| 操作 | 方法 |
|---|---|
| 値を変える | スライダーを左ドラッグ |
| キーにスナップ | キーマークにホバーして右クリック |
| 2D 操作 | 2 つのパラメータを結合すると 2D パッドになる。左ドラッグで操作し、右クリックで 2 つのパラメータのキーの交点にスナップ |
| リセット / ロック | 行内のリセットボタン、パラメータ値のロック、ツールバーの「すべてデフォルト値にリセット」「すべてロック解除」 |
| 検索 | 名前またはパラメータ ID で検索。「関連のみ」で選択したコンポーネントに割り当てられたパラメータだけを表示 |
| 設定 | パラメータ名をクリックして「パラメータ設定」を開く |
## キーのマーク
- 丸：通常のキー。キーとキーの間は補間されます。
- 四角：ブレンドシェイプのキー。形の差分を基本の形に加算します。[[blend-shape]] を参照してください。
- キーマークにホバーすると、そのキーにキーフォームを持つコンポーネントが一覧表示されます。
- 物理演算アイコンの付いたパラメータは物理演算の出力パラメータで、プレビューでは物理演算が制御します。
!> パラメータ上のキーはモデリングのデータで、アニメーションのタイムライン上のキーフレームとは別物です。
*> PSD2Live のパラメータ操作は Cubism とほぼ同じです。複数のキャンバスは同じパラメータのポーズを共有します。
{tutorial=PARAMETERS}

@@ edit-parameters | パラメータにキーを追加・削除
PSD2Live では、キーの位置はパラメータ側で定義され、そのパラメータを割り当てたすべてのオブジェクトで共有されます。オブジェクトがあるキーで変更されると、その形がそのキーに記録されます。
## パラメータのキーを編集する
1. パラメータパネルでパラメータ名をクリックし、「パラメータ設定」を開きます。
2. 「キーポイント」軸で、空いている所をクリックすると点を追加し、ドラッグで値を調整します。数字をクリックすると直接変更でき、Enter で確定します。右クリックで削除します。
3. 「ステップ」はドラッグ時のスナップ間隔を、「等分」はキーポイントを均等に配置します。軸の両端で最小値、デフォルト値、最大値を直接入力できます。
4. 「キー編集を戻す」「キー編集をやり直す」で戻し、「保存」で一度にコミットします。
## オブジェクトにパラメータを割り当てる
1. オブジェクトを選択します。
2. パラメータパネルでパラメータを目的のキーの値までドラッグ（または右クリックでキーにスナップ）すると、パネルで操作したパラメータが編集対象になります。
3. 変形モード（{key:MODE_DEFORM}）に切り替えて形を変更すると、結果がそのキーのキーフォームに書き込まれます。
!> キーを移動すると、既存のキーフォームもキーと一緒に移動します。キーを削除すると、各オブジェクトのそのキーの形も一緒に削除されます（元に戻せます）。
## Cubism との違い
- Cubism ではオブジェクトを選択してから「2点追加 / 3点追加」などのボタンでそのオブジェクトだけにキーを追加します。PSD2Live では「パラメータ設定」でパラメータのキーポイントをまとめて編集し、オブジェクトはキー上で変形することで形を記録します。
- パラメータを新規作成しただけでは動きは生まれません。キー上でオブジェクトの形を作る必要があります。
{tutorial=PARAMETERS}

@@ parameter-modifyication | パラメータの調整
「パラメータ設定」でパラメータの名前、範囲、キーを変更し、パラメータパネルでパラメータのグループと表示を整理します。
## パラメータ設定
1. パラメータパネルでパラメータ名をクリックし、「パラメータ設定」を開きます。
2. 「名前」を変更します。ID は新規作成時のみ編集できます。
3. 「キーポイント」軸の両端で最小値、デフォルト値、最大値を変更します。デフォルト値は範囲内である必要があります。
4. 「パラメータ値をロック」でプレビューを現在の値に保ちます。
5. 「複製」は同じ名前と範囲で新しいパラメータを作成します（コンポーネントの割り当てと変形データは複製されません）。「パラメータを削除」は関連するキーフレームと連動関係も一緒に削除します。
6. 「保存」を押します。
## グループと結合
- ツールバーでパラメータまたはフォルダを新規作成します。フォルダを右クリックすると、ここにパラメータ / フォルダを作成、ラベル色の設定、名前の変更、フォルダの解除ができます。
- 行内の結合ボタンでパラメータを次の項目と結合して 2D コントローラにします。「結合を解除」で独立したスライダーに戻ります。2D パッドの高さはドラッグで調整できます。
!> パラメータの範囲を狭めると、アニメーション内のキーの値とベジェ制御点も合わせて制限されます。パラメータを削除すると、対応するアニメーションのトラックも削除されます。
*> パラメータ定義の変更は 1 ステップの履歴で、元に戻せます。

PSD2Live では、Cubism のパラメータ値のコピー / 貼り付けの代わりに「パラメータスナップショット」でパラメータ値の組を保存・復元します。スナップショットはモデルの現在のすべてのパラメータ値を記録し、いつでも読み込めます。
## パラメータスナップショットを使う
1. パラメータパネルでパラメータを目的のポーズに合わせます。
2. スナップショットバーの「現在のパラメータをスナップショットとして保存」を押すと、新しいスナップショットが「スナップショット n」という名前で作られます。
3. スナップショットにホバーするとキャンバスでそのポーズをプレビューでき、クリックで読み込み、中クリックで削除します。
4. スナップショットを右クリックすると「現在の値で上書き」「名前を変更」「削除」ができます。
## ボーンのポーズ
ボーンモードの「ボーンのポーズ」ツールでは、「ツール詳細」で現在のモデルのパラメータを名前を付けて保存し、再び適用できます。アニメーションエディターの「保存ポーズを挿入」は、それを再生ヘッドの位置に挿入します。[[skeleton]] を参照してください。
## Cubism との違い
- Cubism では選択したパラメータの値をコピーして別の場面に貼り付けます。PSD2Live で保存するのはパラメータのポーズ一式で、読み込むと全体が復元されます。
- スナップショットと名前付きポーズはパラメータの値を変えるだけで、モデルは変更しません。

@@ how-to-edit | 編集の方法
変形モードでオブジェクトの形を変更します。パラメータが割り当てられていないオブジェクトでは基本の形を、割り当て済みのオブジェクトでは現在のパラメータの組み合わせのキーフォームを変更します。
## 基本の流れ
1. オブジェクトを選択し、変形モード（{key:MODE_DEFORM}）に切り替えます。
2. パラメータパネルでパラメータを目的のキーに合わせます。
3. ツールで形を変更します。マウスを離すと結果が履歴に入り、元に戻せます。
## ツール
| ツール | ショートカット | 働き |
|---|---|---|
| 変形 | {key:TOOL_TRANSFORM} | 変形枠で選択した点を移動、拡大縮小、回転する |
| 変形ブラシ | {key:TOOL_BRUSH} | ブラシ範囲内の点を押し動かす。[[deform-brush]] を参照 |
| スムーズブラシ | {key:TOOL_SMOOTH} | 形をなめらかにする |
| 膨張・収縮 | {key:TOOL_INFLATE} | 外側へ膨らませる、または内側へ縮める |
- ワープデフォーマは「頂点」「ベジェ」の編集レベルを切り替えられます。回転デフォーマは原点と端点をドラッグして編集します。
- 「ツール詳細」の「正確な変形」では、選択した点を数値で移動、拡大縮小、回転できます。[[edit-vertices]] を参照してください。
- キャンバスの右クリックメニュー「キーフォームをミラー」で、形を対称キーや反対側のオブジェクトへミラーします。[[motion-mirroring]] を参照してください。
## Cubism との違い
- PSD2Live では形の変更（変形モード）とメッシュ構造の変更（編集モード）を分けており、ツールの設定は左下のツールオプションバーと右クリックメニューにあります。
- ジェネレーターが所有するキーフォームを編集すると、生成結果の上書きとして記録されます。[[generated-overrides]] を参照してください。

@@ keyform-parent-chilid-relation | キーフォーム(親子関係の動き)
親デフォーマと子オブジェクトは同じパラメータを割り当て、それぞれのキーに形を記録できます。パラメータが変わると、親が運ぶ全体の動きと子自身の形が重なって最終的な結果になります。
## 例
角度 X で首を振るとき、頭のデフォーマが頭全体の向きを担当し、顔の経緯格子と顔パーツがそれぞれ角度 X に応じて形を補正します。生成されたモデルはこのように層を分けて割り当てられています。
## 編集時の注意
- オブジェクトを選択したら、直接割り当てられているパラメータを確認し、親から階層を通じて来る動きと区別します。
- 子オブジェクトで編集する形は、現在のポーズでの親の状態を基準にします。
- キーフォームのミラーはオブジェクト自身の変形だけを扱い、デフォルトポーズの親を座標系とします。親のキーフォームは個別にミラーする必要があります。
*> パラメータパネルの「関連のみ」は、選択したコンポーネントに直接割り当てられたパラメータを一覧表示します。

@@ keyform-xydirection | キーフォーム（X,Yの動きをつける）
オブジェクトが 2 つのパラメータ（角度 X と角度 Y など）に同時に割り当てられている場合、キーフォームは格子状に並びます。X のキーと Y のキーの組み合わせごとに形が 1 つあり、斜めのポーズは周囲のキーから補間されます。
## 作り方
1. パラメータパネルで 2 つのパラメータを 2D コントローラとして結合し（行内の結合ボタン）、パッド上で右クリックして 2 つのパラメータのキーの交点にスナップします。
2. 変形モードで各交点の形を順に作ります。まず端点と中点を、次に 4 つの斜めの角を作ります。
3. パッドでキーの間をドラッグし、補間が自然か確認します。
## 生成モデル
生成される頭は、角度 X / Y の端点と中点の組み合わせで 9 つのポーズが生成され、斜めの角には別途補正があります。強さはモデルプリセットの「リグの数値」で調整できます。
*> 斜めのポーズの形は自動合成されないため、1 つずつ作る必要があります（Cubism の [[synthesize-corners]] はまだ提供されていません）。

@@ face-auto-edit | 顔の動きの自動生成
PSD2Live は PSD を読み込むと、顔の動き一式（首振り、まばたき、目玉、眉、口の変形と口の開閉）を自動生成します。上下左右の形を先に手作業で作っておく必要はありません。
## 生成される内容
- 頭 X / Y：端点と中点の組み合わせで 9 つのポーズを作り、原画の頭の傾きを基準にします。斜めの角には別途補正があります。
- 顔は経緯格子と領域ごとの修形を使います。目と眉、瞳、口、耳には個別の補正やマスクがあります。
- 口：口形の設定に従って開閉と口の変形を生成し、上下の唇の輪郭も選択して生成できます。
- 前髪と後ろ髪は強い顔の変形から切り離され、それぞれの揺れパラメータを出力します。
## 調整
1. 「モデルプリセット」パネルの「リギング・口形状 (Rigging & Facial)」グループを開きます：「顔パーツ移動デフォーマ」スイッチ、「頭部の可動範囲」「身体の可動範囲」。
2. 「リグの数値」グループで、頭の向き、目、眉、口、鼻と耳、髪の各項目を細かく調整します。あまり使わない項目は「詳細」にあります。
3. 変更するとモデルが再生成され、既存の手動編集はマージされて保持されます。
!> これはプリセットのアルゴリズムによる生成結果で、3D 復元ではありません。レイヤー分けの仕方、幅の広い髪束、極端な角度、重なった領域などでは手動での修形が必要になることがあります。
## Cubism との違い
- Cubism は作成済みの上下左右の形をもとに顔の残りの動きを自動生成します。PSD2Live は PSD のレイヤーから顔の動きをすべて直接生成し、幅は数値で調整します。
- 生成された顔のキーフォームは、変形モードで引き続き手動で修正できます。
関連：[[model-presets]] · [[standard-parameter-list]]

@@ auto-generation-of-sway-motion | 揺れの動きの自動生成
揺れの生成は Cubism の「揺れの動きの自動生成」にあたります。ワープデフォーマ（またはメッシュ）を選択すると、パラメータ -1 / 0 / 1 に揺れのキーフォームを自動生成し、同時に物理演算の振り子も生成します。設定はプロジェクトと一緒に保存され、いつでも開き直して調整できます。
## 開く
- オブジェクトモードで、キャンバス上で選択したメッシュまたはワープデフォーマを右クリック →「揺れを生成...」。生成済みの場合は「揺れを編集...」と表示されます。
- 階層ツリーの右クリックにも同じメニューがあります。
- 物理演算パネルの「+ 新規」→「選択対象に揺れを作成…」。
メッシュを選択した場合は、ぴったり合うワープデフォーマが自動で 1 層かぶせられます。回転デフォーマは対象にできません。
## 編集
1. 開くとキャンバスが揺れの編集に入り、左下にフローティングの揺れパネルが表示されます。
2. キャンバス上でハンドルをドラッグします。先端の丸で振幅と跳ね上がり、中心線のひし形で柔らかさ、先端の両角で拡大 / 縮小と平行度を設定し、中抜きの丸で揺れの矩形全体を回転、中抜きの四角で支点の辺を変更します。
3. パネルで揺れ方向（左右 / 上下、同時にチェック可）、分割（1–3）、推定（髪 / 小物 / 布）、物理演算の振り子を生成するかどうかを選びます。
4. 「揺れをプレビュー」で効果を確認します。「生成」/「適用」または Enter で書き込み、「キャンセル」または Esc で破棄します。
## ジェネレーターとベイク
- 揺れの軸上のキーフォームは揺れが所有し、再構築のたびに対象の現在の形から再計算されます。これらのキーフォームへの手動の変更は生成結果の上書きとして記録されます（[[generated-overrides]] を参照）。
- 「キーにベイク」は現在の形を通常のキーフォームとして書き込み、物理演算の振り子だけを残します。「削除」は生成された軸と自動作成されたパラメータも一緒に削除します。
## Cubism との違い
- Cubism はワープデフォーマを対象に揺れを生成します。PSD2Live はさらに、メッシュ対象（自動でデフォーマを 1 層かぶせる）、左右と上下の 2 種類の揺れ、分割、根元の平行（複数の髪束を一緒に揺らす）、揺れの矩形の回転に対応しています。
- 物理演算の振り子も同時に生成され、physics3.json と cmo3 に書き出されます。
- パラメータが存在しない場合は自動作成され、`ParamSwing<id>` という名前になります。

@@ edit-vertices | 頂点をキャンバス座標で編集
PSD2Live のキャンバス編集は、常に点がキャンバス上に表示されている位置に対して行われます。オブジェクトがどのデフォーマの下にあっても、ドラッグ、変形枠、ブラシはキャンバス上に見えている点に作用し、プログラムが親のローカル座標へ自動で換算します。正確な数値が必要な場合は「正確な変形」を使います。
## 正確な変形
1. 変形モードで動かしたい点を選択します。
2. 「ツール詳細」パネルの「正確な変形」を開きます。
3. 移動量（キャンバスのピクセル）、拡大率、回転角度を入力し、「適用」を押します。
回転と拡大縮小は変形枠のアンカーを中心にします。対象が回転デフォーマ 1 つの場合はその原点を中心にします。
## 変形枠
変形枠をドラッグすると、ポインターの横に回転角度、拡大率、または移動したキャンバスのピクセル数が表示されます。アンカーをドラッグすると中心を変更でき、中心、角、辺の中点の近くでスナップします。
## Cubism との違い
- Cubism では頂点をキャンバス座標で編集する機能が独立した機能として提供されています。PSD2Live ではデフォルトでキャンバス座標で編集するため、専用のスイッチはありません。
- 数値入力は選択した点全体の移動、拡大縮小、回転だけが対象で、頂点ごとの座標入力はありません。

@@ glue | グルー
グルーは 2 つのメッシュの頂点を貼り合わせ、2 つの部品が継ぎ目で一緒に動いて裂けないようにします。グルー点は 2 つのメッシュが共有する同じ点で、キャンバスでは 1 つのひし形として表示され、選択やドラッグをすると両側の頂点が常に一緒に動きます。
## 作成
1. オブジェクトモードで 2 つのメッシュを選択し、編集モード（{key:MODE_EDIT}）に切り替えます。
2. グルーツール（{key:TOOL_GLUE}）を選びます。その下に 3 つのサブツールがあります：グルーブラシ、重みブラシ、再結合（`1`–`3`）。
3. 重なっている所をグルーブラシで塗ります。または {key:FINISH_PATH} / モードバーの「グルーを作成」で 2 本の輪郭に沿って一続きに接着します。
## 操作
| 操作 | 効果 |
|---|---|
| グルーブラシ | 重なっている所で、もう一方のメッシュに頂点を 1 つ追加またはスライドさせる（UV も一緒に動く）。メッシュだけを変え、画は変えない |
| Alt + ドラッグ | 接着を解除する |
| 重みブラシ | 両側の重みを青（A）/ オレンジ（B）で表示して塗る |
| 再結合 | 塗った頂点の既存の接着を外し、スナップの許容値で接着し直す |
| {key:GENERATE} | どちらかのメッシュで選択した頂点を接着する（このときは書き出しを開かない） |
| 右クリック「距離で縫い目全体を再結合」 | 2 つのメッシュ間の接着をすべて外し、輪郭に沿って接着し直す |
!> 接着は静止形（すべてのパラメータがデフォルト値）の上で行います。パラメータがデフォルト値でないときは、グルーブラシ、再結合、グルーの作成は、まずパラメータをなめらかにデフォルト値へ戻してから接着します。
## Cubism との違い
- PSD2Live のグルーブラシはもう一方のメッシュに頂点を追加またはスライドさせて両側の頂点を重ねるので、2 つのメッシュにあらかじめ位置のそろった頂点がある必要はありません。
- ボーンで分割した四肢や前後分割には、グルーが自動生成されます。

@@ deformpath | 変形パス
変形パス（実験的）は、メッシュに付ける編集補助オブジェクトです。部品に沿って曲線を描き、曲線の制御点をドラッグするとメッシュが曲線に沿って変形し、結果はメッシュのキーフォームとして書き込まれます。3 種類目のデフォーマではありません。
## 作成と編集
1. アートメッシュを選択し、階層ツリーの右クリックで「変形パス」を選ぶか、{key:TOOL_CREATE_DEFORM_PATH} を使います。
2. アートメッシュ上をクリックして制御点を 2 つ以上置き、{key:FINISH_PATH} で確定、{key:CANCEL} でキャンセルします。
3. 編集モードでパスの割り当て位置、影響幅、硬さ、閉じ、角の点を調整します。このときメッシュは動きません。
4. パラメータパネルで目的のポーズを設定し、変形モードに切り替えて制御点をドラッグすると、形がアートメッシュのキーフォームに書き込まれます。
## 編集レベル
パスは L2 / L3 の 2 グループに分かれ、それぞれ別に保存されます。配置パネルか「ツール詳細」の「パス編集レベル」で選び、既存のパスはインスペクタの「編集レベル」で変更します。キャンバスには現在のグループのパスだけが表示されます。
## 書き出し
| ファイル | 内容 |
|---|---|
| `.cmo3` | パスコントローラの構造とメッシュのキーフォーム |
| `.moc3` | ベイク後のメッシュのキーフォーム。ランタイムではパスのアルゴリズムは実行されない |
!> 1 つのメッシュに複数のパスを付けられますが、1 本のパスで複数のメッシュを制御することはできません。ドラッグの効果が Cubism Editor と完全に一致するかはまだ検証されていないため、幅、硬さ、大きな角度の変形は確認が必要です。
## Cubism との違い
- PSD2Live のパスは 1 つのメッシュにだけ作用する、メッシュ上の編集補助です。`.moc3` にはベイク後のキーフォームだけが残ります。
- パスの編集レベル L2 / L3 は、ワープデフォーマの頂点 / ベジェのレベルとは関係ありません。

@@ skinning | スキニング
スキニングは、関節をまたぐ 1 枚のメッシュを複数のボーンに合わせてなめらかに曲げます。Cubism のスキニングはメッシュを回転デフォーマの連なりに変換しますが、PSD2Live は独自のスケルトンで同じことを行います。メッシュをボーンにバインドするとウェイトが自動計算され、書き出し時に Cubism のデフォーマとキーフォームへベイクされます。
## バインドとウェイト
1. ボーンモードで「ボーンを編集」（{key:TOOL_SKELETON_EDIT}）を選び、「バインド」サブツールでメッシュをボーンにバインドします。同じ肢のメッシュはそのうち 1 本にバインドするだけで十分です。
2. ウェイトは肢全体で自動計算されます。各頂点は関節の両側の最大 2 本のボーンに追従し、「関節の幅」の範囲でなめらかに遷移します。
3. 修正が必要な場合は「ウェイト」サブツールを使います。バインド済みのメッシュと同じ肢のボーンを選び、増加、減少、置換、スムーズで塗ります。
4. 「ツール詳細」では、自動ウェイトのクリーンアップや復元、別のメッシュへのウェイトのコピー / ミラーができます。
5. 表示バーの「スキンウェイトを表示」で、ボーンの色で頂点を色分けします。
## ベイク結果
関節の範囲内の頂点は、角度に応じて関節周りの回転をブレンドするため、曲げても肢の幅が変わりません。書き出し時には回転デフォーマとメッシュの補正キーフォームとして書き込まれます。
## Cubism との違い
- Cubism のスキニングはメッシュ上に回転デフォーマの連なりを直接生成し、そのあと Cubism で編集します。PSD2Live のウェイトはスケルトンに属し、ボーンを変更したら再ベイクします。
- 各頂点は隣り合う最大 2 本のボーンの影響しか受けません。
詳しくは [[skeleton]] を参照してください。

@@ skeleton | ボーン
ボーンは PSD2Live のすばやい四肢リギングツールです。スケルトンで体、四肢、しっぽ、翼を動かし、書き出し時に Cubism でそのまま動く構造（胴体の曲げデフォーマ、四肢の回転デフォーマ、関節をまたぐメッシュの補正キーフォーム）へベイクします。書き出したモデルはこのプログラムに依存しません。
## ボーンモード
ボーンの操作は「スケルトン」タブ（階層ツリーと並んでいます）とキャンバスのボーンモード（{key:MODE_SKELETON}）で行います：
| ツール | ショートカット | サブツール |
|---|---|---|
| ボーンのポーズ | {key:TOOL_SKELETON_POSE} | 自動 / FK / IK |
| ボーンを編集 | {key:TOOL_SKELETON_EDIT} | 編集 / 新規ボーン / 押し出し / バインド / ウェイト |
## スケルトンを作成する
1. ボーンモードに入ります。プロジェクトにまだスケルトンがない場合は、キャンバス中央か「スケルトン」タブの「スケルトンを作成」を押します。
2. プログラムがレイヤーのタグと左右からボーンを推定してバインドします。腕は handwear、脚は legwear、足は footwear に、しっぽと翼はそれぞれのレイヤーにバインドされます。
3. 「編集」で関節の端点をドラッグして位置を調整し、「新規ボーン」「押し出し」でカスタムボーンを追加し、「バインド」でメッシュをまとめてバインドします。
4. 「ツール詳細」ではボーンの複製、ミラー、細分化、融合ができます。ボーンを選択すると「関節の幅」と最小 / 最大角度を調整できます。
5. 「完了」を押すと 1 つの履歴として保存されます。ボーンのポーズへの切り替え、モードの変更、別のレイヤーの選択でも保存され、「キャンセル」だけが今回の変更を破棄します。
## ポーズを付ける
- ボーンの本体をドラッグすると FK で、そのボーンだけが回転します。末端をドラッグするか Shift を押しながらドラッグすると IK になります。
- 「ツール詳細」では IK チェーンの長さ、反復回数、曲げる方向を設定し、選択したボーンの末端を固定できます。
- ポーズ付けはパラメータの値を変えるだけで、履歴は作られません。「ポーズ復帰」でゼロに戻します。名前付きポーズは保存してアニメーションに挿入できます。
## 生成される構造とパラメータ
- 胴体の曲げ `DeformSkelTorso`、四肢、しっぽ、翼の回転デフォーマ `DeformSkel_<ボーン ID>`。
- `ParamArmLA`、`ParamLegLA`、`ParamTail1..n` などのボーンのパラメータ。単位は度です。
- ポーズのパラメータ：しゃがみ、重心移動、しっぽ振り、羽ばたき、内股、跳ね。
- ボーンのモーションはアニメーションパネルに表示されます。[[builtin-motions]] を参照してください。
- 「パラメータのサンプリング」で許容誤差、最小角度間隔、メッシュごとのキーフォームの上限を設定し、書き出しサイズを制御します。
!> 左右が同じレイヤーに描かれた肢はバインドされません。先に「モデル → メッシュごとにレイヤーを分割…」で分けてください。ボーンをベイクしたあと、Cubism Editor にはボーンの意味情報は残りません。ボーンを引き続き変更したい場合は `.psd2live` プロジェクトを保管してください。
!> ボーンのパラメータのうち加算できる四肢のパラメータは、書き出し先が Cubism 5.0 以上の場合はブレンドシェイプのパラメータとして書き込まれます。5.0 未満の場合はすべて通常のキーフォームにベイクされ、回転デフォーマ上のポーズは取り除かれます。
## Cubism との関係
Cubism Editor にはスケルトンオブジェクトがなく、四肢は通常、回転デフォーマの連なりとスキニングで手作業で組みます。PSD2Live のボーンは、これらの構造を生成するためのツールです。スケルトン上で配置、バインド、ウェイト調整を行えば、書き出し時に同じデフォーマとキーフォームが自動で得られます。関連：[[skinning]] · [[making-and-rotation-of-rotationdeformer]]

@@ generated-overrides | 生成結果の上書き
揺れやシミュレーションなどのジェネレーターのキーフォームは、再構築のたびに再計算されます。これらのキーフォームに対する変更は上書きされて消えることはなく、「生成結果の上書き」として記録され、すべてのジェネレーターのあとに生成結果とマージされます。
## どの編集が上書きになるか
- 揺れが対象のワープデフォーマに生成したキーフォーム（揺れのパラメータがデフォルト値でないとき）。
- ベイク済みのシミュレーションがキーフォーム軸としてメッシュに書き戻したキーフォーム。
- ボーンのスキニングが、自分で付け替えたメッシュに書き込んだキーフォーム。
生成パラメータがデフォルト値のときの編集は通常の編集のままで、静止形を変更します。
## マージのルール
| 状況 | 結果 |
|---|---|
| 自分が変更していない点 | 新しい生成結果に従う |
| ジェネレーター側が変わっていない点 | 自分の値を保持する |
| 両方が変更した点 | 自分の値を保持し、競合として報告する |
## 問題を確認する
問題があると、インスペクタのツールバーに「上書きの問題 n 件」バッジが表示されます。選択したオブジェクトの問題はインスペクタ上部の「生成結果の上書き」に一覧表示され、バッジをクリックするとすべての問題が表示されます。
- 競合：一部の点がジェネレーターと自分の編集の両方で変更されたため、自分の編集を保持しました。
- 未適用：生成されたキーフォームがもう存在しない、生成された形の点数が変わった、またはメッシュが分割されて置き換えられた。
!> 生成されたキーフォームへの、または生成されたキーフォームからのコピーや、ジェネレーターの軸上でのキーの追加・削除は上書きとして記録できないため、拒否されます。揺れを完全に手動で編集したい場合は、先に揺れパネルで「キーにベイク」を行ってください。
## Cubism との関係
Cubism の自動生成は一度きりで、生成後は通常のキーフォームになります。PSD2Live のジェネレーターは設定に応じて再実行されるため、上書きの仕組みによって手動の変更が再生成後も保持されます。関連：[[auto-generation-of-sway-motion]] · [[simulation]] · [[update-generated-rig]]

@@ motion-mirroring | 動きの反転
片側で作ったキーフォームを反対側へ左右反転してミラーします。たとえば角度 X 30 の形を -30 へ、左目の形を右目へミラーします。結果は通常のキーフォームとして書き込まれ、元に戻せます。
## 使い方
1. 変形モードでオブジェクトを選択し、パラメータをミラーしたいキーに合わせます。
2. キャンバスの右クリックメニュー「キーフォームをミラー」で操作を選ぶか、{key:MIRROR_KEYFORM} で対称キーへミラーします。
| 操作 | 働き |
|---|---|
| 対称キーへミラー | 現在のキーを対称キーへミラーし、そのキーに切り替えて結果を表示する |
| 対称キーからミラー | 対称キーの形で現在のキーを上書きする |
| 反対側のオブジェクトへミラー | 反対側の同種オブジェクトへ書き込む。L/R 付きのパラメータは反対側のものに置き換え、左右のパラメータは符号を反転する |
| その場で左右反転 | オブジェクト自身の中心で現在のキーを反転する |
| すべてのキーを反対側へ / 反対側のオブジェクトへミラー | すべてのキーを一度に処理する |
## ルール
- 符号を反転する左右のパラメータは、範囲がデフォルト値を中心に対称で、かつ 2D 結合の横軸であるか ID が X、Z で終わるパラメータです（AngleX、BodyAngleX、EyeBallX など）。
- 反対側のオブジェクトは、まずレイヤーの意味で対応づけ、次に名前の L/R、Left/Right、左/右で対応づけます。
- ミラーはオブジェクト自身の変形だけを扱い、親のキーフォームは個別にミラーする必要があります。複数のレイヤーを選択した場合はそれぞれミラーし、1 つの履歴としてコミットします。
## Cubism との違い
- PSD2Live ではキャンバスの右クリックメニューで操作し、対称キーと反対側のオブジェクトはパラメータとレイヤーの意味から自動で判断されるため、対応関係を別に指定する必要はありません。

@@ deform-brush | 変形ブラシ
変形ブラシは、変形モードでブラシのように形を押し動かします。髪や輪郭など、広い範囲をやわらかく修正したい箇所に向いています。変更するのはジオメトリだけで、テクスチャは変更しません。
## 使い方
1. オブジェクトを選択して変形モードに切り替え、「変形ブラシ」（{key:TOOL_BRUSH}）を選びます。「スムーズブラシ」と「膨張・収縮」もあります。
2. キャンバス上でドラッグして点を押し動かします。選択がない場合はオブジェクトのすべての点に、選択がある場合は選択した点だけに作用します。
3. デフォルトでは {key:BRUSH_ADJUST_DRAG} のドラッグで半径または硬さを調整し、{key:BRUSH_RADIUS_DOWN} / {key:BRUSH_RADIUS_UP} で半径を調整し、{key:CANCEL} で現在の操作をキャンセルします。
## 設定
| 設定 | 働き |
|---|---|
| 先端 | 円形、直線、矩形（{key:BRUSH_SHAPE_CYCLE} で順に切り替え） |
| 半径 / 硬さ / 強度 | 作用範囲、縁のやわらかさ、1 回の押し出しの強さ |
| 減衰 | スムーズ、球状、ルート、逆二乗、シャープ、リニア、一定、ランダム |
| 接続のみ | ポインター下のメッシュとつながった点だけに影響する |
先端は左ツールバーのブラシの下で選び、そのほかの設定は左下のツールオプションバーとキャンバスの右クリックメニューにあります。ホバー中は、押したときに動く点が赤い円で示され、円が大きいほど影響が強くなります。
*> 「接続のみ」は、隣り合う髪束や上下の唇のように近接した部品を分けて塗るのに向いています。

@@ blend-shape | ブレンドシェイプ
ブレンドシェイプのパラメータは、ほかのパラメータのキーと掛け合わせるのではなく、オブジェクトの既存のキーフォームに形の差分を加算します。複数のパラメータがそれぞれ独立して作用する場合、ブレンドシェイプを使うとキーフォームの数を大幅に減らせます。PSD2Live はブレンドシェイプのパラメータに対応していますが、製品内での編集フローはまだ整備中です。
## すでにできること
1. パラメータの新規作成時に「パラメータ設定」で「ブレンドシェイプ」を選びます（種類は新規作成時にしか選べず、デフォルトの範囲は 0..1 です）。
2. パラメータパネルでは、ブレンドシェイプのキーは四角で表示されます。0 は中立の基本形で、移動や削除はできません。
3. パラメータをほかのキーに合わせ、変形モードでメッシュまたはデフォーマを変更すると、加算する形が記録されます。
4. ボーンとシミュレーションはブレンドシェイプのパラメータ（ボーンのパラメータ、シミュレーションのモードパラメータ）を自動生成します。[[skeleton]]、[[simulation]] を参照してください。
!> 未整備：Cubism の重みの制限設定（[[limit-settings-for-blend-shape-weights]]）、制限カーブ、完全な作成フローはまだ提供されていません。
## 書き出し
メッシュとワープデフォーマのブレンドシェイプには、書き出し先が Cubism 4.2 以上である必要があります。回転デフォーマとパーツのブレンドシェイプには 5.0 以上が必要です。ターゲットバージョンが対応していない場合、書き出しはダウングレードされ、レポートに記載されます。
## Cubism との違い
- Cubism では既存のパラメータをブレンドシェイプに切り替えて重みの制限を設定できます。PSD2Live では種類は新規作成時にしか選べず、重みの制限は今のところありません。

@@ multiply-color-screen-color | 乗算色・スクリーン色
乗算色はオブジェクトを暗くしたり色を付けたりし、スクリーン色はオブジェクトを明るくします。頬染め、影、ハイライトなどを、レイヤーを描き足さずに表現できます。
## 設定方法
1. アートメッシュまたはデフォーマを選択します。
2. インスペクタの「乗算色」「スクリーン色」で色見本をクリックして色を選ぶか、16 進コードを入力します。

- Cubism：乗算色とスクリーン色はキーフォームに属し、パラメータのキーポイントごとに異なる色を設定できます。
- PSD2Live：インスペクタでは固定色を 1 つ設定するだけです。パラメータに応じて変わる色は MCP からしか書き込めません。

1. ワークスペースのタブバー右側の **+** を押して **アニメーション** プリセットを選びます。モーション一覧がプレビューキャンバスの左に、アニメーションエディターがその下に、パラメータパネルが右側に配置されます。
2. 「アニメーション」パネルでモーション行の編集ボタンをクリックするか、右クリックで **編集** を選ぶと、モーションがアニメーションエディターで開きます。
3. パラメータパネルでスライダーをドラッグしてポーズを付け、アニメーションエディターでキーフレームとして記録します。[[timeline-basic-operation-timelinepalette]] を参照してください。

## Cubism との違い
- Cubism：Animator で新しいシーンを作成し、モデルを読み込み、タイムラインにモデルトラックを置いてからモーションを作ります。1 つのシーンが 1 つのモーションファイルに対応します。
- PSD2Live：シーン、モデルトラック、グループトラックはありません。各モーションはプロジェクト内の 1 つのクリップで、現在のモデルのパラメータを直接動かします。背景、音声、複数のモデルを置くこともできません。
- モーションはプロジェクトと一緒に保存され、元に戻す／やり直すの対象になります。アニメーションファイルを別に保存する必要はありません。
*> CMO3 を書き出すと、モーションは同名の `.can3` に別途保存され、Cubism Editor の Animator で cmo3 と一緒に開いて編集を続けられます。
@@ builtin-motions | 組み込みモーション
組み込みモーションは PSD2Live がモデルに合わせて自動生成するモーションです。手作業でキーフレームを打たなくても、待機やまばたきなどのよく使う動きが得られ、モデルと一緒に書き出されます。
## モーション一覧
| グループ | モーション | 説明 |
|---|---|---|
| 基本モーション | 待機モーション、瞬き、頷き、首振り | どのモデルでも再生できる。待機モーションはループ |
| ボーンモーション | しっぽ振り、しゃがみ、重心移動、照れ、手を振る、首かしげ、喜び、片足上げ、ゆらゆら、かわいい待機 | スケルトンが必要。現在のスケルトンで再生できないモーションは表示されない。かわいい待機はループ |
モデルプリセットの「モーション (Motions)」グループにある **基本モーション**、**ボーンモーション** の 2 つのチェックボックスで、グループ全体を生成するかどうかを決めます。[[model-presets]] を参照してください。
## 調整とオン／オフ
1. 「アニメーション」パネルの **組み込みモーション** フォルダで、各行の左のチェックボックスをオン／オフにして、そのモーションを書き出すかどうかを決めます。
2. モーション行をクリックすると調整項目が展開されます。たとえば待機モーションには **揺れ**、**呼吸**、**頭**、**速度** と **まばたき** のスイッチがあり、瞬きには **閉じ具合**、**速度** と **二回まばたき**、頷きと首振りには **振幅**、**速度**、**回数** があります。
3. 行の右側の再生ボタンで、そのモーションをプレビューキャンバスで再生します。
## 手動での変更
アニメーションエディターで組み込みモーションを開いてキーフレームを変更すると、行に **変更済み** と表示され、調整項目は使えなくなります（キーフレームが手動で変更されているため、デフォルトに戻すまでこれらのパラメータは使えません）。右クリックメニュー：
- **カスタムモーションとして複製**：現在の内容で新しいカスタムモーションを作ります。元の組み込みモーションは変わりません。
- **デフォルトに戻す**：手動の変更を破棄し、調整項目から生成した結果に戻します。
- **削除**：削除すると書き出されなくなります。**新規モーション** メニューの **削除したプリセットを復元** から戻せます。
!> 物理演算で動くパラメータは、物理演算の出力と競合しないよう待機モーションには書き込まれません。
## Cubism との関係
Cubism には自動生成されるモーションはなく、Animator で手作業で作る必要があります。組み込みモーションはあらかじめ作られたモーションに相当し、書き出し後は手作業で作ったモーションと同じく `motion3.json` として書き込まれます。ループするモーションは `Idle` グループに入ります。[[notes-for-sdk]] を参照してください。

Cubism では Animator のまばたきエフェクトや Viewer のまばたき設定で自動まばたきを指定します。PSD2Live では、組み込みのまばたきモーションと書き出し時に書き込まれる `EyeBlink` グループで同じ効果を実現します。
## 設定方法
1. モデルプリセットの「モーション (Motions)」グループで **基本モーション** にチェックが入っていることを確認します。
2. 「アニメーション」パネルで **瞬き** にチェックを入れます。その行をクリックして展開すると **閉じ具合**、**速度** を調整でき、**二回まばたき** にチェックを入れると 2 回続けてまばたきします。
3. 待機モーション自体もまばたきします。待機モーションの調整項目で **まばたき** をオフにできます。
## 書き出し結果
- 基本モーションと瞬きがどちらも有効で、メッシュのみの書き出しでない場合、`model3.json` の `Groups` に `ParamEyeLOpen` と `ParamEyeROpen` を含む `EyeBlink` グループが書き込まれ、SDK の自動まばたきはこれに基づいて動作します。
- 瞬きのモーション自体も `motion3.json` として書き出されます。
## Cubism との違い
- Cubism：Animator のモデルトラックでまばたきエフェクトを使ってまばたきの間隔を設定するか、Viewer でまばたきのパラメータを設定してから model3.json を出力します。

## 操作
1. 左側のトラック行をクリックすると、そのカーブだけが表示されます。トラック一覧の上の **すべて表示** ですべてのカーブの表示に戻ります。
2. キーフレームをドラッグすると時間と値が同時に変わります。カーブを 1 本だけ表示しているときは、空いている所をダブルクリックするとその時間と値にキーフレームが追加されます。
3. ベジェ区間のキーフレームの両側にはハンドルがあり、ドラッグしてイージングを調整します。下部の **ハンドルをリセット** でデフォルトのハンドルに戻します。

| 補間 | 説明 |
|---|---|
| リニア | 2 つのキーの間を等速で変化する |
| イージング (ベジェ) | デフォルト。ハンドルで加速と減速を制御する |
| ステップ | 前のキーの値を保ち、次のキーで切り替わる |
| 逆ステップ | すぐに次のキーの値に切り替わって保つ |

1. **ファイル → Live2D モデルを書き出し…**（{key:GENERATE}）を選びます。
2. **形式:** で **moc3**、**cmo3**、**can3**（cmo3 と一緒にモーションを書き出す）、**json**（プロジェクトのメタデータレポート）にチェックを入れます。**メッシュのみ (Mesh Only)** にチェックを入れると、メッシュだけを書き出し、モーションと物理演算は含みません。
3. **SDK ターゲット** でランタイムのバージョン（Cubism 3.0 から最新まで）を選びます。選んだバージョンがモデルで使っている機能に対応していない場合、ウィンドウにダウングレードされる機能が一覧表示されます。
4. 必要に応じて **MOC3 書き出しオプション** を調整します：非表示 Part を書き出す、非表示 ArtMesh を書き出す、ガイド画像 Part を書き出す、physics3.json を含める、cdi3.json を含める、および **Pixels / unit**（デフォルトは自動で、キャンバスの幅に基づく）。
5. **出力フォルダー** を選び、**生成してエクスポート** を押します。
## 出力ファイル
| ファイル | 内容 |
|---|---|
| `<名前>.moc3` | モデルデータ |
| `<名前>.model3.json` | モデル設定。[[export-model3-json]] を参照 |
| `<名前>.physics3.json` | 物理演算。プロジェクトの物理演算のフレームレートで `Fps` を書き込む |
| `<名前>.<モーション>.motion3.json` | モーションごとに 1 つ。[[notes-for-sdk]] を参照 |
| `<名前>.cdi3.json` | パラメータ、パーツ、メッシュの表示名 |
| `<名前>.<幅>/texture_00.png` など | テクスチャアトラスのページ |
| `<名前>.cmo3` / `<名前>.can3` | Cubism Editor のプロジェクトと Animator のプロジェクト |
テクスチャアトラスのページサイズと枚数はウィンドウでは概要だけが表示され、テクスチャワークスペースに移動して調整できます。[[texture-atlas-edit]] を参照してください。
## Cubism との違い
- Cubism：Modeler の「moc3 書き出し」と Animator の「motion3.json 書き出し」を別々に行い、テクスチャアトラスは書き出し時に編集します。
- PSD2Live：モデル、物理演算、モーション、model3.json を同じウィンドウで一度に書き出します。書き出すのは現在コミット済みのモデルで、PSD から再生成はしません。
- エディターの Cubism SDK プレビューと moc3 の書き出しは同じ 1 回のコンパイルなので、プレビューで見えているものがそのまま書き出し結果です。
!> cmo3 内の GUID は書き出すたびに異なります。`.can3` は同じ回に書き出した `.cmo3` とだけ対応するため、両者は同じフォルダーに置く必要があります。
@@ other-formats | その他の形式での書き出し

## 書き出し手順
1. **ファイル → 形式を指定して書き出し** を選び、「ランタイムとプレイヤー」「画像と動画」「レイヤー付き PSD」の 3 グループから形式を選びます。
2. 表示されたウィンドウでその形式固有の設定を調整し（調整できる設定がない場合は「この形式には設定がありません」と表示されます）、**出力フォルダー** を選んで **書き出し** を押します。
3. ファイルは出力フォルダー内の「<プロジェクト名>-<形式>」という名前のフォルダーに書き込まれ、その横に `<名前>.<形式>.report.json` 損失レポートが書き出されます。

- 画像と動画については [[exporting-images]] を参照してください。
- **ポーズを指定した PSD…**：あるモーションの時刻や指定したパラメータ値でポーズを付け、表示されているメッシュごとに 1 レイヤーにします。デフォーマとパラメータは保持されません。

## Cubism との関係
Cubism Editor は Live2D 独自の形式だけを書き出します。VTube Studio、Web、Unity でモデルを使う場合、Cubism ユーザーは通常、組み込み用データを書き出してから各プラットフォームの Live2D SDK を利用します。PSD2Live はこれらのプラットフォームが読めるファイルを直接書き出します。
*> Spine、DragonBones、glTF は実験的なターゲットで、メニューにはなく、コマンドラインからのみ書き出せます。
@@ userdata | ユーザデータとイベント
ユーザーデータは、オブジェクトに付ける任意の文字列で、アプリケーションが読み取るためのものです。PSD2Live ではアートメッシュにユーザーデータを入力できます。
## 設定方法
1. アートメッシュを 1 つ選択します。
2. 「インスペクタ」の下部で **ユーザーデータ** を展開し、テキストを入力します。
3. 入力を終えると 1 つの履歴として記録され、元に戻せます。
## 書き出し
- ユーザーデータはプロジェクトと一緒に保存され、書き出した `.cmo3` に書き込まれて Cubism Editor で確認できます。

## Cubism との違い
- Cubism：アートメッシュにユーザーデータを設定して `userdata3.json` を出力できます。Animator ではモーション内にイベント（ユーザーデータ）を置き、`motion3.json` に書き込めます。
- PSD2Live：ユーザーデータはアートメッシュにしか設定できません。モーションにイベントは置けず、書き出した `motion3.json` にユーザーデータは含まれません。

@@ switch-viewer-setting | 物理演算設定
Cubism では Viewer で物理演算設定に切り替えてから物理演算を編集します。PSD2Live には独立した Viewer はなく、物理演算は「物理演算」パネルで編集します。このパネルはどのワークスペースでも開け、専用の「物理演算」ワークスペースもあります。
## 物理演算設定を開く
1. ワークスペースのタブバー右側の **+** を押して **物理演算** プリセットを選びます。左側のプレビューキャンバスが半分を占め、右側にパラメータパネルと物理演算パネルが順に並びます。
2. または **ウィンドウ** メニューから「物理演算」パネルを開き、任意のキャンバスと一緒に使います。
3. 物理演算のオン／オフと物理演算のフレームレートは、プレビューキャンバス左側のツールバーにあります：**物理演算** / **物理演算オフ**、および **物理 FPS**（30 / 60 / 90 / 120 / 無制限、デフォルト 60）。
## Cubism との違い
- Cubism：物理演算の設定は Viewer で行い、設定結果を `physics3.json` として出力してからモデルと組み合わせます。
- PSD2Live：物理演算はプロジェクトの一部で、プロジェクトと一緒に保存され、元に戻せます。書き出し時には `physics3.json` と `.cmo3` に自動で書き込まれます。物理演算のフレームレートはプロジェクトの設定で、書き出しファイルにも書き込まれます。
- パネル内の振り子キャンバスでモデルを直接揺さぶって試せるため、モードを切り替える必要はありません。

@@ physics-operation | 物理演算について
物理演算は、頭や体などの入力に応じてパラメータに慣性のある揺れを生じさせるもので、髪、アクセサリー、衣服などの揺れに使います。PSD2Live は Cubism と同じ振り子モデルを使います。
## 仕組み
- **入力**：頭や体の角度などのパラメータが、振り子の根元を押したり（位置X）、重力の向きを傾けたり（角度）します。
- **振り子**：根元から垂れ下がる振り子の連なりで、長さ、揺れやすさ、反応速度、収束の速さに従って動きます。
- **出力**：ある振り子の振れ角に倍率を掛けて、出力パラメータに書き込みます。
物理演算はパラメータを書き込むだけで、揺れの形は出力パラメータのキーフォームから来ます。出力パラメータの端点の形が作られていないと、パラメータは動いてもモデルは動きません。
## 物理グループの由来
物理グループは、プリセット（前髪、後ろ髪、瞳のゼリー）、ボーン、揺れ、シミュレーションのベイク、または手動での新規作成から生まれます。詳しくは [[physics-group-information]] を参照してください。
*> パネルとプレビューで使う物理演算の計算は Cubism Native Framework の計算方式と項目ごとに対応しているため、書き出した `physics3.json` は SDK でもエディターと同じように動作します。
@@ physical-operation-setting | 物理演算の設定方法
「物理演算」パネルで物理グループを 1 つ選択すると、その下に振り子キャンバス、応答カーブ、振り子の設定、入力、出力、詳細設定が順に並びます。
## 振り子キャンバス
| 操作 | 働き |
|---|---|
| 空いている所を左右にドラッグ | Viewer でモデルをドラッグするようにモデルを揺さぶる。離すと元の位置に戻る |
| 振り子の末端のリングを上下にドラッグ | その振り子の長さを調整する。クリックで選択 |
| 右側の出力ラベルをある振り子の横までドラッグ | その振り子の角度を読み取るように変更する（振り子番号） |
| 出力ラベルをクリック | 範囲の扇形を表示し、扇形の縁をドラッグして倍率を調整する |
振り子の下の応答カーブは、右へ 1 秒揺さぶってから離したときの反応を示し、設定ごとのオーバーシュートと収束をそのまま比較できます。
## 設定項目
1. **プリセット**：プリセットを 1 つ選んで **読込** を押すと、すべての振り子が置き換わります。**追加…** で現在の振り子を自分のプリセットとして保存します。
2. **編集する振り子**：**すべて** またはある番号を選び、下のスライダーでどの振り子を調整するかを決めます。振り子の追加、削除、上下の移動ができます。
3. スライダー：**全長 / 長さ**、**揺れやすさ**、**反応速度**、**収束の速さ**。名前は Cubism Editor と同じです。
4. **入力**：**追加** でパラメータを加え、種類（**位置X** または **角度**）を選び、**影響度** と反転を設定します。
5. **出力**：**振り子番号**、**倍率**、反転を設定します。右側の **最大出力** は出力がパラメータの端点に達した割合を示し、**最大値で倍率を調整** で 100% に合わせます。
6. **詳細**：振り子の設定表、出力の詳細、**入力の正規化**。
## Cubism との違い
- Cubism：物理演算設定ダイアログで表に数値を入力し、Viewer でモデルをドラッグして確認します。
- PSD2Live：振り子キャンバスで長さ、振り子番号、倍率を直接ドラッグして変更でき、応答カーブと最大出力も表示されます。
- 出力は角度タイプのみです。Cubism ランタイムでは位置X タイプの出力は常に 0 になります。
- ドラッグや入力のたびに、手を離した時点で 1 つの履歴として記録され、元に戻せます。

@@ physics-group-information | 物理演算グループ編集
「物理演算」パネル上部の物理グループ一覧で、モデルのすべての物理グループを管理します。Cubism の物理演算設定のグループ一覧にあたります。
## 物理グループ一覧
- 計算順に並び、番号が付いています。チェックボックスでグループを有効／無効にし、無効なグループは書き出されません。
- 各行には由来（プリセット、ボーン、揺れ、シミュレーション、カスタムなど）と状態が表示されます：**編集済み**、**無効**（パラメータが存在しない、入力や出力がないなど）、**置換済み**（出力がすでにほかのグループで動かされている）。
- タイトルバーの上へ / 下へで計算順を調整します。あるグループがほかのグループの出力を入力にしている場合、読み取られる側のグループを前に置きます。
## 新規作成
**新規** を押します：
- **空の振り子**：デフォルトで頭と体の揺れを入力とし、出力はまだありません。
- **新しいグループとして複製**：選択したグループを複製し、出力パラメータは空になります。
- **physics3.json を読み込む…**：ファイル内の各グループがカスタムグループになります。ID が同じグループは置き換えられます。
- **選択対象に揺れを作成…**：キャンバスで選択したメッシュまたはワープデフォーマに揺れを作成します。[[auto-generation-of-sway-motion]] を参照してください。
## 生成されたグループの変更
生成されたグループも直接編集でき、編集すると **編集済み** と表示され、その後由来が変わっても上書きされません。**その他** メニューの **生成値に戻す** で生成されたバージョンに戻ります。カスタムグループは **名前を変更**、**削除** できます。
## Cubism との違い
- Cubism：すべての物理グループを手動で作成・設定する必要があります。
- PSD2Live：大部分の物理グループはジェネレーターが自動作成し、変更を保持したまま由来に合わせて更新できます。
- 1 つのパラメータを動かせる有効なグループは 1 つだけで、競合するグループは置換済みと表示され、書き出されません。
@@ simulation | 布と髪のシミュレーション
シミュレーションは、エディター内でメッシュに対して本物の 2D の布と髪のシミュレーションを行います。頂点は固定点に引き留められ、重力と慣性で動きます。Cubism ランタイムはこの種のシミュレーションを行わないため、書き出すにはシミュレーションをパラメータ、キーフォーム、Cubism の振り子へ**ベイク**する必要があります。
## 基本の流れ
1. キャンバスでスカートや髪のメッシュを選択し、「シミュレーション」パネルで **新規** を押して **布** または **髪** を選びます。同じ物理ボディ内の複数のメッシュは一緒にシミュレーションされます。
2. 固定点を指定します。パネルの **頂点ウェイトグループ** の固定点の行で **描く** を押すか、キャンバスの「シミュレーション」モード（{key:MODE_SIMULATE}）に切り替えてウェイトペイントで塗ります。**接着** で腰とつながったグルーを **固定点にする** に設定することもできます。
3. パネルのプレビュースイッチを **参照シミュレーション** に切り替え、プレビューで首を振ったり体を揺らしたりしながら、自然になるまで材質を調整します。
4. 物理ボディの **焼き込み** か、ツールバーの **すべて焼き込む** を押します。ベイクはバックグラウンドで数秒かかり、完了すると 1 ステップの元に戻せる操作としてコミットされます。
5. **書き出し結果** に戻すと、プレビューで書き出しモデルの動きが再生されるので、参照シミュレーションと見比べます。
## 頂点ウェイトグループ
| 種類 | 働き |
|---|---|
| 固定点 | リグに引き留められる頂点。ウェイトは固定の強さを表す |
| 剛性 | 伸びと曲げの剛性を頂点ごとに拡大縮小する |
| 形状保持 | 原画の形へ戻る力を頂点ごとに拡大縮小する |
| 質量 | 質量を頂点ごとに拡大縮小する |
| 減衰 | 減衰を頂点ごとに拡大縮小する |
ウェイトグループはこのソフト内にだけ存在し、書き出しファイルには書き込まれません。
## 材質とベイク
- **材質** の節では名前付きのプリセット（綿、シルク、シフォン、ウール、デニム、革、伸縮素材、髪、細く柔らかい髪、太く硬い髪、前髪）を選び、質量、伸び、曲げ、減衰、形状保持などの数値を微調整できます。
- **入力** は物体を揺らすパラメータで、デフォルトは頭や体の角度などです。物体にほとんど影響しない入力はベイク時に除外されます。
- **焼き込み** の節ではモード数、上下のパラメータ、キーポイント、誇張などを設定します。ベイク後は参照シミュレーションと比べた視覚チェック（振幅、遅れ、戻り、揺らぎ）と R² が表示されます。
- ベイク後、物理演算パネルには由来が「シミュレーション」の振り子グループが、パラメータパネルには `ParamSim…` パラメータが現れます。設定、メッシュ、ウェイトが変わるとベイクは古いと表示されますが、再ベイクするまで書き出しには古い結果が使われます。
*> モデルプリセットの「物理・シミュレーション」グループで、前髪、後ろ髪、衣装のシミュレーションを一度に作成してベイクできます。[[model-presets]] を参照してください。
## Cubism との関係
Cubism には振り子の物理演算しかなく、布や長い髪の複雑な揺れは、通常は複数のパラメータとキーフォームを手作業で作り、複数の振り子グループで動かす必要があります。PSD2Live のシミュレーションはこの工程を自動化します。まずリアルタイムでシミュレーションし、それを Cubism で再生できる振り子、パラメータ、キーフォームにフィッティングするため、書き出したモデルはどの Cubism ランタイムでも再生できます。シミュレーションそのもの（参照シミュレーション）は書き出されません。

## 有効化と接続
1. **設定**（{key:OPEN_SETTINGS}）の **MCP** を開きます。
2. 「サービス」で **MCP サービスを有効にする** にチェックを入れ、**ポート**（1024–65535、デフォルト 23871）、**アクセストークン**（**再生成** 可能）、**ツールセット**（**コンパクト（推奨）** または **フル**）を設定して、**適用して再起動** を押します。
3. 「ホストを接続」で、ホストごとのコマンドや設定をコピーします。**セットアップ用プロンプトをコピー** は、ホストに自分で設定させるためのプロンプトを生成します。
4. ホストがツールを一覧表示したら、まず `workspace_inspect` を呼び出して現在のプロジェクトのオブジェクト ID と状態を読み取ります。
## 説明
- サービスはこのマシン上でのみ動作し、Streamable HTTP と Bearer トークン認証を使います。トークンで現在のワークスペースを編集できるため、ローカルのホスト設定にだけ保存してください。
- Stdio にしか対応していないホストでは、Python 3 でリポジトリのルートにある `mcp_proxy.py` を実行します。
- ポートやトークンを変更したら、接続済みのホストの設定も合わせて更新する必要があります。
- ウィンドウを開かずに、コマンドラインの `mcp` サブコマンドで MCP エンドポイントだけを起動することもでき、ワークスペースのストレージはエディターとは別になります。
## Cubism との違い
- Cubism：外部アプリケーションは WebSocket でエディターに接続し、エディター内でアプリケーションごとに許可します。
- PSD2Live：MCP プロトコルを使い、アクセストークンで認証します。MCP による編集は画面操作と同じコマンドを通るため、同じく履歴に入り、元に戻せます。
@@ external-application-integration-api | Live2D Cubism Editor 外部連携 API
PSD2Live の外部インターフェースは MCP ツールです。各操作には厳密なリクエストと結果のスキーマがあり、`workspace_list_operations` で一覧表示、`workspace_get_operation` で確認できます。
## 呼び出しの約束事
- パラメータは `{"request": {...}}` の中に置きます。
- 変更操作には `state`（`workspace_inspect` または前回の結果から取得）が必要です。フルのツールセットではさらに `project_id` と一意の `request_id` が必要です。コンパクトのツールセットでは後の 2 つを省略でき、`request_id` はパラメータから導出されるため、同じ呼び出しを再試行すると元の結果が返ります。
- `state` が現在のプロジェクトと一致しない場合は競合が報告されるので、読み直してから再試行します。
- 時間のかかる操作はバックグラウンドジョブを返すので、`job_wait` / `job_get` で結果を取得します。コンパクトのツールセットの `wait_ms` を使うと、制限時間内であれば結果を直接返せます。
- `workspace_apply_edits` は 1–128 件の編集を 1 つのアトミックな一括操作としてコミットし、すべて成功したときだけ履歴ノードを 1 つ追加します。`workspace_preview_edits` は試行のみで、プロジェクトは変更しません。
## ツールセット
| ツールセット | 内容 |
|---|---|
| コンパクト（デフォルト） | 同系統の操作を 1 つのツールにまとめ（`motion` で `op` により `motion_set_key` を選ぶなど）、残りは `workspace_call` 経由で呼び出す |
| フル | 操作ごとに 1 つのツールで、完全な入力と出力のスキーマ付き |
どちらのツールセットでもすべての操作を呼び出せ、実行と検証は同じです。
## Cubism との違い
- Cubism：WebSocket で JSON メッセージを送り、主にパラメータ値の読み書きとエディターの状態取得に使います。
- PSD2Live：MCP ツールでプロジェクトの読み込み、編集、保存、書き出しができ、画面上の主な編集機能をカバーします。

## プレビューランタイム
プレビューキャンバス左側のツールバーの下部に 3 つのランタイムが並び、クリックで切り替えます：
| 選択肢 | 説明 |

| Cubism SDK（C） | 書き出した moc3 を公式の Cubism 5 ランタイムで再生する |

| p2lrt · 拡張（P+） | PSD2Live ランタイムの高度なモード：円弧に沿ったスキニング、正確なリンク、布と髪のリアルタイムシミュレーション |

## Cubism との違い
- Cubism：Viewer は独立したアプリケーションウィンドウで、出力後のファイルを読み込みます。
- PSD2Live：プレビューはワークスペース内の 1 つのキャンバスで、現在のプロジェクトをその場でコンパイルした書き出し結果を再生し、編集すると即座に更新されます。

## プレビューキャンバス
- キャンバスのモードメニューで **プレビュー**（{key:MODE_PREVIEW}）を選ぶか、**プレビュー** ワークスペースのプリセット（大きなプレビューで、モーション一覧だけを残す）を使います。{key:QUICK_PREVIEW} で編集とプレビューをすばやく切り替えます。
- 左側のツールバー：**待機モーション**、**視線追従**、**滑らかな追従と身体 Y**、**物理演算**、**物理 FPS**、およびランタイムの選択（[[selection-of-viewer]] を参照）。
- 左下のステータスカプセルのメニューで、プレビューの **フレームレート上限**（デフォルトはディスプレイに追従）を設定できます。物理演算のフレームレートとは無関係です。
## Cubism との違い
- Cubism：Viewer は独立したツールで、先にファイルを書き出してから読み込む必要があります。
- PSD2Live：プレビューと編集は同じウィンドウで、書き出さずに確認できます。表情、ポーズの設定、モーションシンクなどの Viewer の機能はまだ提供されていません。
@@ load-model-and-motion | モデルとモーションの読み込み

3. モデルやモーションを編集すると、プレビューは自動で更新されます。

- PSD2Live：モデルは現在のプロジェクトから、モーションはプロジェクト内の組み込みモーションとカスタムモーションから来ます。外部の `motion3.json` は読み込めません。

## Cubism との違い
- Cubism：Viewer でモーショングループ名、サウンドファイル、フェードを自由に設定してから model3.json を出力します。
- PSD2Live：モーショングループはルールに従って自動で決まり、サウンドファイルは指定できません。フェードはカスタムモーションにだけ設定します。

@@ check-the-physics | 物理演算情報の確認
Cubism Viewer ではモデルをドラッグして物理演算の効果を確認します。PSD2Live ではプレビューキャンバスと物理演算パネルで確認します。
## プレビューキャンバスで確認する
1. プレビューキャンバス左側のツールバーで **物理演算** をオンにし、**物理 FPS** を選びます。
2. **視線追従** をオンにしてポインターを動かすか、モーションを再生して、髪などの揺れを観察します。待機モーションを止めてからパラメータのスライダーを直接ドラッグすることもできます。
3. Cubism SDK ランタイムを選んでいる場合、プレビューは公式 SDK が書き出した `physics3.json` を直接読み込みます。
## 物理演算パネルで確認する
- 物理グループを 1 つ選択し、振り子キャンバスの空いている所を左右にドラッグしてモデルを揺さぶり、振り子と出力を観察します。
- 応答カーブは、標準的な揺さぶりに対する各出力の最大振幅と静止までの時間を示します。
- **最大出力** が 100% を超えると警告色で表示され、パラメータが端点で頭打ちになっていることを示します。**最大値で倍率を調整** で修正できます。
物理グループの数、有効な数、フレームレートは物理演算パネルの上部（**有効 n / m**）に表示されます。
## Cubism との違い
- Cubism：Viewer でモデルをドラッグして確認し、物理演算設定の数値を確認します。
- PSD2Live：プレビューと編集は同じウィンドウで、振り子キャンバスでグループごとに試すことができ、応答カーブと最大出力も表示されます。
