@@ t-eye-blink | 10分钟就能看懂的“眨眼”
本教程在 PSD2Live 中完成与 Cubism 初学者教程相同的目标：让角色眨眼。区别在于 PSD2Live 会根据图层标签自动生成眨眼，你要做的是准备好素材、确认结果，必要时再手动修形。
## 准备素材
- 眼白、瞳孔、上睫毛分别分层，图层名可用 `eyewhite` / `眼白`、`irides` / `瞳孔`、`eyelash` / `睫毛`。
- 睫毛层只画上睫毛，不要混入下眼眶线，否则闭眼时可能拉扯下眼眶。
- 左右眼分开，名称带侧别，如 `eyelash-l`、`左睫毛`（左右指角色自身）。
- 需要特定的闭眼造型时，另画 `eye_close` / `闭眼` 图层；否则由程序按睫毛生成闭眼曲线。
## 生成并确认眨眼
1. 选择 **文件 → 新建 → 从 PSD 新建工程…**（{key:OPEN_PSD}），选择 PSD。
2. 在开始界面的 **快捷选项** 中保留 **默认**，生成后进入编辑工作区。
3. 打开 **图层** 面板，确认眼部各层的 **标签** 为对应的部位与侧别；不对时点开标签修改。
4. 打开 **参数** 面板，拖动 **左眼开合** 与 **右眼开合**（`ParamEyeLOpen` / `ParamEyeROpen`，0 为闭眼，1 为睁眼），检查闭眼形状。
5. 闭眼弧度或眼角位置不合适时，在 **模型预设** 的 **Rig 数值 → 眼睛** 中调整 **闭眼弧深**、**闭眼眼角**、**闭眼睫毛厚度**。
## 手动修整闭眼形状
1. 在层级树中选中睫毛或眼白，把参数拖到闭眼的键（右键键标记可吸附）。
2. 切换到 **变形** 模式（{key:MODE_DEFORM}），拖动控制点或使用笔刷（{key:TOOL_BRUSH}）修整形状。
3. 一侧修好后，在画布右键菜单 **镜像关键形 → 镜像到 …** 把形状写到另一侧的同类对象，参数会自动换成另一侧的开合参数。
4. 切换到 **预览**（{key:MODE_PREVIEW}），开启 **待机动画** 检查自动眨眼。
## 与 Cubism 教程的差异
- Cubism：手动创建网格、为眼睛参数追加键并逐个制作闭眼形状，再复制到另一侧。
- PSD2Live：网格、参数键与闭眼形状按标签自动生成；手动编辑只用于修整，编辑会在重新生成后保留。
- 导出时启用眨眼动作的模型会在 model3.json 中写入 EyeBlink 组，运行时可直接自动眨眼。

@@ t-mouth-aiueo | 20分钟就能看懂的“AIUEO”口型
Cubism 的这篇教程用“嘴巴开合”和“嘴型”两个参数组合出あいうえお（AIUEO）五种口型。PSD2Live 在导入时自动为嘴巴生成这两个参数及其关键形，本教程在此基础上检查五种口型并修整。
## 准备素材
- 嘴巴图层画最大张口状态，保留清晰描边，图层名如 `mouth` / `嘴巴`。
- 口腔可画成整体，也可另分 `tooth_t`（上牙）、`tooth_b`（下牙）、`tongue`（舌头），它们会自动限制在嘴内显示。
- 对闭口造型有要求时另画 `mouth_close` / `闭嘴`；否则闭口由程序生成。
## 两个参数的分工
| 参数 | ID | 范围 | 作用 |
|---|---|---|---|
| 嘴巴开合 | `ParamMouthOpenY` | 0…1 | 0 闭嘴，1 最大张口 |
| 嘴型 | `ParamMouthForm` | -1…1 | 负值嘴角下垂、变窄，正值嘴角上扬、变宽 |
五种口型由两者组合：“あ”大开口，“い”小开口加宽，“う”小开口收窄，“え”中开口略宽，“お”中开口收窄。
## 检查与调整
1. 导入 PSD（{key:OPEN_PSD}）后，在 **图层** 面板确认嘴巴、牙齿、舌头的 **标签** 正确。
2. 在 **参数** 面板拖动 **嘴巴开合** 与 **嘴型**，按上面的组合逐一检查五种口型。
3. 闭口的线形在 **模型预设 → 形变与口型 (Rigging & Facial)** 中调整：开启 **生成上下唇描边** 后，点 **嘴形设置** 选择 **初始嘴形**（**平口**、**微笑**、**W 形** 或自定义曲线），并设置 **线宽** 与 **采样边缘颜色**。
4. 嘴型的幅度在 **模型预设 → Rig 数值 → 嘴巴** 中调整，例如 **嘴角上扬**、**笑时加宽**、**闭嘴收窄**、**闭合线位置**。
## 手动修整口型
1. 在层级树中选中嘴巴画元，把 **嘴巴开合** 与 **嘴型** 移到要修整的键（右键键标记可吸附）。
2. 切换到 **变形** 模式（{key:MODE_DEFORM}），拖动控制点或用笔刷 {key:TOOL_BRUSH}、平滑 {key:TOOL_SMOOTH} 调整；开启笔刷的“仅相连项”可分开刷上下唇。
3. 需要更多中间口型时，点参数名打开 **参数属性**，在 **关键点** 轴上点击空白处加点，再在该值上变形。
4. 切换到 **预览**（{key:MODE_PREVIEW}）连续拖动两个参数，确认中间值过渡自然。
## 与 Cubism 教程的差异
- Cubism：手动为嘴巴开合与嘴型追加键，逐个制作四角的口型，再检查五种组合。
- PSD2Live：两个参数及其关键形按素材自动生成，闭口线形与幅度用模型预设调整，手动变形只用于修整。
- 导出时 `ParamMouthOpenY` 写入 model3.json 的 LipSync 组，运行时可直接用于口型同步。

@@ t-figure | 以图形记忆Live2D
本页用几组概念说明 Live2D 模型的组成，并对应到 PSD2Live 的界面名称。熟悉这些概念后，自动生成的结果就容易读懂和修改。
## 画元（图形网格）
PSD 的每个图层导入后成为一个画元，对应 Cubism 的图形网格（ArtMesh）：一张贴图加上覆盖它的三角网格。移动网格顶点，贴图随之变形。网格在 **编辑** 模式中修改拓扑，在 **变形** 模式中改变形状。
## 变形器
变形器是包住画元或其他变形器的“框”。**网格变形器**（对应弯曲变形器 Warp）用一组控制点整体弯曲内部内容，**旋转变形器** 让内容绕一点旋转。变形器可以嵌套：父级的运动会传给子级，例如头部转动带动眼睛和头发。父子关系在 **层级树** 中查看；遮挡由绘制顺序单独决定。
## 参数与关键形
参数是一根滑条，例如 **角度 X**、**左眼开合**。参数上的键记录对象在该值时的形状，PSD2Live 称为关键形；滑条位于两个键之间时，形状自动插值。两个参数可以组成二维关联，同时控制四个角的组合姿势。
## 动画与物理
动画按时间改变参数值；物理根据头部、身体等输入参数计算摆动，再输出到头发摆动等参数。两者都只驱动参数，不直接改变形状。
## 与 Cubism 教程的差异
- 概念相同，名称略有不同：图形网格 → 画元，弯曲变形器 → 网格变形器，键上的形状 → 关键形。
- PSD2Live 另有骨骼与变形路径等编辑辅助，导出时烘焙为 Cubism 的参数、变形器与关键形。
- 上述结构在导入 PSD 时自动生成，可在层级树与参数面板中直接查看。

3. 开启 **自动插帧**（{key:MOTION_TOGGLE_AUTO_KEY}）后，在播放头处拖动参数或在画布上摆姿态即自动打帧；手动模式下摆好姿态后用 **记录姿态**（{key:MOTION_KEY_POSE}）。
4. 用 **摄影表** 排时间，用 **曲线** 调缓动；关键帧默认为贝塞尔缓动。
5. {key:MOTION_PLAY_PAUSE} 播放检查；在动画编辑器切换 **循环**，在动画面板设置淡入、淡出时间。

@@ t-motion-hint | 提高动态质量的技巧
本页整理让动作更自然的通用技巧，这些原则在 PSD2Live 中同样适用。
## 技巧
- **先定节奏再调细节**：先用 **摄影表** 排好关键姿势的时间，再到 **曲线** 视图调整缓动。
- **缓入缓出**：关键帧默认贝塞尔缓动；动作起止处避免匀速，用曲线手柄放慢开始和结束。
- **错开时间**：头、身体、视线不要在同一帧开始，让身体或视线稍早或稍晚，动作更有层次。
- **跟随与重叠**：头发、饰品交给物理跟随，不必逐帧做摆动；物理在预览中开启后检查。
- **留出停顿**：眨眼与小幅呼吸让静止段不显得僵硬，可用待机动作的 **眨眼**、**呼吸** 调节项。
- **检查端点**：参数长时间停在范围端点会显得僵硬，必要时扩大参数范围或调整物理输出倍率。
*> 播放时所有画布共享同一姿态，可以一边在动画编辑器调整，一边在预览画布观察。
