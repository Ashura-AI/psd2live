@@ workflow | 制作流程
PSD2Live 从分层 PSD 自动生成一个可动的初版模型，再在同一个工作区里修形、绑定、加物理与模拟、编动画，最后导出到 Cubism 或其他格式。与 Cubism 先手工搭建再动起来的流程不同，这里的第一步就得到完整的网格、变形器、参数、动作和物理。
## 基本流程
1. **准备 PSD**：按部件分好图层，图层名尽量使用可识别的命名（见 [[precautions-for-psd-data]]）。
2. **选择预设并生成**：在开始页的 **从 PSD 生成** 选预设（最小 / 默认 / 完整），把 PSD 拖入窗口，或按 {key:OPEN_PSD}。生成后自动进入编辑工作区（见 [[psd-import]]、[[model-presets]]）。
3. **核对识别结果**：在 **图层** 面板中检查每层的标签（部位、侧别）与差分设置，识别错的直接修改（见 [[layers-palette]]）。
4. **预览**：在画布模式菜单选 **预览**，或切到「预览」工作区，检查待机、眨眼等动作与物理（见 [[preview-canvas]]）。
5. **按需编辑**：在编辑画布上用变形、编辑、骨骼、绘画等模式修改关键形、网格与像素；在物理、模拟面板调整摆动（见 [[canvas-modes]]）。
6. **保存工程**：{key:SAVE_PROJECT} 保存为 `.psd2live`，它包含源图、全部编辑与分支历史。
7. **导出**：{key:GENERATE} 打开 **导出 Live2D 模型…** 导出 `.moc3` / `.cmo3`；其他格式在 **文件 → 导出为** 中。
{tutorial=BASIC}
## 另外两种起点
- **排版工程**：从空画布开始，导入图片、PSD 或 SVG 素材，摆放并加标签后再生成（见 [[layout-project]]）。
- **从 CMO3 导入**：打开已有的 Cubism 模型继续编辑，不自动生成预设（见 [[cmo3-import]]）。
## 重新生成与编辑
画布上的修改都以可重放的编辑保存。之后改图层标签、模型预设或升级程序，模型由源图重新生成，你的编辑再按顺序重放，因此编辑不会因重新生成而丢失。需要采用新版本生成器时，用 **模型 → 更新生成结果**（见 [[update-generated-rig]]）。
## 与 Cubism 的差异
- Cubism：素材拆分 → 在 Editor 中手工创建网格、变形器、参数并制作关键形 → 在 Animator 中做动画 → 导出。
- PSD2Live：素材拆分后由生成器一次得到初版，建模、物理、动画在同一个程序、同一份工程中完成；保存的是可重放的编辑与历史，而不是最终模型本身。
- 交付 Cubism 时导出 `.cmo3` 可在 Cubism Editor 中继续精修；只用运行时则导出 `.moc3` 文件族。
*> 有 Cubism 经验时，先看交互教程中的术语对照一章。

## 安装与启动

## 与 Cubism 的差异
- Cubism Editor 需要登录或输入许可证激活，FREE 版有功能限制。
- PSD2Live 没有激活步骤和功能分级；Cubism SDK 只是可选的预览方式。

| 扩展名 | 说明 |
|---|---|

- Cubism 的模型工程是 `.cmo3`，动画工程是 `.can3`；PSD2Live 用自己的 `.psd2live` 保存工程，`.cmo3` / `.can3` 只作为导入或导出格式。

@@ fault-map | Editor/Viewer无法正常开启时的确认事项
PSD2Live 启动失败、画面异常或运行中出错时，按下表逐项检查。
## 常见情况
| 现象 | 确认事项 |
|---|---|
| 编辑画布黑屏、闪烁或显示错乱 | 在 **设置 → 画布交互** 勾选「编辑画布与纹理集页面使用软件渲染」；同一处显示当前使用 GPU 还是软件渲染。显卡不支持多重采样或 GPU 绘制失败时，程序会自动改用兼容方式 |
| 预览画布无法使用 Cubism SDK | 没有可用的 Cubism SDK 原生库时，在预览画布的 **预览运行时** 中改用 PSD2Live 运行时；Linux 上无 XWayland 的纯 Wayland 或 musl 系统会自动回退 |
| 面板不见了 | 用工作区标签栏右侧的 **窗口** 菜单重新显示，或选 **重置布局** |
| 画布上看不到模型 | 按 {key:FRAME_VIEW} 适配所选或 {key:RESET_CAMERA} 重置镜头，再检查图层显隐 |
| 程序异常退出 | 下次启动时会询问是否恢复未保存的编辑（见 [[autosave]]） |
| 设置或界面状态异常 | 在设置页目录底部点 **恢复默认**；或关闭程序后带 `--clear-user-data` 参数运行一次，清除设置与本机数据 |
## 收集信息
1. 打开 **日志** 面板，用等级与来源筛选错误，点 **复制日志**。
2. 在 **设置 → 文件与数据** 中找到 **错误日志** 的位置；这里还可清理之前异常退出留在系统临时文件夹中的残留。
3. 帮助页 **关于** 显示版本与运行时环境。
4. 通过 **帮助 → 在线资源 → 问题反馈** 提交问题，附上版本、操作系统、复现步骤与相关素材。
## 与 Cubism 的差异
- Cubism 的确认事项主要是许可证、显卡驱动与 OpenGL 设置。
- PSD2Live 没有许可证；画面问题通过软件渲染选项排查，Cubism SDK 预览不可用时可改用自带运行时。

@@ performance | 处理SDK中模型时的性能
导出模型在运行时的负担主要来自网格顶点、关键形数量、纹理尺寸与遮罩。PSD2Live 在生成和导出时提供几处可以检查和控制这些因素的地方。
## 检查与调整
| 因素 | 在哪里查看或调整 |
|---|---|
| 网格顶点数 | **网格** 面板显示选中图层的顶点数与边长，可调整全局默认或逐层覆盖的网格设置；**图层** 信息中也显示顶点数 |
| 纹理尺寸与显存 | 「纹理」工作区：纹理面板未选图层时列出每页尺寸、图块数、占用与显存（RGBA）；右上角设定纹理集预算（页面尺寸、最多页数与间距），逐层调整纹理密度（见 [[texture-atlas-edit]]） |
| 关键形数量 | 模拟烘焙的模态写成关键形轴时，网格的关键形数量会乘以模态的关键点数；选「融合变形」（Cubism 4.2+）可避免，「自动」在关键形超过 64 个时使用融合变形（见 [[simulation]]） |
| 目标版本 | 导出时按所选 SDK 目标剥离不支持的功能，并列出降级项（见 [[target-version-selection]]） |
## 编辑器内的预览负担
预览画布可在 **帧率上限** 中限制帧率（或跟随显示器）；预览菜单中的「高级模式」只用于 PSD2Live 运行时，开启后实时运行布料与头发模拟，负担更高。
## 与 Cubism 的差异
- Cubism 的手册说明 SDK 中影响性能的因素，由制作者在 Editor 中自行控制网格与纹理。
- PSD2Live 的网格、纹理集与模拟烘焙由生成器按设置产生，性能相关的数值集中显示在网格面板、纹理工作区与模拟面板中；导出报告 `.psd2live.json` 记录降级与损失。

@@ target-version-selection | 选择目标版本
目标版本决定导出的 `.moc3` / `.cmo3` 可使用哪些 Cubism 功能。PSD2Live 在导出窗口中选择，而不是在新建模型时选择。
## 选择方法
1. 按 {key:GENERATE} 打开 **导出 Live2D 模型…**。
2. 在 **SDK 目标** 下拉中选择 Cubism 3.0、3.3、4.0、4.2、5.0 或 5.3（默认 5.0）。
3. 当前模型用到了目标不支持的功能时，窗口中列出「导出时将降级以下已使用的功能」，逐项显示格式、功能与对象。
## 会被降级的功能（示例）
| 功能 | 说明 |
|---|---|
| 四角变形方式 | 较早目标不支持新的弯曲变形方式 |
| 反转蒙版 | 需要较新的目标 |
| 混合形状 | 融合变形相关功能按版本分级 |
| 正片叠底颜色 / 滤色颜色 | 较早目标不支持 |
| 扩展混合模式、部件离屏合成 | 需要较新的目标 |
目标版本也影响生成：例如目标没有融合变形时，模拟的模态写成关键形轴。
## 与 Cubism 的差异
- Cubism 在新建模型或之后通过对话框选择目标版本，编辑时不能使用目标不支持的功能。
- PSD2Live 在导出时选择，按目标剥离不支持的功能并在报告中列出；同一工程可分别导出到不同版本。

Solo（独显）只显示选中的图层，暂时隐藏其他图层，便于检查被遮挡的部件。

@@ autosave | 自动备份功能
PSD2Live 在编辑时持续把未保存的修改写入本机的工作区存储。程序异常退出后，下次启动可以把这些修改恢复为未保存的工程。

@@ divide-the-material | 关于素材拆分
要让插画动起来，需要把会分别运动或互相遮挡的部分画在不同图层上，这一步称为素材拆分。PSD2Live 读取拆好的分层 PSD，按图层名称识别部位并自动生成网格、变形器与参数，因此拆分的粒度直接决定生成结果。
## 拆分的基本原则
- 每个部位单独一层：眼白、瞳孔、上睫毛、眉毛、鼻子、嘴巴、前发、后发、脸、脖子、上衣等。
- 瞳孔画完整的圆，包括被眼皮遮住的部分；眼白用来限制瞳孔的显示范围。
- 嘴巴画最大张口状态，闭口由程序生成；口腔可画成一个整体，也可另分上牙、下牙、舌头。
- 前发与后发分开，被遮挡的区域多画一些，运动时不露底。
- 左右成对的部件（双眼、双耳、双臂）最好分成左右两层，并在名称里写明侧别。
## 拆分不足时的补救
画在同一层的左右部件不会在导入时自动拆开，会作为一个部件生成。可以在导入后用 [[split-by-mesh]] 拆成独立图层；一个图层需要同时位于另一部件前后时（例如领子绕过脖子），用 [[depth-split]]。
## 与 Cubism 的差异
- Cubism：拆分方式完全由制作者决定，载入后逐个手动建立网格、变形器与参数。
- PSD2Live：拆分后按图层名称（或导入后在图层表中修改的标签）自动生成整套绑定，所以命名和分层要符合 [[precautions-for-psd-data]] 中的约定。
- PSD2Live 还可以不经 PSD，在 [[layout-project]] 中把单独的图片摆到画布上再生成。
*> 命名识别失败的图层不会被丢弃，会照常生成网格并使用回退归属，导入后在图层表中修正标签即可。

@@ reimport-psd | 如何制作载入PSD
本页说明为 PSD2Live 准备 PSD 文件时的格式与结构要求。符合要求的 PSD 可以直接导入并自动生成模型。
## 文件格式
- 使用 RGB、8 位、透明背景的分层 PSD。
- 文字、矢量、图层样式和调整效果先栅格化，或合并到对应的像素层。
- 身体保持基本正立；头部可轻微倾斜，自动基准估计仍需在预览中核对。
## 图层命名
生成器按图层名称识别部位，英文、中文、日文、韩文名称均可，例如 `front hair`、`前发`、`eyelash-l`、`左睫毛`。名称对照表见 [[precautions-for-psd-data]]。识别结果只是初始值，导入后可在「图层」面板的「标签」列随时修改。
## 侧别与编号
- 左右指角色自身：角色的左侧通常在画面右边。
- 名称中的数字（如 `front hair 1`）用于区分同类素材；部分 Photoshop 副本后缀会被清理。
- 数字本身不会建立表情切换。需要随参数切换的图层，在导入后设置 [[variants]]。
## 画布尺寸
网格设置默认「随文档尺寸缩放」：长度按长边缩放到固定尺寸的文档计算，因此大尺寸 PSD 会得到同样疏密的网格。清晰度来自图层自身的像素。
## 与 Cubism 的差异
- Cubism：PSD 的图层与文件夹结构直接成为图形网格和部件，命名只用于显示。
- PSD2Live：图层名称决定生成器把它当作哪个部位，部件由生成器按部位自动建立，不按 PSD 文件夹划分。
*> 没有 PSD 时，也可以把外部工具拆好的图片写成 Layout 清单（JSON 或 zip）直接打开，见 [[layout-project]]。

@@ precautions-for-psd-data | 创建PSD的注意事项
自动生成依赖图层名称与分层方式。下面是绘制时容易出问题的地方，以及生成器能自动识别的图层名称表。
## 绘制时注意
- 睫毛层只画上睫毛，不要混入下睫毛和下眼眶线，否则闭眼时可能拉扯下眼眶。
- 嘴巴画最大张口；对闭口造型有要求时另画 `mouth_close`。闭口原图无法靠变形恢复不存在的口腔。
- 前发与后发分开，被遮挡处保留足够重叠。
- 闭眼可以预先画好 `eye_close`，也可交给睫毛的闭眼曲线。
!> 命名成功不代表造型已经合格。导入后检查中立、眼口开合、转头和头发运动，核对层序、左右、遮罩及露底。
*> 识别结果可以在「图层」面板的「标签」列修改，见 [[psd-import]]。

@@ split-by-mesh | 按网格拆分图层
当一个图层里画着几块互不相连的部分（例如两只眼睛画在同一层），可以按网格的连通区域把它拆成独立图层，让每块分别获得自己的网格、变形与标签。
## 打开方式
- **模型 → 按网格拆分图层…**：扫描所有图层，列出包含独立网格的图层，可 **全选** / **取消全选** 后点 **拆分所选**。
- 层级树中右键图层 → **拆分独立网格…**，或在物体、编辑、绘画模式的画布右键菜单 **网格** 中选择，只处理这一个图层。
- 导入图层后，程序可以主动询问是否拆分；在对话框勾选不再提示，或在 **设置 › 提示** 的「导入图层时提示按网格拆分」中开关。
## 拆分步骤
1. 打开 **按网格拆分图层** 对话框，确认每个网格区域的预览。
2. 选择命名方式：两块时可选 `L / R`、`T / B`、`1 / 2` 或 **自定义命名**；更多块时按编号或自定义。
3. 点 **拆分图层**。不想拆时点 **保持单层**，批量时可点 **全部保持单层**。
`L / R` 命名按角色自身的左右：画面左侧的部分得到 `-r` 后缀并标为右侧，另一块为 `-l`。
## 拆分后的结果
部件取代原图层，网格取自原网格的对应部分，原图层上的关键形、混合形、路径、权重与胶水随之带到部件上。之后修改部件的网格设置时，按部件自己的像素重新生成网格并迁移这些绑定。
!> 从 CMO3 导入的模型不能按网格拆分。
## 与 Cubism 的关系
Cubism 中图层在 PSD 里拆好后才载入，载入后无法再拆分图形网格，需要回到绘图软件修改 PSD 并重新载入。PSD2Live 可以在编辑器内直接拆分，不必修改 PSD。需要按自定义形状而不是连通区域分开、或要前后穿插时，见 [[depth-split]]。

@@ depth-split | 前后分层
一个图层里的不同部分，有时需要分别位于另一个部件的前面和后面，例如后领口藏在脖子后、前领片盖在脖子前。**前后分层** 把图层复制成前后两层夹住中间对象，自动设置绘制顺序并用胶水让两层一起变形，你只需在前层上擦掉应藏到后面的部分。
## 操作步骤
1. 在编辑画布切到 **物体** 模式，选中要分层的图层（如上衣），按住 {kbd:Shift} 加选要夹在中间的对象（如脖子）。
2. 右键要分层的图层，选择 **将「图层名」前后分层**。菜单中的名称是将被复制的对象，点击前确认。
3. 程序创建「`图层名 · 后`」和「`图层名 · 前`」两层取代原图层，自动选中前层并切到 **绘画** 模式的 **橡皮擦**。
4. 沿中间对象的边缘擦掉前层中应被遮住的部分。擦多了可用绘画会话中的撤销恢复。
5. 点 **确认应用**。前层保留原网格与变形，不需要重新生成网格。
6. 在参数面板检查转头、身体转动等姿势，必要时回到前层继续修边。
只选中了一个图层时，在层级树中右键它选择 **前后分层…**，在弹窗的 **穿插对象** 中选择中间对象，确认前层／中间／后层关系后点 **创建并擦除**。
## 注意事项
- 一次只分层一个图层；可以加选多个中间对象，它们会一起放在前后层之间并保持彼此的顺序。
- 创建后外观不会立即变化：新前层起初是完整复制，需要擦除后才出现遮挡效果。
- 有未提交的绘画会话时，先应用或放弃再创建。
!> 从 CMO3 导入的模型暂不支持前后分层。

## 与 Cubism 的关系
在 Cubism 中通常回到绘图软件把素材拆成前后两层，再重新载入并分别设置变形，或用胶水连接。PSD2Live 在编辑器内一步完成复制、排序与黏合，后层保留完整像素，原图层的形变数据复制到两层。

@@ layout-project | Layout 工程与素材库
Layout 工程让你先在画布上摆好部件，再生成绑定；生成之后还可以继续加图、改标签，然后重新生成，已有的编辑会保留。素材库（**素材** 面板）保存工程用到的所有图片，图层显示的像素来自它关联的素材。
## 开始一个 Layout 工程
- **从空画布开始**：在开始页选 **排版工程**（或 **文件 → 新建 → 新建 Layout 工程…**），选择常用尺寸或输入宽高后点 **创建排版工程**。新工程还没有绑定，并切到 Layout 工作区。
- **从 PSD 开始**：照常导入 PSD。工程直接生成绑定，同时 PSD 的每个图层出现在素材面板里，并与画布上的图层关联。
- **从 Layout 清单开始**：外部工具写出的清单（JSON，或根目录放着它的 zip）用打开 PSD 的方式打开，图层按清单摆好，尚未生成。
## 素材面板
- **导入**：点 **导入** 或 **导入文件夹**，或把文件拖到面板上。支持 PNG、BMP、TIFF、WebP、JPEG、PSD、CMO3 中的分层图片与 SVG。PSD 成为一个文件夹，图层组成为子文件夹。
- **整理**：把素材拖到其他文件夹即可移入；右键可重命名、新建文件夹、删除。正在被图层使用的素材不能删除。
- **素材窗口**：双击素材打开独立窗口，可查看、绘画、翻转与调色，所有使用该素材的图层一起更新。
## 摆放与生成
1. 把素材或整个文件夹拖到画布上，或右键 **放置到画布**。
2. 在 **物体** 模式下用变换框移动、缩放、镜像图层；摆放和缩放都不重采样像素。
3. 在「图层」面板的 **标签** 列说明部位与侧别，在 **差分** 列设置开关或切换差分。
4. 点编辑画布右上角生成栏的 **生成**。之后新放置或改过标签的图层显示为「待生成」，点 **重新生成** 并入绑定。
还没生成的图层可以用 {key:LAYER_FORWARD} / {key:LAYER_BACKWARD} 上移、下移一层，{key:LAYER_TO_FRONT} / {key:LAYER_TO_BACK} 置顶、置底；生成之后，已生成图层的前后用 [[draworder]] 调整。
*> 画布单位决定模型的大小与比例，清晰度来自素材自身的像素：图层摆得越小，纹理越密。
{tutorial=LAYOUT}
## 与 Cubism 的关系
Cubism 只从 PSD 建模，素材的增减要回到绘图软件修改 PSD 再重新载入。Layout 工程相当于把「整理素材、摆放、命名」也放进编辑器，适合素材来自多个文件或由程序拆分的情况。参考图层见 [[sketch]]。

@@ psd-import | PSD载入
导入分层 PSD 后，PSD2Live 按图层名称识别部位，自动生成网格、变形器、参数、动作与物理，并进入编辑工作区。生成内容由 [[model-presets]] 决定，可在导入前选择，也可之后修改。
## 导入方式
- **文件 → 新建 → 从 PSD 新建工程…**（{key:OPEN_PSD}）选择文件。
- 把 PSD 拖到窗口任意位置。
- 在开始页 **从 PSD 生成**：先在详情面板选预设（**最小** / **默认** / **完整**），需要时逐项调整，再选择文件；**最近的 PSD** 中双击直接生成。
预设会被记住，菜单、最近文件或拖放导入的 PSD 都按它生成。导入后头发与服装模拟会依次烘焙，进度显示在状态栏。
## 导入后检查
1. 打开 **图层** 面板，核对每个图层识别出的 **标签**（部位与侧别）；不对时点开标签修改，已生成的图层在重新生成后采用新标签。
2. 在 **差分** 列为需要随参数显隐或切换的图层设置 [[variants]]。
3. 切到预览，检查眨眼、口型、转头和头发运动。
4. 用 {key:SAVE_PROJECT} 保存为 `.psd2live` 工程。PSD 的每个图层同时登记为素材，见 [[layout-project]]。
{tutorial=BASIC}
## 与 Cubism 的差异
- Cubism：载入 PSD 只生成图形网格与部件，网格、变形器、参数都需要手动或用辅助功能逐项建立。
- PSD2Live：导入即得到可动的完整模型，之后在编辑器中修改；所有修改作为编辑记录保存，重新生成时会重放。
- Cubism 的部件按 PSD 文件夹建立；PSD2Live 按识别的部位自动建立部件。
- 已有的 Cubism 模型可通过 [[cmo3-import]] 打开。

@@ psd-re-import | PSD重新载入
修改了原画后，需要把新像素带进已有的工程。PSD2Live 没有按图层对应关系重新载入整份 PSD 的功能，而是按需要选择下面的方式。
## 替换个别图层的像素（保留编辑）
1. 在素材面板 **导入** 修改后的 PSD，它会成为一个新的素材文件夹。
2. 在画布或图层列表选中要更新的图层。
3. 在新素材上右键 **替换选中图层的图片**。图层在画布上的位置与大小不变，只有像素和纹理集图块变化。
4. 点生成栏的 **重新生成**。替换过图片的图层默认按新像素重新生成网格；想保留原网格，在生成按钮的下拉中选 **生成但保留替换图片的几何**。
也可在 **纹理** 面板用 **替换图像…** 替换单个图层，见 [[png-file-export-replacement]]。
## 增加新图层
把新素材拖到画布上摆放，标好标签后 **重新生成**，已有编辑保留，见 [[layout-project]]。
## 从头重新生成
**模型 → 重新分析 PSD**（{key:REANALYZE}）重新读取当前 PSD 并按当前预设生成一个新工程。有未保存的修改时会先询问是否保存；原工程中的编辑不会带入新工程。
## 与 Cubism 的差异
- Cubism：PSD 重新载入时按图层名称或手动指定对应关系，替换已有图形网格的纹理，并可选择是否保留网格。
- PSD2Live：没有整份 PSD 的对应关系设置，通过素材替换逐层更新像素；新增图层通过摆放加入，再重新生成。
!> 已有作者编辑、绑定或物化网格的图层，替换图像并重建网格可能会被拒绝，原因显示在纹理集页面上方。

@@ model-presets | 模型预设
**模型预设** 面板决定自动生成哪些内容以及生成的幅度：形变与口型、Rig 数值、动作、物理与模拟。修改后模型按新设置重新生成，你已有的编辑照常重放。
## 在哪里设置
- 导入前：开始页 **从 PSD 生成** 的详情面板，可选 **最小** / **默认** / **完整** 预设后逐项调整。生成按钮的菜单可切换预设，或 **应用到当前模型**。
- 导入后：**模型预设** 面板（**窗口** 菜单中可重新打开）。顶部工具条可全部展开 / 折叠，**恢复默认** 把所有模型预设恢复为默认值。
## 各组内容
| 组 | 内容 |
|---|---|
| 形变与口型 | 五官位移变形器开关、头部幅度与身体幅度（0–4 倍）、生成上下唇描边及线宽与颜色、嘴形设置 |
| Rig 数值 | 身体 X（左右转身）、身体 Y、身体前后倾、大小变（头身比）、身体 Z 与呼吸、立体与透视；**高级** 中是头部转向、眼睛、眉毛、嘴巴 |
| 动作 | **基础动作**、**骨骼动作** 两组；关闭后该组动作从动画面板、预览和导出中移除 |
| 物理与模拟 | 前发、后发各选 **模拟** / **经典摆动** / **关闭**；**服装** 模拟（只模拟宽松部位）；果冻眼；自动 Pin 物理权重 |
勾选 **仅选中** 时，物理与模拟的预设只作用于选中的图层。
## 使用建议
1. 先保留默认值生成并预览。
2. 需要调整时每次只改一项，观察预览变化。
3. 贴图图集的参数不在这里，在导出窗口中设置。
{tutorial=BASIC}
## 与 Cubism 的关系
Cubism 没有对应的面板：变形器、参数、动作和物理都由制作者手动建立，或分别使用 [[auto-generation-of-deformer]]、[[face-auto-edit]]、[[auto-generation-of-sway-motion]] 等辅助功能。PSD2Live 的模型预设把这些生成步骤集中在一处，且修改后可随时重新生成。

@@ update-generated-rig | 更新生成结果
开启头发模拟、启用骨架、拆分图层等会改变自动生成结果的操作，会把你已有的编辑合并到新的生成结果上，并保存为固定的数据，此后升级程序也不会自动改变这些结果。想采用新版本生成器的改进时，使用 **更新生成结果**。
## 操作
1. 先用 **模型 → 预览生成结果更新** 查看：状态栏显示更新会不会改变模型、有几项需要查看，工程本身不变。
2. 执行 **模型 → 更新生成结果**。你没改过的部分换成新版本的生成结果，你的修改保留。
3. 无法干净迁移的地方会在状态栏提示条数，并在检视面板的 **生成结果覆盖** 中列出。
打开工程或生成结果变化后，程序会在后台检查是否有较早版本合并得不对的结果，有则在编辑画布顶部提示，可直接点「更新生成结果」或「预览变化」。关闭提示后，在生成结果再次变化前不会再出现。
## 注意事项
- 生成结果没有变化时不产生历史；更新是一步历史，可撤销。
- 在生成器生成的关键形上做的画布编辑，会作为对生成结果的覆盖保存，更新时与新结果三方合并。
## 与 Cubism 的关系
Cubism 中模型数据就是制作者手动建立的结果，不存在需要更新的生成部分。PSD2Live 的模型由生成结果加上你的编辑组成，本功能负责在生成器改进后把两者重新合并。

@@ texture-atlas-edit | 编辑纹理集
纹理集是导出时把所有图层像素打包成的贴图页面。PSD2Live 在 **纹理** 工作区中显示纹理集，可以逐个图层调整图块的位置、密度与旋转，并设置页面预算。
## 三种尺寸
每个图层有三种尺寸：在画布上覆盖的矩形（画布单位）、自身栅格的像素，以及在纹理集中的图块像素。**纹理** 面板以「画布 → 原图 → 纹理集」三格并列显示所选图层的这三项。
## 在纹理集页面上操作
- 单击图块选择对应图层，在空白处拖动框选；选择与画布和图层列表同步。
- **拖动图块** 移动位置；与其他图块的网格重叠或超出页面时图块显示为红色，松开不移动。
- 拖动所选图块的角点按比例调整密度；拖动顶边外的圆形手柄旋转，按住 {kbd:Shift} 以 15° 步进。
- 右键图块可加倍 / 减半密度、旋转 90°、移到其他页、锁定尺寸、排布所选图块、替换图像。
移动、缩放和旋转先进入调整会话，页面顶部显示会话栏，可撤销、重做、**放弃**，点 **应用** 后作为一步历史提交。
## 排布与预算
- 左上角 **排布** 按菜单选项一次性排布并保存：**按网格形状（图块嵌套）** 或 **按矩形**，范围为 **全部图块** 或 **仅所选图块**。
- **自动排布** 开启时每次修改后按矩形重新排布；关闭时（新工程默认）保持当前布局。
- 右上角 **纹理集预算** 设置页面尺寸、最多页数与间距。「适配」低于 100% 表示放不下，所有未锁定图块一同缩小；**锁定尺寸** 的图层保持尺寸。
## 纹理面板
**纹理密度** 滑块与 ½× / 2× / 重置按钮调整每个原始像素对应的纹理集像素（1/64–16）。未选图层时显示每页尺寸、图块数、占用、显存估算等概况。
## 与 Cubism 的差异
- Cubism：在纹理集编辑对话框中手动摆放与缩放图形网格，按纹理尺寸设定集合。
- PSD2Live：纹理集随模型自动打包，在纹理工作区中可随时调整，调整按网格实际覆盖的区域判断重叠；导出对话框只显示纹理集摘要。
*> 编辑画布右下显示栏的 **原始像素** 让画布直接采样图层自身的栅格，用于对比打包后的清晰度。

@@ concept-of-artmesh | 关于图形网格
图形网格（ArtMesh）是把纹理贴在由顶点和三角形组成的网格上的对象，移动顶点即可让图像变形。PSD 中的每个图层导入后成为一个图形网格，在 PSD2Live 中也称为画元。
## 网格的构成
- 顶点：网格上的点，变形时移动的对象。
- 边与三角形：连接顶点，决定图像如何随顶点拉伸。
- 轮廓：沿图层不透明像素的边缘，网格外的像素不显示。
顶点越密，变形越细腻，但编辑和运行时的负担也越大。PSD2Live 导入时按图层的 Alpha 自动生成网格，见 [[mesh-edit]]；需要局部调整时见 [[mesh-edit-manual]]。
## 属性
选中图形网格后，**检视面板** 显示名称、ID、部件、变形器、剪贴 ID、反转蒙版、绘制顺序、不透明度、正片叠底色、屏幕色、混合模式、剔除与用户数据。
{tutorial=LIVE2D_BRIDGE}
*> 网格变形器（Warp）、旋转变形器负责带动图形网格整体变形，见 [[deformer]]。

@@ mesh-edit | 自动网格生成
PSD2Live 导入 PSD 时自动为每个图层生成网格：先沿图层 Alpha 描出轮廓，再按设置放置边缘点与内部点并三角化。网格的疏密与形状由 **网格** 面板的设置决定，可以全局设置，也可以按部件覆盖。
## 网格面板
在 **网格** 工作区或 **窗口** 菜单打开 **网格** 面板：
- **全局默认** 作用于所有未单独覆盖的部件。
- 选中某个 ArtMesh 后，面板显示该部件自己的设置，修改后该部件显示「已自定义设置」。
- 网格未覆盖部分可见像素时，面板会提示比例；点 **按当前像素重建** 即可包含。
## 主要设置
| 分组 | 设置 | 作用 |
|---|---|---|
| 轮廓位置 | 单层 / 双层 / 三层边缘、外边缘距离、边缘网格宽度 | 轮廓附近放几圈顶点及其位置 |
| 点位密度 | 边缘点距离、内部密度 | 轮廓顶点间距与内部点距 |
| 内部填充算法 | 渐疏泊松填充（默认）、平衡四叉树填充、正三角分形细分、轮廓层铺、简单三角填充 | 内部点的排布方式 |
| 连接拓扑 | 抑制边缘点之间的跨越连线 | 让非相邻边缘点通过内部点连接 |
| 单位 | 随文档尺寸缩放、按贴图像素描出轮廓、包裹 | 长度单位、描轮廓的精度、闭合睫毛等细小凸起之间的缝隙 |
修改设置会重建网格，已有的关键形、路径、权重与胶水迁移到新网格上。
## 与 Cubism 的差异
- Cubism：载入后对选中的图形网格执行自动网格生成，从预设中选择后调整边距与点间隔。
- PSD2Live：导入时已为所有图层生成网格，设置作为全局默认与部件覆盖保存，随时修改随时重建。
- PSD2Live 提供多层边缘与多种内部填充算法，以及按贴图像素描轮廓与包裹拓扑。
*> 设置面板的 **显示说明** 可展开每个选项的解释。

@@ interior-shape | 内部造型
内部造型是可选的网格关键形生成器：它让图层内部的纹理随一个虚拟曲面产生收放和偏压，使衣服、头发等大块部件在转动时有体积感。它不生成新纹理或阴影，也不是布料模拟。
## 使用
1. 选择一个已生成的图层，打开 **内部造型** 面板。
2. 勾选 **启用**，程序生成内部造型并开始试动。
3. 在 **造型** 中调整横向 / 纵向幅度、曲面鼓起、偏压、褶皱强度与轮廓保持。
4. 需要运动带缓动时，打开 **缓动与传动**，设置缓动时间、传递时间、传动强度与 **传动方向**。
5. 在 **试动** 中拖动二维参数盘或开启 **鼠标跟随** 检查效果；**独显并居中** 只显示此图层并在画布居中。
拖动结束提交一条历史记录。生成失败时保留草稿和之前的有效结果。
## 设置
| 设置 | 范围 | 含义 |
|---|---|---|
| 横向 / 纵向幅度 | 0–2 | 两个方向各自的造型总量 |
| 曲面鼓起 / 偏压 | 0–2 | 虚拟拱面及其偏压程度；任一为 0 时无曲面位移 |
| 褶皱强度 | 0–2 | **局部褶皱** 的贡献；没有局部褶皱时不生效 |
| 轮廓保持 | 0–1 | 0 释放可见轮廓，1 保护原图轮廓 |
| 缓动时间 | 0–0.6 秒 | 第一阶段的响应时间 |
| 传递时间 | 0–0.5 秒 | 后区相对前区的传播时间 |
| 传动强度 | 0–1 | 后区权重，0 不分区 |
**更多设置** 中的横 / 纵鼠标倍率只影响鼠标试动，不改变关键形幅度或导出的参数范围。**驱动参数** 可选择已有参数或 **新建参数**。
## 注意事项
- 关闭 **启用** 保留设置，不应用形变；**删除效果** 移除配方及其物理，可撤销。
- 网格、素材或驱动参数变化后，面板提示重新生成或重新绑定；失效的效果在导出时跳过并在警告中列出。

@@ system-of-parent-child-relation | 父子结构的机制
对象挂在哪个变形器下，就跟随哪个变形器移动，这就是父子结构。子对象的形状在父级的局部空间中求值，父级变形后，子对象被整体带着走；子对象自己的关键形再叠加在上面。
## 继承的规则
- 网格变形器下的对象：整个形状随父级网格一起弯曲。
- 网格变形器挂在网格变形器下：子变形器的控制点被父级变换，内部再按自己的网格插值。
- 旋转变形器挂在网格变形器下：只继承原点位置和角度，父级的非刚性弯曲传不到它下面。
- 旋转变形器下的对象：随原点刚性转动。
## 父级与直接绑定
对象自身绑定的参数决定它自己的形状；父级的参数通过层级传下来。编辑时先确认要改的是对象自己的轴还是父级带来的运动，避免把父级姿态误当成对象的直接绑定。
*> 层级树中的「父级」徽章标出所选对象的祖先。
相关：[[setting-of-parent-child-relation]] · [[combintion-of-parent-child-relation]] · [[keyform-parent-chilid-relation]]

2. 拖到目标变形器上松开，即挂到它下面；拖到「移到顶层」区域则移到根级。
3. 改父级是一步历史，可撤销。

@@ combintion-of-parent-child-relation | 父子结构的组合
多个变形器嵌套，可以把复杂的动作拆成几层简单的运动：外层负责大的转向，内层负责局部的弯曲或旋转，各层只绑定自己需要的参数。
## 生成模型中的组合
PSD2Live 生成的身体就是这样分层的：
1. `DeformBodyXY`：身体 X / Y，整个上半身转向、随髋部移动。
2. `DeformBodyLean`：身体前后倾与大小变（头身比）。
3. `DeformBodyZBreath`：身体 Z 与呼吸。
4. 其下是头部旋转与面部经纬网，再往下是五官与头发。
每层只处理自己的参数，下层自动继承上层的运动；例如头部旋转会同时被身体转向带动。实际结构以层级树为准。
## 组合时注意
- 粗网格的上层变形器会重新采样下层的形状，精细的弯曲放在离网格最近的一层。
- 旋转变形器放在网格变形器下时只继承原点和角度，需要跟随弯曲的部件应挂在网格变形器下。
*> 启用骨架后，躯干弯曲与四肢旋转变形器接在这条链的末端，见 [[skeleton]]。

@@ auto-generation-of-deformer | 变形器的自动生成

## 自动生成的内容
- 身体链：身体 X/Y、前后倾、身体 Z 与呼吸，站立全身角色另有腿部变形器。

2. 你在生成结果上做的编辑会合并到新的生成结果上保留。

- Cubism 的自动生成为所选对象创建单个变形器结构；PSD2Live 在导入时一次生成整个模型的变形器链和关键形。
- 生成结构随模型预设变化，具体对象以层级树为准。

@@ parameter | 关于参数
参数是驱动模型动作的数值滑块，例如角度 X、眼睛开合。对象在参数的若干个键上各记录一个形状（关键形），参数取中间值时形状自动插值。动画和物理最终都是在随时间改变参数值。
## 参数面板
| 操作 | 方法 |
|---|---|
| 改变数值 | 左键拖动滑条 |
| 吸附到键 | 悬停在键标记上右键单击 |
| 二维控制 | 两个参数关联后显示为 2D pad：左键拖动，右键吸附到两个参数的键交点 |
| 复位 / 锁定 | 行内复位按钮；锁定参数值；工具栏「全部复位」「全部解锁」 |
| 查找 | 搜索名称或参数 ID；「仅关联」只看绑定到选中组件的参数 |
| 属性 | 单击参数名打开「参数属性」 |
## 键的标记
- 圆点：普通键，键与键之间插值。
- 方点：融合变形键，把形状差叠加到基础形状上，见 [[blend-shape]]。
- 悬停键标记会列出在该键上有关键形的组件。
- 带物理图标的参数是物理输出参数，预览中由物理接管。
!> 参数上的键属于建模数据，与动画时间线上的关键帧不同。
*> PSD2Live 中的参数操作与 Cubism 基本一致；多个画布共用同一份参数姿态。

@@ edit-parameters | 向参数追加/删除键
在 PSD2Live 中，键的位置定义在参数上，所有绑定该参数的对象共用；对象在某个键上被修改时，形状记录到该键上。
## 编辑参数的键
1. 在参数面板单击参数名，打开「参数属性」。
2. 在「关键点」轴上：点击空白处加点，拖动调值；点击数字可直接修改，回车确认；右键删除。
3. 「步长」决定拖动时的吸附间隔，「均分」把关键点均匀分布；轴两端可直接输入最小值、默认值、最大值。
4. 用「撤销点编辑」「恢复点编辑」回退，点「保存」一次提交。
## 让对象绑定到参数
1. 选中对象。
2. 在参数面板把参数拖到目标键的值（或右键吸附到键），面板中操作的参数即成为编辑目标。
3. 切到变形模式（{key:MODE_DEFORM}）修改形状，结果写入该键的关键形。
!> 移动键时，已有的关键形随键一起移动；删除键会同时删除各对象在该键上的形状，可撤销。
## 与 Cubism 的差异
- Cubism 在选中对象后用「追加 2 点 / 3 点」等按钮给该对象单独加键；PSD2Live 在「参数属性」中统一编辑参数的关键点，对象通过在键上变形来记录形状。
- 新建参数本身不会产生运动，需要在键上给对象做形状。

@@ keyform-parent-chilid-relation | 关键点（父子结构的动作）
父变形器和子对象可以绑定同一个参数，各自在键上记录形状；参数变化时，父级带动的整体运动与子对象自己的形状叠加，得到最终结果。
## 示例
角度 X 转头时，头部的变形器负责整个头部的转向，面部经纬网与五官再各自按角度 X 修正形状。生成的模型就是这样分层绑定的。
## 编辑时注意
- 选中对象后看清它直接绑定的参数，与父级通过层级带来的运动区分开。
- 在子对象上编辑的形状以父级在当前姿态下的状态为基础。
- 镜像关键形只处理对象自身的形变，以默认姿势的父级为坐标系；父级的关键形需要单独镜像。
*> 参数面板的「仅关联」列出直接绑定到选中组件的参数。

@@ keyform-xydirection | 关键点（添加X和Y的移动）
对象同时绑定两个参数（如角度 X 与角度 Y）时，关键形排成一张网格：每个 X 键与每个 Y 键的组合都有一个形状，斜向姿势由四周的键插值。
## 制作方法
1. 在参数面板把两个参数关联为 2D 控制器（行内的关联按钮），在 pad 上右键吸附到两个参数的键交点。
2. 在变形模式中依次为各交点做形状：先做端点和中点，再做四个斜角。
3. 用 pad 在键之间拖动检查插值是否自然。
## 生成模型
生成的头部按角度 X / Y 的端点与中点组合生成九个姿势，斜角另有修正，强度可在模型预设「Rig 数值」中调整。
*> 斜角姿势的形状不会自动合成，需要逐个制作（Cubism 的 [[synthesize-corners]] 尚未提供）。

@@ face-auto-edit | 面部动作的自动生成
PSD2Live 导入 PSD 时会自动生成整套面部动作：头部转向、眨眼、眼球、眉毛、嘴型与口型，不需要先手工做好上下左右的形状。
## 生成的内容
- 头部 X / Y：端点与中点组合成九个姿势，以原画头部倾斜为基准；斜角另有修正。
- 面部采用经纬网和分区修形；眼眉、瞳孔、嘴和耳朵有独立的补偿或遮罩。
- 嘴部：按嘴形设置生成开合与嘴型，可选生成上下唇描边。

2. 在「Rig 数值」组细调头部转向、眼睛、眉毛、嘴巴、鼻子与耳朵、头发各项；不常用的项在「高级」中。
3. 修改后模型重新生成，已有的手动编辑按合并保留。
!> 这是按预设算法生成的结果，不是 3D 重建。分层方式、宽发片、极端角度和重叠区域都可能需要手动修形。

- Cubism 根据已经制作好的上下左右形状自动生成面部的其余动作；PSD2Live 直接从 PSD 图层生成全部面部动作，用数值调整幅度。

@@ auto-generation-of-sway-motion | 摇摆运动的自动生成
摇摆生成对应 Cubism 的“摇摆运动的自动生成”：选中网格变形器（或网格），在参数 -1 / 0 / 1 上自动生成摆动的关键形，并同时生成物理摆锤。设置随工程保存，可随时重新打开调整。
## 打开
- 物体模式下右键画布上选中的网格或网格变形器 →「生成摇摆...」；已生成的显示「编辑摇摆...」。
- 层级树右键同样的菜单。
- 物理面板「+ 新建」→「为选中对象创建摆动…」。
选中网格时会自动包一层贴合的网格变形器。旋转变形器不能作为目标。
## 编辑
1. 打开后画布进入摇摆编辑，左下角显示浮动的摇摆面板。
2. 在画布上拖手柄：尖端圆点设幅度和上翘，中心线菱形设柔软度，尖端两角设放大 / 缩小与平行，空心圆旋转整个摇摆矩形，空心方块改支点边。
3. 面板中选择摇摆方向（左右 / 上下，可同时勾选）、分段（1–3）、自动估计（发丝 / 饰品 / 布料）与是否生成物理摆锤。
4. 「预览摆动」查看效果；「生成」/「应用」或 Enter 写入，「取消」或 Esc 放弃。
## 生成器与烘焙
- 摇摆轴上的关键形归摇摆所有，每次重建按目标当前形态重新计算；在这些关键形上的手动修改记为生成结果覆盖（见 [[generated-overrides]]）。
- 「烘焙为关键」把当前形态写成普通关键形，只保留物理摆锤；「删除」连同生成的轴和自动创建的参数一起移除。
## 与 Cubism 的差异
- Cubism 以弯曲变形器为目标生成摇摆；PSD2Live 另外支持网格目标（自动包一层变形器）、左右与上下两种摇摆、分段、底部平行（多束头发一起摆）与旋转摇摆矩形。
- 同时生成物理摆锤，导出到 physics3.json 和 cmo3。
- 参数不存在时自动创建，命名为 `ParamSwing<id>`。

@@ glue | 胶水

1. 在物体模式选中两张网格，切到编辑模式（{key:MODE_EDIT}）。
2. 选 Glue 胶合工具（{key:TOOL_GLUE}），其下有三个子工具：胶水刷、权重笔刷、重新合并（`1`–`3`）。
3. 在重叠处涂胶水刷；或按 {key:FINISH_PATH} / 模式条「创建胶水」沿两条轮廓整段胶合。
## 操作
| 操作 | 效果 |
|---|---|
| 胶水刷 | 在重叠处让另一网格新增或滑动一个顶点（UV 随之移动），只改网格不改画面 |
| Alt + 拖动 | 解除胶合 |
| 权重笔刷 | 以蓝色（A）/ 橙色（B）显示并绘制两侧权重 |
| 重新合并 | 去掉被刷顶点上已有的胶合，再按吸附容差重新胶合 |
| {key:GENERATE} | 胶合任一网格上选中的顶点（此时不打开导出） |
| 右键「按距离重新合并整段」 | 去掉两网格间的全部胶合，沿轮廓重新胶合 |
!> 胶合在静止形（所有参数为默认值）上进行。参数不在默认值时，胶水刷、重新合并和创建胶水会先把参数平滑移回默认值再胶合。
## 与 Cubism 的差异
- PSD2Live 的胶水刷会在另一网格上新增或滑动顶点，使两侧顶点重合，不要求两张网格事先有对齐的顶点。
- 骨骼拆分的肢体和前后分层会自动生成胶水。

@@ deformpath | 转换路径
变形路径（实验性）是挂在网格上的编辑辅助对象：沿部件画一条曲线，拖动曲线控制点就能让网格顺着曲线变形，结果写成网格的关键形。它不是第三种变形器。
## 创建与编辑
1. 选中画元，在层级树右键「变形路径」，或用 {key:TOOL_CREATE_DEFORM_PATH}。
2. 在画元上单击放置至少两个控制点，按 {key:FINISH_PATH} 确认，{key:CANCEL} 取消。
3. 在编辑模式调整路径的绑定位置、影响宽度、硬度、闭合与角点；此时网格不动。
4. 在参数面板设置目标姿态，切到变形模式拖控制点，形状写入画元的关键形。
## 编辑层级
路径分 L2 / L3 两组，各存一套，在放置面板或「工具细节」的「路径编辑层级」中选择，已有路径在检视面板的「编辑层级」中修改；画布只显示当前组的路径。
## 导出
| 文件 | 内容 |
|---|---|
| `.cmo3` | 路径控制器结构及网格关键形 |
| `.moc3` | 烘焙后的网格关键形，运行时不执行路径算法 |
!> 一个网格可以有多条路径，但一条路径不能控制多个网格。拖动效果尚未与 Cubism Editor 完全验证一致，宽度、硬度与大角度形变需要检查。
## 与 Cubism 的差异
- PSD2Live 的路径只作用于一个网格，是网格上的编辑辅助；`.moc3` 中只留下烘焙后的关键形。
- 路径的编辑层级 L2 / L3 与网格变形器的顶点 / 贝塞尔级别无关。

@@ skinning | 蒙皮
蒙皮让一张跨关节的网格随多根骨骼平滑弯曲。Cubism 的蒙皮把网格转换成一串旋转变形器；PSD2Live 用自己的骨架完成同样的事：把网格绑定到骨骼，权重自动计算，导出时再烘焙成 Cubism 的变形器与关键形。
## 绑定与权重
1. 在骨骼模式选「编辑骨骼」（{key:TOOL_SKELETON_EDIT}），用「绑定」子工具把网格绑定到骨骼；同一条肢体的网格只需绑定到其中一根。
2. 权重在整条肢体上自动计算：每个顶点最多跟随关节两侧的两根骨骼，在「关节带宽」内平滑过渡。
3. 需要修正时用「权重」子工具：选已绑定的网格和同一肢体内的骨骼，按增加、减少、替换、平滑绘制。
4. 「工具细节」中可清理、恢复自动权重，或复制 / 镜像权重到另一网格。
5. 显示栏的「显示蒙皮权重」按骨骼颜色给顶点着色。
## 烘焙结果
关节带内的顶点按角度混合绕关节旋转，弯曲时肢体宽度不变；导出时写成旋转变形器加网格的修正关键形。
## 与 Cubism 的差异
- Cubism 的蒙皮在网格上直接生成旋转变形器链，之后在 Cubism 中编辑；PSD2Live 的权重属于骨架，修改骨骼后重新烘焙。
- 每个顶点最多受两根相邻骨骼影响。
详见 [[skeleton]]。

@@ skeleton | 骨骼
骨骼是 PSD2Live 的快速肢体绑定工具：用骨架带动身体、四肢、尾巴和翅膀，导出时烘焙成 Cubism 能直接运行的结构——躯干弯曲变形器、四肢的旋转变形器和跨关节网格的修正关键形。导出的模型不依赖本程序。
## 骨骼模式
骨骼的操作在「骨骼」标签页（与层级树并列）和画布的骨骼模式（{key:MODE_SKELETON}）中进行：
| 工具 | 快捷键 | 子工具 |
|---|---|---|
| 骨骼姿态 | {key:TOOL_SKELETON_POSE} | 自动 / FK / IK |
| 编辑骨骼 | {key:TOOL_SKELETON_EDIT} | 编辑 / 新骨骼 / 挤出 / 绑定 / 权重 |
## 创建骨架
1. 进入骨骼模式；工程还没有骨架时，点画布中央或「骨骼」标签页的「创建骨架」。
2. 程序按图层标签和侧别自动推断骨骼并绑定：手臂绑 handwear，腿绑 legwear，脚绑 footwear，尾巴、翅膀绑各自的图层。
3. 用「编辑」拖动关节端点调整位置；「新骨骼」「挤出」添加自定义骨骼；「绑定」批量绑定网格。
4. 「工具细节」中可复制、镜像、细分、融合骨骼；选中骨骼后可调「关节带宽」与最小 / 最大角度。
5. 点「完成」保存为一条历史；切到骨骼姿态、换模式或选中别的图层也会保存，只有「取消」放弃本次修改。
## 摆姿态
- 拖动骨骼身体为 FK，只旋转这根骨骼；拖动末端或按住 Shift 拖动为 IK。
- 「工具细节」可设置 IK 链长、迭代与弯曲方向，并固定所选骨骼末端。
- 摆姿态只修改参数值，不产生历史；「重置姿态」归零。命名姿态可保存并插入动画。
## 生成的结构与参数
- 躯干弯曲 `DeformSkelTorso`，四肢、尾巴、翅膀的旋转变形器 `DeformSkel_<骨骼 ID>`。
- 骨骼参数如 `ParamArmLA`、`ParamLegLA`、`ParamTail1..n`，单位为度。
- 姿势参数：下蹲、重心转移、甩尾、扇翅、膝盖内扣、弹起。
- 骨骼动作在动画面板中出现，见 [[builtin-motions]]。
- 「骨骼参数采样」设置容差、最小角度间隔和单网格关键形上限，控制导出体积。
!> 左右画在同一图层的肢体不会被绑定，请先用「模型 → 按网格拆分图层…」拆开。骨骼烘焙后 Cubism Editor 中不保留骨骼语义，需要继续改骨骼时请保留 `.psd2live` 工程。
!> 骨骼参数中能相加的四肢参数在导出目标为 Cubism 5.0 及以上时写成融合变形参数；目标低于 5.0 时全部烘焙为普通关键形，旋转变形器上的姿势会被去掉。
## 与 Cubism 的关系
Cubism Editor 没有骨架对象，肢体通常用旋转变形器链和蒙皮手工搭建。PSD2Live 的骨骼是生成这些结构的工具：在骨架上摆放、绑定、调权重，导出时自动得到同样的变形器与关键形。相关：[[skinning]] · [[making-and-rotation-of-rotationdeformer]]

@@ generated-overrides | 生成结果覆盖
摇摆、模拟等生成器的关键形每次重建都会重新计算。你在这些关键形上的修改不会被覆盖掉，而是记录为“生成结果覆盖”，在所有生成器之后与生成结果合并。
## 哪些编辑是覆盖
- 摇摆在目标网格变形器上生成的关键形（摇摆参数不在默认值时）。
- 已烘焙模拟以关键形轴写回网格的关键形。
- 骨骼蒙皮写在你自己改挂的网格上的关键形。
生成参数在默认值处的编辑仍是普通编辑，修改的是静止形状。
## 合并规则
| 情况 | 结果 |
|---|---|
| 你没改过的点 | 跟随新的生成结果 |
| 生成器没变的点 | 保留你的值 |
| 两边都改了 | 保留你的值，并报告冲突 |
## 查看问题
检视面板工具栏在有问题时显示「n 项覆盖问题」徽标；选中对象的问题列在检视面板顶部的「生成结果覆盖」中，点徽标列出全部问题。
- 冲突：某些点同时被生成器和你的编辑修改，已保留你的编辑。
- 未生效：生成的关键形已不存在、生成的形状点数已改变，或网格已被拆分替换。
!> 复制到或复制自生成的关键形、在生成器的轴上增删键无法作为覆盖记录，会被拒绝。想完全手动编辑摇摆时，先在摇摆面板「烘焙为关键」。
## 与 Cubism 的关系
Cubism 的自动生成是一次性的，生成后就是普通关键形。PSD2Live 的生成器会随设置重新运行，覆盖机制让手动修改在重新生成后保留下来。相关：[[auto-generation-of-sway-motion]] · [[simulation]] · [[update-generated-rig]]

@@ motion-mirroring | 动作镜像
把一侧做好的关键形左右镜像到另一侧，例如角度 X 30 的形状镜像到 -30，或左眼的形状镜像到右眼。结果写成普通关键形，可撤销。
## 使用方法
1. 在变形模式选中对象，把参数调到要镜像的键。
2. 在画布右键菜单「镜像关键形」中选择操作，或按 {key:MIRROR_KEYFORM} 镜像到对称键。
| 操作 | 作用 |
|---|---|
| 镜像到对称键 | 把当前键镜像到对称键，并切换到该键显示结果 |
| 从对称键镜像 | 用对称键的形状覆盖当前键 |
| 镜像到对侧对象 | 写到另一侧的同类对象，带 L/R 的参数换成另一侧，左右参数取反 |
| 原位左右翻转 | 以对象自身中心翻转当前键 |
| 全部键镜像到另一侧 / 到对侧对象 | 一次处理所有键 |
## 规则
- 取反的左右参数是范围以默认值对称、且为二维关联横轴或 ID 以 X、Z 结尾的参数（AngleX、BodyAngleX、EyeBallX 等）。
- 对侧对象先按图层语义配对，再按名称中的 L/R、Left/Right、左/右配对。
- 镜像只处理对象自身的形变，父级的关键形需要单独镜像；选中多个图层时分别镜像，在一条历史中提交。
## 与 Cubism 的差异
- PSD2Live 在画布右键菜单中操作，对称键与对侧对象按参数和图层语义自动判断，不需要另行指定对应关系。

@@ deform-brush | 变形笔刷

@@ blend-shape | 融合变形
融合变形参数把形状差叠加到对象已有的关键形上，而不是与其他参数的键相乘。多个参数各自独立作用时，用融合变形可以大幅减少关键形数量。PSD2Live 支持融合变形参数，但产品中的编辑流程仍在完善。
## 已经可以做的
1. 新建参数时在「参数属性」中选「融合变形」（类型只能在新建时选择，默认范围 0..1）。
2. 参数面板中融合变形的键显示为方点；0 是中性基形，不能移动或删除。
3. 把参数调到其他键，在变形模式中修改网格或变形器，即记下叠加形状。
4. 骨骼与模拟会自动生成融合变形参数（骨骼参数、模拟的模态参数），见 [[skeleton]]、[[simulation]]。
!> 尚未完善：Cubism 的权重限制设置（[[limit-settings-for-blend-shape-weights]]）、限制曲线和完整的创建流程还没有提供。
## 导出
网格与网格变形器上的融合变形需要导出目标 Cubism 4.2 及以上；旋转变形器与部件上的融合变形需要 5.0 及以上。目标版本不支持时导出会降级并在报告中说明。
## 与 Cubism 的差异
- Cubism 中可在已有参数上切换为融合变形并设置权重限制；PSD2Live 只在新建时选择类型，暂无权重限制。

@@ animation-preparation | 动画创建准备
PSD2Live 的动画在编辑器内部完成，不需要像 Cubism 那样另开 Animator、建立场景并导入模型。模型的动作（Motion）直接保存在工程里，导出时写成 `motion3.json`，或随 CMO3 写成 `.can3`。
## 动作从哪里来
- **内置动作**：生成模型时按模型预设自动生成待机、眨眼、点头、摇头等动作，有骨架时还有骨骼动作，见 [[builtin-motions]]。
- **自定义动作**：在「动画」面板点 **新建动作**，选 **空白动作** 或 **从预设复制**，之后在「动画编辑器」中逐参数打关键帧。
## 准备工作区
1. 点工作区标签栏右侧的 **+**，选 **动画** 预设：动作列表在预览画布左侧，下方是动画编辑器，右侧为参数面板。
2. 在「动画」面板中单击动作行的编辑按钮，或右键选 **编辑**，动作在动画编辑器中打开。
3. 在参数面板中拖动滑块摆出姿势，在动画编辑器中记录为关键帧，见 [[timeline-basic-operation-timelinepalette]]。
{tutorial=ANIMATION}
## 与 Cubism 的差异
- Cubism：在 Animator 中新建场景、导入模型、在时间线上放置模型轨道后制作动态；一个场景对应一个动态文件。
- PSD2Live：没有场景、模型轨道和组轨道；每个动作就是工程里的一个片段，直接驱动当前模型的参数，也不能放背景、音频或多个模型。
- 动作随工程保存，并参与撤销/重做；不需要单独保存动画文件。
*> 导出 CMO3 时，动作另存为同名 `.can3`，可在 Cubism Editor 的 Animator 中与 cmo3 一起打开继续编辑。
@@ builtin-motions | 内置动作
内置动作是 PSD2Live 按模型自动生成的动作，无需手动打关键帧即可得到待机、眨眼等常用动态，并随模型一起导出。
## 动作列表
| 分组 | 动作 | 说明 |
|---|---|---|
| 基础动作 | 待机动画、眨眼动作、点头动作、摇头动作 | 任何模型都能播放；待机动画为循环 |
| 骨骼动作 | 甩尾、下蹲、重心转移、害羞扭捏、挥手、歪头、开心欢呼、单脚翘、开心摇摆、少女待机 | 需要骨架；当前骨架无法播放的动作不列出；少女待机为循环 |
模型预设「动作 (Motions)」组的 **基础动作**、**骨骼动作** 两个勾选框决定整组是否生成，见 [[model-presets]]。
## 调整与开关
1. 在「动画」面板的 **内置动作** 文件夹中，勾选或取消每行左侧的勾选框，决定该动作是否导出。
2. 单击动作行展开它的调节项：例如待机动画有 **摆动**、**呼吸**、**头部**、**速度** 与 **眨眼** 开关；眨眼动作有 **闭合程度**、**速度** 与 **连眨两次**；点头、摇头有 **幅度**、**速度**、**次数**。
3. 行右侧的播放按钮在预览画布中播放该动作。
## 手动修改
在动画编辑器中打开内置动作并修改关键帧后，行上显示 **已修改**，调节项变为不可用（关键帧已手动修改，恢复默认后才能使用这些参数）。右键菜单：
- **复制为自定义动作**：以当前内容新建一个自定义动作，原内置动作不变。
- **恢复默认**：丢弃手动修改，回到按调节项生成的结果。
- **删除**：删除后不再导出；可从 **新建动作** 菜单的 **恢复已删除的预设** 找回。
!> 物理驱动的参数不会写进待机动画，以免与物理输出冲突。
## 与 Cubism 的关系
Cubism 没有自动生成的动作，需要在 Animator 中手动制作。内置动作相当于预先做好的动态，导出后与手动制作的动态一样写成 `motion3.json`；循环动作归入 `Idle` 组，见 [[notes-for-sdk]]。

@@ about-fade | 关于淡变
淡变（Fade）是动作开始和结束时与其他动作之间的过渡时间。运行时切换动作时，新动作在淡入时间内逐渐生效，旧动作在淡出时间内逐渐消失，避免姿势突变。
## PSD2Live 中的淡变
- 自定义动作有 **淡入时间 (s)** 与 **淡出时间 (s)**，默认均为 1 秒，导出到 `motion3.json` 的 `FadeInTime` / `FadeOutTime`。
- 未经手动修改的内置动作不写淡变时间，由运行时使用默认值。
- 导出 CMO3 时，淡变写入 `.can3` 的场景。
设置方法见 [[fade-setting]]。
*> 淡变只在运行时切换动作时起作用；编辑器预览单独播放一个动作时看不出差别。
@@ fade-setting | 淡变值设置
在「动画」面板中设置自定义动作的淡变时间。
1. 在「动画」面板的 **自定义动作** 文件夹中，单击要设置的动作行，展开设置。
2. 在 **淡入时间 (s)** 与 **淡出时间 (s)** 中输入 0–5 秒的值。
3. 导出后写入该动作的 `motion3.json`。
*> 内置动作需要淡变时，先用 **复制为自定义动作** 复制一份再设置。
## 与 Cubism 的差异
- Cubism：在时间线面板中为整个动作设置淡入/淡出，也可以为每条参数曲线单独设置淡变。
- PSD2Live：只能在「动画」面板中为整个动作设置淡入/淡出，没有逐参数曲线的淡变。

@@ notes-for-sdk | 嵌入SDK时的注意事项

## 文件与分组
| 动作 | 动作组 | 文件名 |
|---|---|---|
| 待机动画与其他循环动作（含循环的自定义动作） | `Idle` | `<模型名>.<动作>.motion3.json` |

## 注意事项
- 只写入模型中存在的参数；动作里指向已删除参数的轨道不导出。
- 贝塞尔手柄限制在段内（`AreBeziersRestricted: true`），各版本 SDK 都能正确播放。
- 物理驱动的参数不写进待机动画，避免动作与物理争夺同一参数。
- 动画面板中取消勾选的动作不导出；仅网格导出不写动作。
- 动作中没有用户数据事件（Event），见 [[userdata]]。
## 与 Cubism 的差异
- Cubism：在 Animator 的导出设置中逐个场景输出 motion3.json，分组与文件名由导出设置或 Viewer 决定。
- PSD2Live：导出 Live2D 模型时一次写出全部动作，分组与文件名按上表自动决定。

@@ physics-operation | 关于物理模拟
物理模拟让参数跟随头部、身体等输入产生惯性摆动，用于头发、饰品、衣物等的摇摆。PSD2Live 使用与 Cubism 相同的摆锤模型。
## 机制
- **输入**：头部、身体角度等参数推动摆锤根部（位置X）或倾斜重力方向（角度）。
- **摆锤**：从根部垂下的一串摆锤，按长度、摇摆度、反应速度、收敛速度运动。
- **输出**：某个摆锤的摆角乘以倍率后写入输出参数。
物理只写参数，摇摆的形状来自输出参数的关键形；输出参数没有做好端点形态时，参数在动但模型不动。
## 物理组的来源
物理组可以由预设（前发、后发、果冻眼）、骨骼、摆动、模拟烘焙或手动新建产生，详见 [[physics-group-information]]。
*> 面板与预览使用的物理计算逐项对应 Cubism Native Framework 的计算方式，导出的 `physics3.json` 在 SDK 中的表现与编辑器一致。
@@ physical-operation-setting | 如何设置物理模拟
在「物理」面板中选中一个物理组后，下方依次是摆锤画布、响应曲线、摆锤设置、输入、输出与高级设置。
## 摆锤画布
| 操作 | 作用 |
|---|---|
| 在空白处左右拖动 | 像在 Viewer 中拖动模型一样牵动模型，松开后回到原位 |
| 上下拖动摆锤末端的圆环 | 调整该摆锤长度；单击选中它 |
| 拖动右侧输出标签到某个摆锤旁 | 改为读取该摆锤的角度（摆锤数） |
| 单击输出标签 | 显示范围扇形，拖动扇形边缘调整倍率 |
摆锤下方的响应曲线显示向右牵动 1 秒后松开的反应，可直接比较不同设置的过冲与收敛。
## 设置项
1. **预置**：选一个预置后点 **导入**，替换全部摆锤；**追加…** 把当前摆锤存为自己的预置。
2. **编辑摆锤**：选 **全部** 或某个编号，决定下方滑块调整哪个摆锤；可追加、删除、上下移动摆锤。
3. 滑块：**总长 / 长度**、**摇摆度**、**反应速度**、**收敛速度**，名称与 Cubism Editor 相同。
4. **输入**：用 **添加** 加入参数，选择类型 **位置X** 或 **角度**，设置 **影响度** 与反转。
5. **输出**：设置 **摆锤数**、**倍率** 与反转。右侧的 **最大输出力** 显示输出达到参数端点的百分比，**按最大值调整倍率** 把它调到 100%。
6. **高级**：摆锤设置表、输出细节与 **输入标准化**。
## 与 Cubism 的差异
- Cubism：在物理模拟设置对话框中用表格输入数值，在 Viewer 中拖动模型确认。
- PSD2Live：摆锤画布中可直接拖动修改长度、摆锤数和倍率，并显示响应曲线和最大输出力。
- 输出只有角度类型：Cubism 运行时中位置X 类型输出恒为 0。
- 每次拖动或输入在松手后记一条历史，可撤销。

@@ physics-group-information | 物理模拟群组编辑
「物理」面板上方的物理组列表管理模型的全部物理组，相当于 Cubism 物理模拟设置中的群组列表。

- **空白摆锤**：默认输入头部与身体的晃动，还没有输出。
- **复制为新组**：复制所选组，输出参数清空。
- **导入 physics3.json…**：文件中的每个组成为自定义组；ID 相同的组被替换。
- **为选中对象创建摆动…**：为画布上选中的网格或弯曲变形器创建摆动，见 [[auto-generation-of-sway-motion]]。

- Cubism：所有物理组都需手动创建和设置。
- PSD2Live：大部分物理组由生成器自动创建，并可在保留修改的同时随来源更新。

@@ simulation | 布料与头发模拟
模拟在编辑器中对网格做真实的 2D 布料与头发模拟：顶点被固定点牵住，受重力和惯性驱动。Cubism 运行时不做这种模拟，所以模拟需要**烘焙**成参数、关键形和 Cubism 摆锤后才能导出。
## 基本流程
1. 在画布上选中裙子或头发的网格，在「模拟」面板点 **新建**，选 **布料** 或 **头发**。同一个物理体中的多张网格一起模拟。
2. 指定固定点：在面板 **顶点权重组** 的固定点一行点 **绘制**，或切换到画布的「模拟」模式（{key:MODE_SIMULATE}）用权重笔刷绘制；也可以在 **胶水** 中把与腰部相连的胶水设为 **作为固定点**。
3. 把面板的预览开关切到 **参考模拟**，在预览中转头、摇身体，调整材质直到自然。
4. 点物理体的 **烘焙**，或工具栏的 **烘焙全部**。烘焙在后台进行，需要数秒，完成后作为一步撤销提交。
5. 切回 **导出效果**，预览播放的就是导出模型的动作，与参考模拟对照。
## 顶点权重组
| 种类 | 作用 |
|---|---|
| 固定点 | 被 Rig 牵住的顶点，权重表示固定得多牢 |
| 刚度 | 逐顶点缩放拉伸与弯曲刚度 |
| 保形 | 逐顶点缩放向原画形状的回弹 |
| 质量 | 逐顶点缩放质量 |
| 阻尼 | 逐顶点缩放阻尼 |
权重组只存在于本软件，不写入导出文件。
## 材质与烘焙
- **材质** 节可选命名预设（棉布、丝绸、雪纺、羊毛、牛仔布、皮革、弹力布、头发、细软发、粗硬发、刘海），再微调质量、拉伸、弯曲、阻尼、保形等数值。
- **输入** 是晃动物体的参数，默认为头部与身体角度等；对物体几乎没有影响的输入在烘焙时被剔除。
- **烘焙** 节设置模态数、上下参数、关键点、夸张等，烘焙后显示与参考模拟对比的视觉检查（摆幅、滞后、回落、抖动）和 R²。
- 烘焙后，物理面板出现来源为「模拟」的摆锤组，参数面板出现 `ParamSim…` 参数。设置、网格或权重改变后烘焙显示为已过期，导出仍用旧结果，直到重新烘焙。
*> 模型预设「物理与模拟」组可一步为前发、后发与服装创建并烘焙模拟，见 [[model-presets]]。
## 与 Cubism 的关系
Cubism 只有摆锤物理，布料和长发的复杂摆动通常要手动做多个参数与关键形，再用多组摆锤驱动。PSD2Live 的模拟把这一过程自动化：先实时模拟，再拟合成 Cubism 能播放的摆锤、参数与关键形，因此导出的模型在任何 Cubism 运行时中都能播放。模拟本身（参考模拟）不会导出。

@@ external-application-integration-api | Live2D Cubism Editor 外部集成 API
PSD2Live 的外部接口是 MCP 工具。每个操作都有严格的请求与结果 schema，可用 `workspace_list_operations` 列出、`workspace_get_operation` 查看。
## 调用约定
- 参数放在 `{"request": {...}}` 中。
- 修改操作需要 `state`（来自 `workspace_inspect` 或上一次结果）；完整工具集还需要 `project_id` 与唯一的 `request_id`。精简工具集可省略后两者，`request_id` 由参数派生，相同调用的重试取回原结果。
- `state` 与当前工程不一致时报冲突，需重新读取后再试。
- 耗时操作返回后台任务，用 `job_wait` / `job_get` 取结果；精简工具集的 `wait_ms` 可在时限内直接返回结果。
- `workspace_apply_edits` 把 1–128 项编辑作为一个原子批量提交，全部成功后只追加一个历史节点；`workspace_preview_edits` 只试运行，不修改工程。

- Cubism：Viewer 载入已导出的文件，可一次载入多个动态文件。

@@ motion-setting | 动态设置
Cubism Viewer 中为每个动态设置分组、淡变、循环等，并写入 model3.json。PSD2Live 在「动画」面板与动画编辑器中设置这些属性，导出时自动写入。
## 设置项
| 项目 | 位置 |
|---|---|
| 是否导出 | 「动画」面板中动作行左侧的勾选框 |
| 名称 | 自定义动作右键 **重命名** |
| 循环 | 动画编辑器工具栏的 **循环** |
| 时长 / 帧率 | 动画编辑器工具栏的 **时长** 与 **FPS** |
| 淡入 / 淡出 | 自定义动作展开后的 **淡入时间 (s)** / **淡出时间 (s)**，见 [[fade-setting]] |
## 动作组
动作组不需要手动指定：循环动作归入 `Idle` 组，其余动作各自成组，详见 [[notes-for-sdk]]。
## 与 Cubism 的差异
- Cubism：在 Viewer 中自由设置动态组名、声音文件与淡变，再输出 model3.json。
- PSD2Live：动作组按规则自动决定，不能指定声音文件；淡变只对自定义动作设置。

@@ export-model3-json | 输出模型设置文件
model3.json 是把 moc3、纹理、物理、动作等文件组合起来的模型设置文件。Cubism 在 Viewer 中输出它；PSD2Live 在导出 Live2D 模型时自动写出。
## 写出方法
在 **文件 → 导出 Live2D 模型…**（{key:GENERATE}）中勾选 **moc3** 后导出，输出目录中生成 `<名称>.model3.json`，见 [[export-moc3-motion3-files]]。
## 内容
| 项目 | 内容 |
|---|---|
| `Moc` / `Textures` | moc3 文件与纹理集页面 |
| `Physics` | `physics3.json`（勾选 **包含 physics3.json** 且有物理时） |
| `DisplayInfo` | `cdi3.json`（勾选 **包含 cdi3.json** 时） |
| `Motions` | 按动作组列出全部动作文件 |
| `Groups` | `EyeBlink`（启用眨眼时）与 `LipSync` |
## 与 Cubism 的差异
- Cubism：在 Viewer 中设置动态、表情、姿势、命中判定等后手动输出。
- PSD2Live：随模型自动写出，内容由工程决定；不写表情、姿势与命中判定。
@@ check-the-physics | 确认物理模拟信息
Cubism Viewer 中拖动模型确认物理的效果。PSD2Live 在预览画布和物理面板中确认。
## 在预览画布中确认
1. 在预览画布左侧工具栏打开 **物理**，选择 **物理帧率**。
2. 打开 **鼠标跟踪** 后移动指针，或播放动作，观察头发等的摆动；也可以停止待机动画后直接拖动参数滑块。
3. 选择 Cubism SDK 运行时时，预览由官方 SDK 直接读取导出的 `physics3.json`。
## 在物理面板中确认
- 选中一个物理组，在摆锤画布空白处左右拖动牵动模型，观察摆锤与输出。
- 响应曲线显示标准牵动下各输出的最大幅度与静止时间。
- **最大输出力** 超过 100% 时以警告色显示，表示参数被截断在端点，可用 **按最大值调整倍率** 修正。
物理组的数量、生效数和帧率显示在物理面板上方（**生效 n / m**）。
## 与 Cubism 的差异
- Cubism：在 Viewer 中拖动模型确认，并查看物理设置的数值。
- PSD2Live：预览与编辑在同一窗口，可在摆锤画布中逐组试听，并显示响应曲线与最大输出力。
